# 自进化记忆何时会把一道题答错

本文说明当前这项预实验在研究什么、和什么比较、怎样算做成。实验仍在运行，文中没有结果，也没有结论。

## 问题

带记忆的语言模型做完一道题后，会把这道题的经验留下来，供后面的题使用。已有工作表明，这样通常能提高一整套题的平均准确率。平均分提高，并不表示每一道题都受益。记忆可能让一道原本做对的题变错。

本实验逐题比较「使用记忆」和「不使用记忆」的对错，回答三件事：

1. 这种由记忆造成的变错，是否多到不能用模型本身的随机波动来解释。
2. 在模型写出答案之前，能否根据当时看到的记忆，判断这道题会不会被记忆带偏。
3. 如果不能每道题都做两次（一次有记忆、一次没有），只抽查一小部分，能否及时发现记忆已经开始拖后腿。

第 1、2 件成立，后续才值得做「这道题用不用记忆」的选择。只成立第 1 件，则改为监控整条记忆的质量，必要时退回旧版本。都不成立，则这条线停止。

## 一个例子

下面是说明用的虚构例子，不是实验输出。

题目是：把直角坐标 \((0,3)\) 写成极坐标 \((r,\theta)\)，要求 \(r>0\)，且 \(0\le\theta<2\pi\)。正确答案是 \((3,\pi/2)\)。

不使用记忆时，模型答对。使用记忆时，系统检索到上一题，那一题把角度写成了度数。模型照着写成 \((3, 90)\)，这道题由对变错。这种结果记为**伤害**。

若检索到的是一道解法正确、形式也一致的旧题，模型因此答对了原本会错的题，记为**帮助**。对错没有变化，记为**持平**。

模型即使不看记忆，同一道题连做两次也可能一次对、一次错。所以「由对变错」不能直接算成记忆的责任。实验把同一套题在无记忆下完整做两遍，用这两遍之间的翻转比例当作噪声底。记忆造成的伤害率减去这个噪声底，才是要检验的量。

## 实验材料

数据使用公开基准 SeqMem-Eval，不改它的代码，只调用它。五套题覆盖计算、知识和写代码：

| 数据集 | 内容 |
| --- | --- |
| MATH500 | 500 道数学题 |
| MMLU-Pro Engineering | 工程类选择题 |
| MMLU-Pro Physics | 物理类选择题 |
| HumanEval | 按说明编写 Python 函数 |
| APIBench-HF | 根据需求调用 HuggingFace 的接口 |

模型是 Qwen3-8B，设置与 SeqMem-Eval 论文中该模型的设定一致：温度 0.7，不开启思考模式，最多生成 2048 个词。检索用 Qwen3-Embedding-0.6B，每次取最相近的 3 条记忆。模型在一块 RTX 4090 上由 vLLM 提供服务。

题目按固定顺序逐题完成。后面的题只能看到前面留下的记忆，看不到未来的题。同一道题的有记忆和无记忆结果按题目编号配对。

## 比较对象

无记忆运行是对照，记忆方法都是 SeqMem-Eval 已实现的在线方法。每种记忆方法在每套题上运行一次。无记忆运行运行两次，用来估计噪声底。

**Baseline（无记忆）。** 每道题只看题目本身。它不积累经验。同一套题独立做两遍。

**HistoryRAG（代码中的方法名是 ExpRAG）。** 把过去每一题的题目、模型回答和对错存下来。新题到来时，按文本相似度取出最相近的若干条，把原文放进提示。记忆的内容就是旧题本身，不做摘要。

**DC-RS（Dynamic Cheatsheet，检索加综合）。** 除了按相似度找回旧题的解答，还维护一份持续改写的备忘。解题时同时阅读这份备忘和检索到的旧解答。备忘会把零散经验收成更短的说明，也可能把某次错误的做法写进去。

**AWM-Online（Agent Workflow Memory）。** 从已经成功的解答里归纳可重复使用的步骤，并附上少量成功例子。它存的是「这类题可以怎样做」，不是每一题的全文。

**ExpeL-Online-ST（单次作答的 ExpeL）。** 维护一组可以新增、修改或删除的规则，并检索过去的成功案例。每道题只回答一次。实验没有使用 ExpeL 的多次尝试版本：那个版本在答错后会看反馈再答，改变的就不只是记忆。

## 怎样下结论

每道题得到三种结果之一：帮助、伤害、持平。事先规定的判断标准是：

- 伤害率比两次无记忆运行之间的翻转率至少高出 5 个百分点，并且这个差值的置信区间下界大于 0。这用来判断伤害是否真实存在。
- 仅用模型写答案之前就能看到的信息（题目走到了数据流的什么位置、检索到几条、这些旧题当初是否做错、题目和记忆的相似程度），预测「这道题会被伤害」。要求排序能力达到 AUC 0.65。训练和测试按时间前后分开，也按数据集轮流留出，避免用到未来的题。
- 正式运行时不可能每道题都做两次。这里模拟只对大约 10%–30% 的题再做一次无记忆对照，并用随时有效的置信区间判断：记忆带来的提升是否已经可以确认，或者是否已经差到应该报警。

准确率还会和 SeqMem-Eval 论文表 3 里 Qwen3-8B 的数字对照，允许 3 个百分点以内的差别。差别更大时，先检查实验设置是否和论文一致，再解释记忆的影响。
