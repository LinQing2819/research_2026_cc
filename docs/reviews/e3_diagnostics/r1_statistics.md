# 第1轮：统计归因与实验设计诊断

日期：2026-10-27。性质：独立分工的内部研究诊断，不是外部同行评审。
范围：只读既有材料及少量定向算术；未修改冻结代码，未运行新回放，未调用模型。
本轮收束于证据边界与三项可证伪假设；统一候选的详细攻击留待第2轮。

## 1. 结论先行

- **事实**：E3没有达到既定增量筛查门槛；这是当前表示、工作模型、分配与复核流程在这张旧表上的联合结果，不是统计上证明表示无效。
- **事实**：把E2组件选择器从31题扩到完整64题，ON的观测均值仍低于OO。“只因31题/预算少才反转”的简单解释不成立；更大独立样本是否改善选择仍未知。
- **推断**：异长搜索前缀、题目组成及工作噪声失配是可信的机制风险，但现有结果没有识别它们各自造成多少损失。不能将某一项直接称作失败主因。
- **事实与限制**：两rep的ON−OO在dev均负、test均正，削弱了“仅某一rep偶然翻转”的解释；ON−ZZ的test方向却不一致。两rep不够确认稳定效用，更不够确认一般性分布漂移。
- **建议**：先检验难度消除后是否还有可预测的配置增量，再决定是否花费新解码或多历史成本；不以原始正确性相关、首奇异能量或“新案例已曝光”替代这一步。

## 3. 哪些归因可以支持

### 3.1 31题与少预算：可以否定一个具体解释，不能否定所有预算作用

只补ON/OO这一组定向算术，不重做七臂结果表：

| 既有dev题段 | ON正确数 | OO正确数 | ON−OO |
|---|---:|---:|---:|
| 前31题 | 24/62 | 35/62 | −17.74pp |
| 后33题 | 33/66 | 39/66 | −9.09pp |
| 完整64题 | 57/128 | 74/128 | −13.28pp |

**事实**：新增到完整64题并没有使ON超过OO。因此，保持这批回答、候选和均值最大化规则不变，单纯解除31题权限不足以选出ON。完整四臂dev成本为2,733,064预留tokens，恰为原授权预算1,366,532的两倍；这只是旧表上的成本反事实，不是已执行的新选择实验。

E3也不是“同一个31题选择器”：它把dev分成搜索40题和复核24题，实际复核14–18题。报告中ON−OO在完整S为−16.25pp、完整V为−8.33pp；更多读取当前S/V标签，并无必然恢复test排序的依据。预算仍可影响候选覆盖、入围及平局，但不能据完整均值推断所有自适应算法在更大预算下都怎样。

**未知**：dev/test反转的来源比例。E2从同一历史后缀预先随机置换划分dev/test（[E2协议L49–53][e2]），不是预设的两个时间分布。随机题目组成、真实题间效应异质性、解码波动及后端稳定性均需区分；一次分割的反转不能命名为已证实的“分布漂移”。

### 3.2 主代理新增诊断：增强限制，不建立因果结论

| 描述性证据 | 可支持的判断 | 不能推出 |
|---|---|---|
| ON−OO：dev两rep为−14.06/−12.50pp；test为+2.13/+12.77pp | 反转并非仅由某一个rep的符号驱动 | 稳定单题收益；解码完全不是原因 |
| ON−ZZ：test两rep为−1.06/+10.64pp | 相对无记忆的优势比相对OO更脆弱，ZZ必须保留 | ON可靠优于无记忆 |
| 原始正确性跨rep相关：test .596、dev .522；按题减七臂均值后为.112/.136 | 原始相关含大量可被题目共同成分解释的结构 | 剩余信号为零，或已识别其生成机制 |
| test首奇异能量由原矩阵88.17%降至题中心化后30.12% | 不可用原始低秩外观证明“配置增量低秩” | 真增量必为高秩，或某个GP核必然失效 |
| 新增案例实际曝光test 93/94、dev 59/64 | “多数题没有看到新案例”的解释不符观测 | 新案例就是净收益原因，或曝光越多越好 |

中心化和奇异值是旧标签上的描述操作，且中心化残差本身也有解码噪声。低残差相关不等于不可学习；该题×臂结果矩阵也不是E3的7×7文本核，不能把两者的谱直接等同。

“有无新增案例”在test只有1道未曝光题，几乎没有题间对照支持，不能据此拟合可靠的曝光有无效应。旧/新配置的同题干预比较仍存在，但无法自动分离新增案例内容、替换、数量与长度。题型、案例数、相似度变化可作预先定义的候选调节变量，不能按旧收益挑分组后宣称机制。

### 3.3 当前可以归因到哪里

**事实**：报告支持“当前实际表示没有形成有用的选择差异”：rendered/unpacked最终选择全同，rendered/stored仅一次不同；筛查未过是三个准确率差未到阈值，不是技术无效或非ZZ次数不足。它识别的是这些已实现算法在固定表上的行为差，不是检索/packing干预对模型推理的因果效应。

**未知**：文本特征弱、核权重、噪声、搜索、候选截断、有限V各自贡献。不能由联合失败推出“GP害了ON”；完整dev本来就不偏向ON。ON是E2预定主组合，并非事后才发明，但称其为真实最佳臂仍不成立：test观测最高不是无噪声oracle。

## 4. GP平均化、异长前缀与噪声

### 4.1 平均什么，以及丢掉什么

[实现L68–84、L132–145][selection]将40题的组件相似度平均成一个7×7核，将各臂累计回答压成一个均值。其潜在对象是七个全局臂效用，不是 `f(题目, 配置)`。

**推断**：最终目标本来是选择一个固定配置，因此平均效用并非错误；但当前表示没有直接学习“哪些题受哪个版本帮助”。相反方向的条件效应可能抵消，题目组成变化可能改变排序。若改做逐题路由，就是新研究目标，不能事后用路由oracle评价原固定选择器。

还有两层不同的平均：代码使用 `mean(R_q) * mean(E_q)`，不是 `mean(R_q * E_q)`。两者一般相差题间协变项；不过本轮定向核查发现S中old/new/empty各版本规则文本均恒定，因此本表对应规则相似度恒定，不能把这一代数区别当成本次失败原因。

### 4.2 异长prefix破坏的是直接可比性，不是自动构成代码错误

[实现L101–109、L148–171][selection]为各臂读取同一随机顺序的不同长度前缀；它们是嵌套集合，不是各自独立抽样。同题共同难度在等长配对差值中可消掉，但“短前缀A均值−长前缀B均值”还含题目组成差。

对预先固定长度、均匀随机顺序，前缀均值可以对完整S均值无偏；本实现长度又受已读得分、后验、成本与可负担性共同影响，不能直接套用该无偏性或固定样本误差解释。成本依赖题目文本且可能与难度相关；不跳昂贵题符合冻结规则，也不自动保证停止前缀具有代表性。

**推断**：重叠题目造成的跨臂抽题误差应与文本相似度核区分。文本核是潜在臂效用的先验协方差，不是共享题目的观测噪声协方差。忽略后者既可能夸大某些差值不确定性，也可能遗漏组成偏移；不能笼统断言所有后验都过窄。

V使用共同题块，修复了候选间异长分母问题；但只有入围者有机会，且V最大值仍有选择乐观性。V是复核不是独立显著性验收，更多V不能救回已经漏掉的候选。16个顺序只测固定表敏感性，不提供16份新题/解码/历史。

### 4.3 `.25/n_answers`何时保守，何时不足

代码为臂a放入对角噪声 `0.25/(2m_a)`，不依赖实际对错分歧。

- **固定已读题目、预先固定样本量、请求条件独立**：Bernoulli方差至多.25，该式是该前缀解码均值方差的上界。它可能偏保守，不能仅因rep共享题目就认定条件解码相关。
- **随机新题目标**：记单臂题目正确概率为 `p_q`，每题两次独立解码。则
  `Var(均值) = Var_q(p_q)/m + E_q[p_q(1-p_q)]/(2m)`。
  两次回答不等于两道独立题；极端稳定但难度不同的题目可使方差达到 `.25/m`，是工作噪声上界的两倍。固定S的无放回读取另需有限总体修正，不能照搬iid式。
- **自适应停止/跨臂比较/新历史**：还分别有选择、共享题目及历史变异问题。高斯工作后验不提供这些保证；即使Bernoulli方差上界成立，也不使 `m±s` 变成校准置信区间。

报告中V的14–18题，一条回答对应2.78–3.57pp。独立解码最坏情景下，两臂差值标准误约11.8–13.4pp。后者只是方差尺度说明，不是本次置信区间；前者也不妨碍16顺序平均出现更小数值。它们共同提醒：2pp筛查阈值不是这点数据已经具备2pp统计分辨率。

## 5. 三项后续假设及最小设计

以下全部是研究建议，**没有批准或执行新增模型调用**。优先顺序：先H2的零生成反证，再决定H1是否值得；H3是泛化主张的必要门槛，不是自动扩实验。

### H1：固定题集的期望效用反转在新解码中仍存在

**可证伪表述**：在同一历史、输入、模型和评分下，固定dev64的ON−OO期望不为正，固定test94期望为正；先检验两题集的效应差 `G=Delta_test−Delta_dev`。仅G非零不足以证明两边异号，需分别报告区间。

**设计**：若获准，仅为ON/OO在全部158道既有题上收集预定数量的全新独立解码，跨阶段交错请求，冻结模型/提示/评分和停止点。旧回答仅用于规划，主估计不与旧回答择优拼接。不要只重测旧分歧题，不改temperature为0来替代同一目标。不变的题集使结论只针对解码，不恢复新题泛化资格。若扩充ZZ，另定主次与多重性，不借ON−OO的稳定替代ON−ZZ。

**功效成本**：双侧.05、80%功效正态规划，固定题独立解码最坏方差
`Var(G) <= (.5/r)*(1/64+1/94)`。每臂每题新增r=4时，1264次回答、精确预留6,567,888 tokens，只能以该近似检出约16.1pp的G；r=11时3476次、18,061,692 tokens，对约9.7pp的G有相同规划功效。不是符号联合确认的功效保证。

**反证/停止**：若预定区间足够窄且不支持反转，削弱固定题异质性解释；若跨零但很宽，只能判不确定。若G稳定，也不能分离题型组成与其他固定题属性，更不能改称时间漂移。

### H2：去除题目共同成分后，表示仍能预测配置增量

**可证伪表述**：在共同题目与预先固定观测掩码上，rendered相对stored及无共享模型，对留出题/留出解码的配置差值有增量预测价值；该价值在等预算完整选择中仍存在。原始正确率拟合优度不作为成功标准。

**最小设计**：先用旧表作零生成诊断，固定分割与评价指标，比较“表示种类”和“臂均值工作噪声/题目配对模型”两个因素；保持训练可见行相同，隔离表示与分配。共同前缀配对差值和异长掩码分别测量，冻结一个主预算点，再单独评价自适应分配。无需本轮实现，不能为拟合test调参。

**指标**：留出同题臂差的平方预测误差、差值校准、有限候选召回及最终策略相对ZZ/固定ON的收益，分开报告。中心化残差若需七臂标签，只能离线评价，不能向实际选择器泄漏未购买标签。低秩/核结构必须优于题目共同截距和无结构对照，而非只重构容易/困难题。

**反证/停止**：若收益只存在于原始正确性、消除题目共同成分后消失，不能宣称增量可迁移；若共同观测时有增量、异长自适应时消失，才形成分配/观测模型值得单独检验的证据。不能仅以原谱变化认定哪一种结果。

**功效成本**：旧表诊断新增生成0，不能做确认性p值。独立新题的两臂收益规划见第6节；预测误差差的方差须另估，不能套用准确率样本量。最终等预算策略检验需连同S、V和回退一起计费，不能只展示一个理想掩码。

### H3：选择收益能跨独立构建历史保留，且超过零选择成本基线

**可证伪表述**：冻结的完整策略，在指定任务与构建机制上，相对固定ZZ及固定ON具有至少预定实用收益；或达到预定非劣界同时降低总成本。两种目标必须事先二选一。

**设计**：任务内独立重建历史，划分语义隔离的B/S/V/T，固定历史数、题数、候选与强基线。相同历史下各方法共享可合法复用的结果；所有回退也进入T评价。若多历史共用题目，采用历史与题目的交叉层级方差，不把H×n×rep视作iid。相同日志的多个快照不是新历史；不同顺序独立重建若共用构建题池，也只能对该固定池的构建随机性外推。

**功效成本**：历史效应标准差若为5pp或10pp，即使每条历史内测量完全无误，检测3pp均值增量的正态规划也约需22或88条独立历史；这是情景，不是当前估计。小历史数还需t分布/仿真修正。加入每历史n=1000、题级差值方差.14后，简化独立嵌套情景约需24/89条；单一两臂测试成本已约4.99亿/18.51亿预留tokens，未含构建、S/V及其他基线。

**反证/停止**：收益仅在本条历史或某个事后挑选任务成立，或被固定ON/ZZ以更低成本解释，就不支持通用选择器。至少两任务可检查任务依赖，不能把两任务当足以代表所有任务的随机样本。历史方差目前无法由一条历史估计，资源不足应收缩主张而非用更多旧题顺序代替历史。

## 6. 统一功效口径与第2轮入口

对**固定历史的新题**，用题为配对单位，`D_q=mean_r(Y_a−Y_b)`。单一主对比、双侧alpha=.05、80%功效的正态规划为：

`n ≈ ceil((1.960+0.842)^2 * Var(D_q) / g^2)`。

这里g是待检验边界到真实效应的距离：检测3pp对零、或真实6pp要超过3pp，均为g=.03。若主张多对照同时通过，必须重新做多重性与联合功效规划，不能照抄单项80%。

已有封存analysis的C1题级方差为.13956，取.14作迁移情景，另列.25敏感性，**两者都不是新任务/选择器差值方差的保证**。两臂每题各r=2，按当前ON/OO约20,800预留tokens/题换算：

| g | 题数：方差.14 / .25 | 回答次数 | 仅两臂测量预留成本 |
|---|---:|---:|---:|
| 10pp | 110 / 197 | 440 / 788 | 229万 / 410万 |
| 6pp | 306 / 546 | 1224 / 2184 | 636万 / 1136万 |
| 3pp | 1221 / 2181 | 4884 / 8724 | 2540万 / 4536万 |
| 2pp | 2748 / 4906 | 10992 / 19624 | 5716万 / 1.02亿 |

题目异质性可能使方差超过.25；有界D属于[-1,1]，不加假设的上界为1。更多同题解码只缩小解码项，不消除题目/历史项。ON−ZZ或策略−基线也有不同的成本与方差，以上仅为量级锚点。

新实验的主检验、校准办法、任务聚类、预算和停止条件都须另行冻结；不得替换E2的六个既定区间。第2轮优先攻击H2是否真有增量预测对象和可识别对照，再判断其收益是否足以支付第6节以及独立历史的成本。
