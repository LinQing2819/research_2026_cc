# R2：A/D 信息消融的可识别性与最小诊断

日期：2026-10-27。性质：研究设计交叉反驳，不是实验准入或统计验收。

**裁决：强制选择“总体 signed diff 的低成本估计”为唯一最终目标；放弃本轮“失败发现”目标。A 的选择算法 HOLD，D 仅准入只读数据资格阶段。** 下文的小规模新解码方案只是供 R3 审查的条件预算，不是启动许可，也不产生 3pp、非劣或部署安全 PASS。

依据：[R2共同候选稿](r2_candidate_revision.md)、[R1统计](r1_statistics.md)、[R1记忆文献](r1_memory_literature.md)、[R1问题重构，尤其§2.2/§8](r1_problem_reframing.md)、[R1数据与评估文献](r1_data_and_evaluation_literature.md)。本轮没有联网，没有重算旧成绩表，没有模型调用或实现修改；只做文末两项预算算术。

## 1. 接受什么，否决什么

| 事项 | R2判断 |
|---|---|
| 已知新版本，旧版本关系是否提供可迁移的验证信息 | 接受为待证伪的信息命题，不接受为已证实贡献 |
| 用发现更多失败、变化更大的题证明总体估计更准 | 拒绝；目标和抽样分布不同 |
| 用 ON 作为正确配置标签，或以选回 ON 的次数验收 | 拒绝；旧结果不确立 ON 的稳定优势 |
| 用原始答对率、难题识别、静态适用域识别替代版本差值预测 | 拒绝；这些信号可在两个版本中同时存在 |
| 可重复就有新颖性，或不可重复就说明没有新颖性 | 两种推论均拒绝；测量资格和文献差异是两道独立门 |
| 四千次量级 pilot 必须给出统计 PASS | 拒绝；允许结果未决，且可以因资格不足完全不跑 |

旧 14 条在 new20 中全部保留，仅有微小措辞归一化差异，新增六条并重排。因此当前更新不能支持“删除前提/抽象遗失”的机制故事。新增、顺序、检索和打包可能共同影响实际输入；未分离干预前，只谈**版本更新包的总差异**，不把收益归到某条规则。

源规则到真实经历的绑定暂无。它阻止候选 B 的来源特异性研究，但不自动阻止 A：A 必须有真实的版本父子关系、完整输入和历史独立性记录，不必假装已经有逐规则源谱系。这两种“谱系”不可混称。

按本轮补充的数据核验，当前导出快照只有 `completed,pool,prefix_sha256,rules`，`pool` 条目只有 `qid,question,trajectory`；没有 `rule -> source` 事件谱系。`prefix_sha256` 标识前缀，不恢复逐次规则编辑或真实来源绑定。**目前只有一条已分析历史、一个两端快照 transition；不能按六条新增规则、重排或两端文本切片拼出八个独立更新。** 合成中间版本也不能补足自然历史样本量。

## 2. 唯一目标与总体权重

令 `h` 表示独立构建历史中预先指定的一次自然更新，`q` 为该历史的冻结评价题，`r` 为独立解码：

```text
D_hqr = Y_new,hqr - Y_old,hqr
tau_hq = E_decode[D_hqr]
Delta_h = sum_q pi_hq * tau_hq
```

旧新使用各自冻结版本按同一协议得到的实际输入，solver、评分器、预算和环境相同；不在评价中继续学习。`tau` 包含该更新引起的内容、排序、检索和 packing 变化，不是单条规则效应。配对单位是**同一历史、同一题的两个版本**，不是同 rep 编号意味着共用随机数。

主目标为有限冻结题池上的 `Delta_h`。池内按题等权，题池的构成和排除规则在看结果前冻结。两任务分别报告；如给描述性汇总，任务等权，任务内留出历史等权，不按题量、调用数或发现失败数加权。这不是部署流量权重，也不代表任意未来任务/历史总体。

最终想检验的是：同总成本下，真实旧新关系能否降低 `Delta_h` 的估计误差。**本轮 D 只检查支持这一目标的预测信息和残差结构，不能用它提前宣布估计效率获胜。**

### 选题与估计必须分离

- 本轮不生成挑战题、不做自适应采集。各信息条件使用完全相同的校准题、标签权限和独立概率审计题。
- 定向发现题的均值不是 `Delta_h`；发现收益/伤害可以留作描述，不能进入主成功标准。
- 后续若研究采集，必须记录条件抽样概率及成本，保留正概率探索和独立随机审计。探索下限本身不修复偏差；还要使用与实际无放回/自适应设计相容的估计器。
- 不能先读取全部候选新旧回答再声称节省生成预算；已有标准答案也不等于已有候选模型表现。

对与训练/校准题分离的有限评价池 `Q_h`，冻结预测 `m_hq` 后，从中均匀无放回抽取审计题 `A_h`，可研究普通模型辅助估计：

```text
Delta_hat_h = mean_{q in Q_h}(m_hq)
              + mean_{q in A_h}(Dbar_hq - m_hq)
```

在冻结预测、概率抽样和无偏解码测量条件下，残差校正针对该有限题池均值；它不是本项目的新估计器。非均匀目标必须同步改成相应权重。审计标签不得再用于调预测后重算同一“独立”结果。

**关键对照：** 若 `m_hq` 是任意常数，上式恰好退化为审计题的直接 paired 均值。因此只修正常数偏置或猜对全局方向，不证明省题；需要可泛化的题间 signed 残差结构。小样本审计也没有提供无噪声 `Delta_h` 真值，不能拿它自身当真值比较估计误差。

## 3. signed diff、magnitude 与噪声

`tau_hq`、`abs(tau_hq)`、`P(Y_new != Y_old)` 是不同对象。高分歧可以来自随机解码；更新帮助一部分题、伤害另一部分题，也可能在总体完全抵消。能找“变化大”不等于知道方向，更不等于知道总体权重。

本轮以**signed 残差方差的降低**为与总体估计有关的主诊断，signed 平方预测误差和校准为辅助。不得用只识别答题难度的分数验收。预测锁定后，可在独立审计上比较同一批 `Dbar` 的损失差和残差；共同测量噪声不应被当成某一表示的独有收益。

审计每版本四次解码，预先拆为两组，每组两次，得到 `D^(1)`、`D^(2)`。它们只提供有限的解码复核：

- signed 结构须在两组中分别报告，不能先按第一组筛“回归题”再只展示第二组成功者。
- `abs(Dbar)` 和观测分歧率有噪声贡献，不是 `abs(tau)` 的无偏标签。若描述幅度，可用独立组乘积 `D^(1)*D^(2)` 的聚合量探查 `tau^2`，前提是条件独立且 solver 稳定；保留负的噪声估计，不截成零或据此认证单题。
- magnitude 只能作次级解释；若它未改善 signed 残差或总体估计，不能改换主目标宣布成功。幅度可能有助于后续方差分配，但那需另审设计。

### 11985 对设计的直接否决

R1 已记录：11985 的 ON/OO 完整 token IDs 相同、均为 3568 tokens，prompt SHA256 相同，但 ON 两次全对、OO 两次全错；四次 seed 不同。在冻结、无状态、稳定 solver 的假设下，这不是记忆输入干预，不能标为个体修复。**每臂两次一致不确认个体回归；本方案四次也不自动确认。**

因此保留完整 token IDs、请求配置与交错调度记录；相同输入单元作为零效应检查，不按观测成绩删题。若新诊断出现相同输入的系统性偏移，应先排查测量条件，而不是宣称版本作用。

旧新绝大多数实际提示不同，故“是否暴露变化”既不能解释效应方向，也不能作为主要省题来源。未来如按输入相同跳过解码，必须在看回答前判定、保留其总体零贡献及原分母，并保留测量检查；本最小预算不预扣这项未经证实的节省。

## 4. 信息消融：不能让对照替主张作弊

信息条件只改变**评估预测器看到什么**，不改变被评价 solver 的旧新输入。以下条件共享编码器、简单预测头、输出维度、训练标签和调参上限；特征/边界分析调用也同预算。新版本条件应允许把等额分析预算用于自身边界分析，不能故意只给它一个弱摘要。

| 条件 | 可见信息 | 可以排除什么 |
|---|---|---|
| N：新版本 | 题目、新版本可用文本与实际渲染信息；新版本边界分析 | 单版本信息是否已经足够 |
| M：廉价变化量 | N + 增删量、长度差、顺序/曝光变化等预定非语义幅度特征 | 是否只是“改得多就更不稳定” |
| U：旧新原文 | N + 真旧版本及实际渲染，明确版本方向，不额外生成 diff | 旧内容本身的价值 |
| D：旧新原文加 diff | U + 确定性、可复核的真实差分 | 显式差分组织是否比直接给两端更有效 |
| P：匹配非配对旧版 | N + 同任务、长度/格式接近的非父版本，按相同流程处理 | 额外旧文本/预算的解释；仅为负对照 |

非父版本来自不含留出题族的预定开发库，匹配不看成绩；无法匹配则记录不可识别，不能任挑一个很差的旧版衬托 D。P 单独表现差不证明真实关系有价值，D 仍必须优于强 N、M 和 paired 常数。

U 就是必要的**等预算 rawpair baseline**，不是弱化后的旧新摘要。U/D 的原始两端可见内容必须相同，总编码/推理预算相同；不能只截断 U、给 D 额外上下文或隐藏生成 diff 的成本。两端原文加 diff 放不下时，先判该单元的信息/预算条件不合格，不把压缩或截断差异命名为新增信息。

三个必要限制：

1. `diff` 是旧新原文的确定性函数。D 胜 U 只能说明有限模型/预算下显式组织有用，不能说它增加了原文之外的信息量。U/D 胜 N 也可能只是旧内容有用，不等于“版本关系”已被单独因果识别。
2. 给定新版本后，所谓“隐藏方向的旧新文本”往往可恢复方向。随机交换标签不是可靠的 signed 信息消融，反向排列同一对也不是新的自然更新。M 是弱变化量对照，不声称它与方向统计独立。
3. 若自然数据中每种新版本/规则族只对应唯一旧版，无法从这些数据完全区分旧内容、关系和域标签。只能检验该输入包的有限预测增量；需要未见更新关系的外推来减弱记忆解释，不能靠制造假删除或假反例补出识别。

### 必须保留的简单基线

- `tau_hat=0`。
- `tau_hat=c_h`：只用该未见更新的共同校准题计算 paired 差值均值，对所有审计题预测同一常数；另列只用开发历史的任务级常数。它们不需要完整候选回答表。
- 均匀抽样的直接 paired 均值。本轮共用均匀审计；固定题型分层抽样的 paired 均值留作后续采集对照，不能伪造本轮未采集的标签。
- N 的强单版本边界方法。只按题目 embedding 取代表点可列为后续采集基线，不在本轮偷偷增加选择实验。

预测可重复但不胜这些基线，只说明存在可测量对象，不支持更复杂算法。估计 `new-old` 也不证明两者优于无记忆；本轮不做配置部署选择，因此不把 ZZ/固定 ON 的策略收益混入主目标。若未来恢复策略主张，零选择成本的固定版本及 ZZ 对照必须重新入账。

## 5. 防止记住 ON、题目或适用域

- 不使用 ON 标签、历史胜者、旧 test 分组收益、qid、源 ID、绝对时间/顺序作为预测捷径。规则方向可以看，但不能把臂名当效用标签。
- 按**构建历史根、规则/适用条件族、题目语义族**隔离开发与留出。数值替换、同题改写、同规则复述不能跨侧；同一日志多个快照仍只是一条历史。
- 留出题族同时排除所有构建轨迹和拟合/校准输入中的近重复。家族划分依题目/规则内容及已有元数据，不能依收益挑“可迁移”分组；不确定的谱系合并成同一簇。
- 每条未见更新可用相同的 16 题校准，故主诊断是有限标注适配，**不是零样本跨更新迁移**。审计题族不得已在该校准集中出现；所有条件权限相同。
- 每任务的留出更新必须包含开发阶段未见的规则条件关系。若效果仅由固定任务/域标签或某个旧前提的反复出现解释，降级为域内预测；不能声称更新关系迁移。

六条历史能否满足这些隔离约束要先查数据。不能一边使用同族数据增加样本，一边把“适用域已记住”称作迁移。两个任务均有开发历史的设计也不是零样本跨任务泛化。

## 6. 两个具体任务与数据资格

|---|---|---|
| MMLU-Pro Engineering | 冻结题干、选项、标准答案的一道工程题；按物理关系/求解模板分题族 | 延续原任务但排除 E2/E3 已看标签及其近重复。评分支持选项正确性，不单独证明推理或公式机制 |

第二任务取自仓库已有接口，避免立即设计新任务平台；依据是 [SeqMem-Eval README](../../../third_party/SeqMem-Eval/README.md) 和 [APIBench适配器](../../../third_party/SeqMem-Eval/tasks/task_apibench.py)。接口存在不等于数据、独立历史或合格 oracle 已存在。本轮未完成其资产审计；APIBench 不能满足资格就 HOLD，不临时换一个已知效果好的任务。

**独立单元方案：两任务各 3 条历史，每历史只取 1 次自然更新。** 每任务 1 条用于开发，另外 2 条在预测/评分方案冻结后留出。更新位置按预定进度窗和“首个合格实际变化”规则确定，不按收益、规则疑似错误或差分大挑选；无合格更新算资格失败，不能选择后续好看的更新替换。

优先资格是独立起点、互不重叠且无近重复的构建经历流。同一公共构建池换 seed/顺序，只能提供对固定池构建随机性的证据，必须降级记录，不能算获得了六份独立来源历史。后缀题、解码重复或重放顺序都不增加历史数。

| 必查项 | 接受条件 | 缺失时 |
|---|---|---|

| 实际版本干预 | 原始与渲染文本可恢复；检索/packing 可核查；逐题完整输入身份可比 | 缺失则不能解释版本作用 |
| oracle | 标准答案/评分版本固定，API gold 不泄漏给预测器；非 LLM 临时裁判 | HOLD，不用新增裁判调用掩盖资格缺口 |
| 自然性 | 原更新过程的真实日志，不人为植入删条件或选择已知失败 | 合成更新只能另立问题，不填自然更新名额 |
| 成本 | 全流程调用、token、构建/特征/失败成本有账；预算能覆盖整套对照 | 不够即 HOLD，不删强对照换取开跑 |

只读资格阶段可读已有快照、元数据、评分器与 token 记录，手工写隔离/预算清单；不得调用模型生成特征、构建新历史、跑 prepare/preflight/smoke/run 或更改原记忆。本轮也不授权新增旧表拟合。缺逐规则源绑定须如实记录，但只有来源机制研究以它为硬门。

具体进路是先定位原始构建日志，核实是否已有其他独立根历史及可恢复更新事件，再出两任务的隔离清单、测量字段清单和逐项成本表。若没有，R3 应接受“数据缺口已明确、测量方案可审”的研究交付，新增生成继续 HOLD；另行申请数据采集，不视为本轮失败。

## 7. 条件性最小诊断与硬预算

以下只有 R3 另行批准后才可执行；如六条合格历史无法获得，保持 HOLD。

每历史设 16 道共同校准题，每题旧新各 2 次解码；另有来自独立冻结评价池的 32 道概率审计题，每题旧新各 4 次解码。所有信息条件与常数基线共享这些 solver 回答，但预测器只能读取其被分配的校准标签。审计题可以共用已冻结的输入特征，不能共用给训练器的审计答案。

| 项目 | 预算/规则 |
|---|---|
| 旧新标签采集 | `2任务 × 3历史 × (16题 × 2版本 × 2rep + 32题 × 2版本 × 4rep) = 1920` 次回答 |
| 完整路线总上限 | 3072 次已提交模型 attempt，含 solver、记忆构建、特征/边界分析、任何参考模型、失败和重试 |
| 其余共享额度 | 1152 次，不是每个方法各有 1152 次；构建与所有对照分配须在运行前逐项冻结 |
| 单次约束 | 沿用 R1 预算口径：输入至多 5888、输出预留至多 2048，共 7936 tokens；超长不暗换更大服务 |
| token 总上限 | `3072 × 7936 = 24,379,392` 预留 tokens |
| 其他硬停止 | 沿用 R1 单路线至多 72 GPU 小时、24 人工小时，任一上限先到即停；不保证在该时间内完成 |

上表前一式和 token 式是本轮仅有的两项额外算术，不是功效计算。已有构建若可复用，新增支出和历史构建成本分账，总方法成本仍报告后者，不能说离线数据免费。若完整成本不能落入此诊断封顶，R3 可否决该方案；此处没有证明剩余额度足以新建六条历史。

1920 次是计划成功回答形状，失败重试会消耗共享余量；超限不补跑追结果。相同 solver 回答的合法共享不意味着五个信息条件没有特征成本。全题池预测、边界卡、CPU embedding/选择耗时均计账；不存在免费大模型、完整新候选输出表或预算外 pilot。

### 这点数据最多证明什么

- 四条留出历史分别提供有限的 signed 残差信息、噪声和实现可行性诊断；开发的两条不能并入“六条独立确认”。
- 同一历史内的题和 rep 不作为独立历史。若跨历史复用题，须显式记录历史与题的交叉聚类；不能用所有回答数作 iid 样本量。
- 报每任务、每留出历史、每解码组的结果及敏感性；这么少的历史不靠 cluster bootstrap 或普通 t 区间取得跨历史保证。
- 不能确认 3pp 总体增益、3pp 非劣、误提交率、单题回归或普遍迁移。R1 已给出小效应需大得多样本的情景，本轮不重复求“刚好能过”的功效。
- 正向结果最多使信息价值假设值得继续研究。没有全池可靠真值或另设独立误差评估，不能宣布模型辅助估计已比 paired 审计均值更准。

## 8. R3 接受、拒绝与未决规则

| 层级 | 可接受的决定 | 拒绝/停止条件 |
|---|---|---|
| 当前资格 | 接受只读资产与隔离审计；输出缺口和真实成本 | 不把缺数据转成自动授权构建/解码 |
| D 的可测量性 | 自然版本、评分、输入身份和独立性均可核验，观测不只由明显测量异常解释 | 同输入系统性效应、标签泄漏、同源冒充独立，则停止解释 |
| D 的有限信息价值 | 留出历史/题族上的 signed 残差改善相对 N/M/paired 常数呈一致可复核迹象，完整成本未被简单方案支配 | 优势仅是原始正确率、magnitude、记住域/臂名或弱 P 对照，则拒绝对应增量主张 |
| D 中 U 与 D 的区别 | U 有用而 D 不优于 U，可保留“旧版本输入有用”的窄假设 | 不再宣称显式 diff 算法贡献；两端已含全部差分信息 |
| A 的采集/估计算法 | 只能在资格与信息结果值得继续、且另有冻结设计后审议 | 未证明信息结构就扩 GP/RL/主动选题，拒绝 |
| 新颖性 | 单独对照 R1 已核验近邻，明确新增的信息条件/估计对象 | 可重复、跑通、节省若干调用均不自动排除已有方法重合 |

“一致迹象”是进入下一次研究设计审议的依据，不是统计显著性或方法 PASS。噪声大、历史少、区间宽、两任务结论分裂时一律允许 **HOLD/未决**；不能把未显著解释为零增量，也不能增加 seed、换题或改阈值追通过。若主张只能靠挑战集均值、人工删除前提或改成失败发现才成立，本条总体估计路线应拒绝，而非中途换目标。

文献侧最低边界不变：paired 验收、主动评估、单版本边界、变更驱动回归和局部消融已有直接近邻。本轮不重新查重，更不宣布无人研究。**交给 R3 的唯一入口是：先确认是否有合格独立数据，随后决定是否值得测信息；选择算法继续 HOLD。**
