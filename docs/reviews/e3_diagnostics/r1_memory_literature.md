# 第1轮：E3失败后的外部记忆文献核验与新颖性边界

日期：2026-10-27。状态：**宽泛提案重合已确认；两个窄假设保留研究，尚不支持实现或新颖性承诺。**

## 1. 范围与结论

本轮只研究、联网检索和记录，没有修改实现，没有运行新的模型实验。已完整阅读 [E3真实回放结果与逐题诊断](../../E3真实回放结果与逐题诊断.md) 和 [历史来源记录](../e3_replay_design/sources.md)。

按用户追加要求，把 CounterMem、FAME、MemAdapter、Decision-Aware Memory Cards/CICL 提至最高优先级。除四个历史引用外，最终重点比较六篇：上述四篇、CICL直接引用的CMI、MemRL。不为满足数量继续扩展A-MEM、Mem0、SEAL、Dynamic Cheatsheet；前期搜索见到的这些论文片段不承担本轮新颖性判断。检索目标时间窗为2024—2026，精读集中于直接威胁候选的2026版本，并非逐年配额式综述。

本文件是至少三轮研究中的 **R1外部记忆分工交付**，不是三轮总评。当前执行未额外启动独立子代理，不能把并行网页读取算作多agent评审；R2/R3及跨agent交叉质疑仍需主代理组织。主动模型选择、实验设计理论和泛bandit检索归主代理，本文只交付记忆侧的重合、实验对象和必要对照。

核心结论：

1. **四个历史arXiv编号本轮均核验通过**：版本元数据可读，标题与所述方法基本对应，关键正文可读。没有需要标成“未核实”的历史条目，但不能把“论文存在”升级成“实验或定理已独立验证”。
2. **适用条件、边界卡、原始证据、局部反事实、因果记忆选择均已有直接近邻。** CounterMem同时覆盖经执行验证的动作对照、源任务证据、适用条件、选择/跳过和冗余处理；MemAdapter明确生成boundary cards；CICL明确规定trigger/evidence/scope；SkillSmith已有随机遮蔽、二阶交互和版本作用域失败记忆。
3. 不能以“语义相似不等于有用”“加适用域”“保存反例”“记忆消融”“换成RL/GP/embedding”作为主贡献。E3也没有提供足够证据支持这些替换会奏效。
4. 尚可研究的是更窄的信息命题：**旧新规则的差分，相比只看新规则的边界描述，是否提供可迁移的验证信息；源经历的正确绑定，相比等预算的相关经历，是否对抽象退化有特异保护作用。** 都只是可证伪假设，不保证无重合。

## 3. 历史引用对候选的约束

### 3.1 Faulty Memories：不止“延迟抽象”

[§5](https://arxiv.org/html/2605.12978v2#S5) 明确让episodic buffer与abstract store并存，允许Retain/Delete/Consolidate；episodic-only可匹配或超过Auto，不支持“必须抽象才有收益”。[§7](https://arxiv.org/html/2605.12978v2#S7) 已要求抽象建立在可恢复的原始轨迹上；[L.3](https://arxiv.org/html/2605.12978v2#A12.SS3) 显示延迟压缩缓解但未消除差距。

更直接的重合是 [I.1 memory surgery](https://arxiv.org/html/2605.12978v2#A9.SS1)：固定其余七条工作流，只移除W8，在50个WebShop任务上比较。论文报告两个rollout模型的成功数分别从7/50到14/50、18/50到23/50。每格只有单次run，因此支持该快照中的内容干预证据，不是普遍、稳定的单条规则伤害保证。

**重合判断：** 快慢记忆分离、原始经历作为证据、选择性/延迟抽象、固定快照单条消融都不能再作为首次提出。历史记录只强调§5/§7会漏掉直接的局部干预近邻。

### 3.2 PACE：验收不是验证任务发现

[§4](https://arxiv.org/html/2606.08106v1#S4) 对同题的候选/当前配置做配对比较，丢弃同对同错，以discordant outcomes建立e-process。保证依赖每步条件胜率在零假设下不超过1/2，且是**单候选**保证。

[§6](https://arxiv.org/html/2606.08106v1#S6) 明说它继承dev覆盖，无法认证dev看不到的增益。不能把anytime-valid解释为“反复复用开发题来产出候选仍自动全程有效”；选择性抽取对候选有利的题也不会自动保留目标分布上的保证。

**重合判断：** 配对验收、预算内早停、保留当前版本已有。可能研究“验证题从哪里来”，但不能只在PACE前接一个LLM出题器就宣称新颖；CounterMem/MemAdapter已进一步覆盖条件反例和假想任务。

### 3.3 SkillSmith：直接覆盖干预、交互和版本失败记忆

[§3.2](https://arxiv.org/html/2606.01314v2#S3.SS2) 对已检索skill做独立随机mask，以居中特征估计主效应/二阶交互，使用Bayesian shrinkage；按单位上下文成本的边际效用分配，检索分数包含与当前已选集合的交互。

[§3.3/3.5/3.6](https://arxiv.org/html/2606.01314v2#S3.SS3) 还包括疑似组件定位、反事实确认、先在parent上复现通过再做失败编辑的delta debugging、版本作用域nogoods、受影响组件依赖检查和单元/集成/回归测试。预算耗尽为未解决，不能当作通过。

**重合判断：** 随机局部干预、冗余/冲突交互选择、失败证据复用、版本变更后失效、针对受影响组件验证都已有。条件限制是固定估计窗口内平稳且同质的二阶效应、足够共同检索暴露；不能将模型保证外推为任意任务异质性下的因果泛化。附录的1-minimal也不是最小基数致错集。

### 3.4 LIMBO：按题决定是否用记忆和花多少预算

[§III-C—E](https://arxiv.org/html/2609.14138v1#S3.SS3) 定义none/full/compressed/retrieved动作，与token/轮数/tool预算组合；还区分原始轨迹和保留动作语法的trimmed-trace渲染。两头LinUCB分别预测准确性和成本，逐题在线更新，基础模型不变。

**重合判断：** 无记忆选项、按题记忆/成本联合控制、不同注入表示不是新方向。本轮不重复其bandit理论；它并不为某一条规则的适用边界或具体记忆更新的因果改善提供验证。

## 4. 新增直接近邻

### 4.1 CounterMem：对宽泛反事实提案的最强否决

根据 [§3](https://arxiv.org/html/2609.31874v1#S3)、[附录B](https://arxiv.org/html/2609.31874v1#A2)：

- 失败动作后最多提出4个局部替代动作，从**同一状态的副本或reset**运行测试、证明检查器、SQL结果检查器等。这里的world model可以是可执行检查器，不应顺承成“另训一个神经世界模型”。
- 经检查且收益超过阈值才可入库，记录为 `(q, a_minus, a_plus, e, c, u)`，包含情境、原/改动作、检查证据、适用条件和复用统计，并保留源任务ID。
- 适用条件在检索过滤和提示渲染两处发挥作用；排除同任务来源。候选到达后DQN选一条或skip，基础LLM冻结。构建/训练排除最终评估任务，评估时记忆和策略均冻结。
- 入库和保留分数已处罚重复建议与冲突；不能把“反事实记录加去重”作为差异。

条件不是装饰：[§5.3、E.3](https://arxiv.org/html/2609.31874v1#A5.SS3) 专门构造表面相近但条件不成立的look-alike任务，去掉 `c` 后所报告有害使用率由11.8%升至34.2%。**删除同时发生于检索过滤和渲染两处**，故不能据此拆出“条件文本”或“条件gate”的独立效应；分母是selected-record uses，不是全部任务，也不是配对broken-task比例。[D.8](https://arxiv.org/html/2609.31874v1#A4.SS8) 明文要求生成“条件为假”的相似目标，因此“新增边界反例任务”也已高度重合。

证据边界：[附录A](https://arxiv.org/html/2609.31874v1#A1) 承认检查只支持已测状态、记录可能随工具/要求变化而陈旧，且目前每个决策至多用一条。复用统计 `u` 的实现并非对每个新任务都执行完整memory/no-memory反事实对照；动作变化并成功可标beneficial，部分情况参照先前已执行尝试。不能把它等同于无偏的逐条记忆处理效应。

成本边界：[§4.4](https://arxiv.org/html/2609.31874v1#S4.SS4) 的task-run tokens不单独核算离线selector训练；每解出一题的检查次数也不等于总检查数。论文自述代码待接收后发布，运行配置/轨迹并未全部包含在稿件中，本轮未运行代码。

**不能宣称的新颖点：** 同状态动作反事实、执行验证后存记忆、源证据＋适用条件、选择或跳过、条件反例、伤害/收益分开报告。

### 4.2 FAME：已用反事实任务测记忆边界，但目标是隐藏表征诊断

[§3](https://arxiv.org/html/2609.39473v1#S3) 固定记忆，通过干预query来观察诱导概念的变化。用leave-one-out记忆下的hidden states建立参考，对比事实/反事实query的概念漂移，再根据任务要求判断应该保持还是应该适应；不是“漂移越大记忆越坏”。

[附录E](https://arxiv.org/html/2609.39473v1#A5) 已给出系统化模板：保留伪特征但改变真实任务关系、去掉伪特征而保持关系、改变环境、制造知识冲突，并控制吸引记忆关联的提示强度。

**重合判断：** 反事实任务、适用边界、伪相关诊断、普通失败与记忆误导的区分均已有。其测量对象是query intervention下的hidden-state/readout变化，而不是新旧外部记忆版本的任务收益差；它不是黑盒API即可直接使用的方法，也不是持续提交/回滚规则。

**限制：** 方法中的可识别性和answer-free表述有SCM、hidden-state充分性、连贯记忆和特定readout等假设；本轮未验证证明。该文主要是诊断框架，不能把AUROC当作在线修复后的准确率，也不能从一般相似度检索自动推出所有记忆一致。

### 4.3 MemAdapter：边界卡和按情境调节影响已是方法本体

[§3.1](https://arxiv.org/html/2610.05162v1#S3.SS1) 与 [H.1.1](https://arxiv.org/html/2610.05162v1#A8.SS1.SSS1) 明确：

1. 固定原记忆的内容、来源和时间范围，不给当前query；由记忆推导任务类型、构造假想请求和证据条件，评估在每个条件下可支持什么、可影响哪部分、不能证明什么。
2. 比较这些评估，按等价影响合并，输出每个memory_id的boundary card，含counterfactual settings、conditional-use rules、boundary summary。
3. 再把当前query、证据和所有记忆共同交给Context-Aware Reflection，处理限定/更新/冲突，产生逐条use instruction；最后在Evidence-Based Reasoning中按支持来源和使用范围检查答案。

**重合判断：** “固定记忆、变化任务、发现适用域，再绑定证据并约束推理”几乎就是其管线。不能把“适用域不是记忆的静态标签而是记忆与任务的关系”当作我们的新观点。

**关键区别而非免重合理由：** 假想条件中的warranted contribution来自LLM评估，已读算法没有对每个假想任务执行与CounterMem同类的可执行结果验证。答案支持检查也是内部生成过程，不是独立裁判/外部可恢复审计轨迹。论文保持上游记忆/检索不变，是post-retrieval适配，而非根据新旧规则diff决定持久提交。

实验对照复用相同冻结检索集，能分离检索差异；但不能把所有增益归因于边界推断质量而忽略额外推理开销。其结果也显示某些有益记忆使用指标变差，说明“更少被记忆误导”不能替代“保留本来有益的记忆”。

### 4.4 CICL：决策效用、带证据/作用域的卡片和打包次序已有

[§3.1—3.5](https://arxiv.org/html/2606.08151v2#S3) 的context unit包括文件、测试、轨迹、规则、记忆；图边含冲突、precondition及来源关系。效用分解为action shift、outcome uplift、necessity、negative-transfer risk，运行分数用固定启发式权重再扣成本。

memory card的五个必填字段为 **trigger、evidence、action hint、failure-if-ignored、scope**。它还明确区分：

- 先选ID再压缩文本：考察压缩本身。
- 先压缩成本再预算打包：候选ID也可能改变。

这对E3尤其重要：改变表示或卡片长度，不自动意味着决策信息有增量，也可能只是换了入选集合。

**重合判断：** 决策而非相似度导向的检索、条件/证据卡、成本打包、移除高效用项的诊断都已有。不能通过新命名或把judge换成GP重建贡献。

**证据边界：** [§6](https://arxiv.org/html/2606.08151v2#S6) 明确承认counterfactual-inspired不等于正式因果识别，效用没有被随机干预识别。主要真实代码结果是50个SWE-bench Verified实例的**文件检索**，不是官方patch成功；[§5.6](https://arxiv.org/html/2606.08151v2#S5.SS6) 的patch检查规模很小。故它否决宽泛表述，但不能据此认定完整agent收益已充分验证。

### 4.5 CMI：不能声称“以前只有反事实想象，没有实际记忆干预”

[§3.2—3.4](https://arxiv.org/html/2605.17641v1#S3.SS2) 比较无记忆、单条记忆、扰动该记忆三种回答，以任务评分差筛选。这直接覆盖“在外部记忆上做局部干预而非只测相似度”。

必须保留两个限制：

- §3.2/§8承认选择时使用useful/irrelevant/harmful角色标注；§3.3的干预评分还显式使用目标答案 `a*`。这是带标注的受控研究，不是最终无标签任务上免费获得的selector监督。不能拿其数值当作同信息条件的部署基线。
- 文字称筛选扰动后稳定的记忆，但公式定义 `Stability = score_with - score_perturbed >= 0`；这一判据本身并不排除扰动后大幅退化。比如0.8减0.2仍通过。这个公式/解释不一致未通过代码解决，不能援引为已建立的稳定性保证。

**重合判断：** 存在方法和实测干预这个事实不能因为评估限制而抹掉。我们的区别必须是新的信息条件、估计对象或可迁移证据，而非“首次用真实回答消融记忆”。

### 4.6 MemRL：效用学习不是因果归因，也不是新贡献空白

[v2 §4.1—4.3](https://arxiv.org/html/2601.03192v2#S4.SS1) 定义Intent–Experience–Utility triplet，先语义候选召回，再将归一化相似度和Q效用混合排序；没有候选时不注入记忆。环境反馈更新实际注入项的效用，LLM参数不变。

需分清表述：§4.1用raw experience描述payload，§4.3实际写回过程又由LLM总结新轨迹。不能据“raw”一个词宣称它必然保留所有原始token、不可变源证据和完整谱系。

**重合判断：** 冻结基础模型、运行时反馈学习记忆价值、语义相关但无用的项被压低已有。多个注入项共享任务回报并不等于逐条因果边际效应；只把E3换成Q-learning/RL不会解决这一识别问题，也不会自动解决开发集缺少信号。

## 5. 候选查重矩阵

下表的“未见”仅限§2列出的读取范围，不是对所有文献的不存在断言。

| 候选元素 | 已确认的最贴近覆盖 | 仍可区分的具体问题 |
|---|---|---|
| 针对变更生成/选择验证任务 | SkillSmith检查受影响组件并回归验证；CounterMem验证局部修正且生成条件为假的look-alike任务；MemAdapter构造记忆特定的假想任务 | **给定同一新规则，旧新差分是否比单版本边界信息提供额外验证价值**；不是“是否能生成边界题” |
| 记忆规则的适用条件 | CounterMem的 `c` 过滤/渲染；MemAdapter的条件影响规则；CICL的trigger/scope；SkillSmith的版本scope | 条件在具体更新中被扩张/删除后，能否事先定位受影响任务；静态标签或单次判断不构成差异 |
| 原始经历证据绑定 | Faulty Memories要求可恢复原轨迹；CounterMem保存动作对照、检查结果和源ID；MemAdapter保留来源语义；CICL有evidence/source | **正确源绑定是否优于同token、同相关性的非源经历或错误绑定**；存字段本身不新 |
| 局部因果干预 | Faulty的单工作流移除；SkillSmith随机mask和delta debugging；CMI实际回答干预；CounterMem同状态动作干预；FAME query干预 | 必须先说明干预的是query、动作、记忆项还是记忆版本，且是哪一种收益；不能统称反事实就混用证据 |
| 冗余/交互选择 | SkillSmith二阶效应及交互检索；CounterMem重复/冲突处罚；CICL图关系与预算选择 | 单条收益不等于集合边际收益；但提出集合选择、二阶项或去重仍已重合 |
| 持续更新验收 | PACE配对提交门；SkillSmith阶段化候选验证、拒绝保留parent和版本失效 | 验收目标与抽样覆盖必须另行定义；换统计器不补不存在的验证信号 |

特别区分三个命题：

1. **源动作修正有效：** 同状态下 `a_plus` 优于 `a_minus`，CounterMem可验证这一点。
2. **记忆在新任务上有效：** 注入该记录优于不注入，需要新任务上的对照；源动作验证不能直接推出。
3. **提交新记忆版本总体有益：** 新规则/经历组合优于当前版本，需要对目标任务分布定义和检验；个别任务获救、适用条件写得合理或hidden-state变化不能直接推出。

同样，来源ID、证据文本、可恢复执行轨迹、独立结果验证是不同层级。文献已有其中若干层级，并不意味着我们只补一个哈希或字段就有论文贡献。

## 6. 与E3失败的直接连接

E3主方法50.83%，相对stored为-0.166个百分点、independent为+0.066、uniform为+0.532，均未达开发筛查阈值；全部六方法也低于固定ZZ的52.66%。rendered与unpacked最后选择完全相同。ON虽在测试点估计最高，但开发数据没有支持它，96次选择均未最终选择ON。

因此本轮不支持把故事改写成“只需更好的语义表示/更聪明的RL就能找到ON”。16种顺序不是16份独立数据，ON不是预先已知最优真值，既有94题不能继续承担新方法的独立确认。

导出表没有当前回答的完整推理正文，每题只有两次回答，也未建立某条规则的已验证致错机制。题12004中ON相对OO占优却未超过ZZ；题12200中ON更差。后续必须先取得实际注入的规则/经历及来源映射，才有资格把某次差异归因为规则越界或经历修复，不能倒推具体因果解释。

## 7. 两个可检验差异

### H1：版本差分是否提供单版本边界卡之外的验证信息

**问题。** 固定新规则、模型、经历池和总验证预算，向验证任务构造/排序器额外提供旧规则及其差分，是否更容易找出该更新真正改善或损害的任务，并把这一信息迁移到未见过的规则更新？

候选输入应是可审计的旧/新规则、增加/删除的前提或例外、关联源经历；验证对象是旧/新**记忆版本**的配对任务收益，而非FAME的表征漂移或CounterMem的源动作局部收益。单纯给新规则生成反例已经不新。

必要对照：

1. 只看新规则的MemAdapter式边界卡和CounterMem式look-alike题。
2. 只看来源经历的相似任务选择，以及同预算均匀/分层任务选择。
3. 给出旧新差分的候选；另做隐藏差分、仅等长附加文本的消融，排除额外token/推理量因素。

按源任务家族和规则更新拆分开发/独立评估，不能让同一条规则的改写版本跨集合泄漏。所有方法共用基础模型、冻结检索/打包协议、验收规则和总成本上限。定向题用于发现机制/排序，不可直接当作目标总体的无偏证据；保留独立随机审计及最终未见测试。主代理负责具体采样/估计/验收理论，本文不另造bandit。

**可证伪指标。** 同成本下发现真实新旧差异的比例、对未见更新的损害定位能力、独立审计下的净准确率和误提交率。若优势仅在自己生成的反例中成立、换规则家族即消失，或单版本边界对照相当，则不支持“差分带来额外信息”。新增的出题、验证和拒绝候选成本必须计入。

**新颖性状态：HOLD，高重合风险。** 与SkillSmith受影响组件回归、CounterMem条件反例和MemAdapter任务空间构造都很近。仅把它们接起来并不是差异；需要证明这里的额外输入信息确有不可由单版本方法解释的增量。

### H2：源经历绑定是否对抽象退化具有特异保护作用

**问题。** 某规则在更新中丢失前提/例外后，回看它真正来源的经历，是否比同样相关但非来源的经历更能恢复正确边界？

这首先是机制研究，不预设要设计一个新记忆架构。对每个可追溯规则采用旧/新两个版本，分别搭配真实源经历、非源但任务相关且token预算匹配的经历、无经历。另保留规则/经历都没有的ZZ和episodic-only。对同一源文本集合，可再置换规则到证据的绑定，分开检验“证据内容有用”和“绑定关系有用”。

核心对比是下面的交互，而非“加原始经历比不加好”：

`I = (新规则+源经历 - 新规则+匹配非源经历) - (旧规则+源经历 - 旧规则+匹配非源经历)`

各项是独立任务与足够重复下的平均任务得分。自然产生的规则更新与人为删除前提的受控更新分开报告，不能只挑已知受害题；匹配/抽样不读取最终测试标签。题目难度、证据长度、格式和位置尽量保持一致，不能把更完整答案泄漏当成来源绑定收益。

**可证伪预测。** 若新规则确实丢失适用条件，应出现可重复的正交互及域外误用减少；若匹配非源经历同样有效、置换绑定不影响结果，或episodic-only已同成本解决问题，则“源绑定机制”没有独立增量，退回普通经验检索解释。

**新颖性状态：HOLD，仅机制假设。** Faulty Memories已经比较episodic/abstract并拆分重写伤害，CounterMem已有源证据，SkillSmith已有交互估计。可能剩余的是“来源特异性×规则更新”的识别和迁移证据，绝不是保留原文、增加citation ID或发明另一种卡片。后续仍需针对provenance/experience-abstraction研究继续查重。

## 8. R2/R3交接与停止条件

- **R1已完成：** 四个历史引用身份/关键方法重核；四个追加近邻精读；CMI/MemRL补位；重合矩阵和两个可证伪假设。
- **R2待主代理组织：** 由独立研究角色反驳H1是否只是CounterMem/MemAdapter的组合，并核查变更驱动测试选择；另审H2是否已被provenance和抽象退化研究覆盖。不能以本轮“未见”作为新颖性证明。
- **R3待主代理组织：** 在不写实现的前提下收敛研究问题、独立数据与成本可行性，确定一个主假设或停止。任何新增实验证据需求都先明确所需轨迹、可执行检查器与真实预算。
- **停止/降级：** 没有可恢复源经历则不做H2因果归因；找不到单版本强对照之外的增量则不做H1新方法；真实总成本被episodic-only/ZZ或现有方法支配则不扩GPU；只剩embedding/GP/RL替换则否决该方向。

最终立场：**可以继续研究E3暴露的信息不足，但“适用域＋证据＋反事实＋局部选择”已不是空白。此轮完成的是缩窄问题和排除宽泛创新宣称，不是确认找到无人做过的方法。**
