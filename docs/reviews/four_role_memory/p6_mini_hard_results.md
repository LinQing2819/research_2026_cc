# P6-mini hard-v2开发性小试结果

## 结论

本轮完整执行并回收了3道题、每题8个记忆子集的24份正式回答。前两道题的8个子集全部答对，仍然存在天花板效应；第三道预备微积分题只有`BC`子集答对，其余7个子集均未得到正确的最终答案。

这是第一轮出现的**同题内记忆条件差异**，但还不能解释为稳定的跨角色语义协同。`BC`中的B是无关四面体题的E-，C是无关矩阵题的R，正确回答没有显式使用两者内容。更稳妥的解释是：不同记忆上下文改变了生成轨迹，只有`BC`在固定1,536-token输出预算内完成了正确推理和最终答案。

## 第三题的错误类型

第三题的8个子集不是7次同一种数学错误：

| 子集 | 结果 | 结束原因 | 最终答案 |
|---|---|---|---|
| 空集 | 错 | `length` | 未输出 |
| A | 错 | `length` | 未输出 |
| B | 错 | `length` | 未输出 |
| C | 错 | `stop` | `1` |
| AB | 错 | `length` | 未输出 |
| AC | 错 | `length` | 未输出 |
| BC | 对 | `stop` | `\sqrt{2}` |
| ABC | 错 | `length` | 未输出 |

`ABC`在截断前已经推导出两个有效分量`1`和`\sqrt{2}-1`，但尚未输出求和与`\boxed{}`。因此，`ABC=0`及对应的三项残差`-1`明显受到输出预算截断影响，不能直接解释为加入A后产生了真实的负向三阶交互。

## 可以与不能说明的内容

可以说明：

1. 更难题目打破了第一轮24个常数1标签的完全天花板；
2. 在冻结prompt、模型、随机种子和输出预算下，第三题的不同记忆子集产生了不同的可观测结果；
3. `BC`是唯一在预算内完成并输出正确最终答案的条件；
4. 当前prompt存在明显的冗长生成与截断问题，输出完成性已成为结果组成部分。

不能说明：

1. E-与R已经形成可复现的语义协同；
2. `IBC=+1`可以推广到其他题目；
3. `ABC`中的A具有真实负效应；
4. 当前3题、每个子集1次的数据足以训练或评估P7选择器；
5. 正式P6、dense召回或人工准入库已经完成。

## 下一步决策

不在当前24个标签上训练P7。若继续验证，应建立新的独立冻结批次，并在执行前解决两个问题：
