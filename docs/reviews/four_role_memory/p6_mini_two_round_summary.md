## 两轮分别说明什么

### 第一轮

三道题的空集和所有记忆条件均正确，24个标签全部为1。该轮验证了服务器执行、持久账本、恢复、导出和评分闭环，但没有产生记忆选择信号。

### hard-v2

前两道题仍然全部正确。第三道题打破天花板，只有`BC`输出正确答案`\sqrt{2}`；另外6个子集因达到1,536-token上限而没有输出最终答案，`C`则完成回答但错误地输出`1`。

hard-v2产生了同题内条件差异，但B和C内容与目标题并不相关，且结果明显受到输出截断影响。因此，当前只能把它记录为生成条件差异，不能声称已经证明E-与R的语义协同。

## 汇总边界

两轮可以合并汇报工程工作量和描述性结果，但不能合并伪装成一次预先冻结的6题确认实验，原因是：

1. hard-v2是在观察到第一轮天花板之后，按预先标注难度另行冻结的第二批题；
2. 两轮具有不同执行身份和独立预算账本；
3. 每个子集仍只有一次解码，没有重复测量；
4. 候选来自`lexical_diagnostic`，内容仍为`pending_human_review`；
5. 当前结果不授权P7训练。

准确限定仍然是：

```text
NOT_FORMAL_P6; NOT_DENSE_RETRIEVAL;
NOT_HUMAN_ADMITTED_LIBRARY; DESCRIPTIVE_ONLY
```
