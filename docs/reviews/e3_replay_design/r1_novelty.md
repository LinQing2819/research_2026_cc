# 第一轮：新颖性、问题价值与替代解释

日期：2026-10-26。评审者：本会话主代理。
这是三轮中的第一次书面审查，不是外部独立审稿意见。
对象：前一轮对话的“组件级记忆更新与验收”P0，及本轮修订P1/P2。

## 判定

| 版本 | 判定 | 核心理由 |
|---|---|---|
| P0：四组合比较＋部分提交＋统计验收 | **FAIL_METHOD_NOVELTY** | 更多动作没有带来新的推断方法；普通全组合选择可复现 |
| P1：再加入交互图、贝叶斯估计、失败记录 | **FAIL_METHOD_NOVELTY** | SkillSmith v2已有高度相近的机制，堆模块不形成增量 |
| P2：结构失配下的主动组件版本选择 | **HOLD_METHOD_CLAIM；可继续审可行性** | 具体问题可证伪，但相对已有低秩bandit/二阶估计尚未定义明确算法增量 |

第一轮没有给“可投稿方法”或新生成实验PASS。
允许把P2交给第二、三轮审查，以判断是否值得进行零生成离线研究，
并不把“可继续审查”写成已通过新颖性。

## 1. 当前结果为什么不够支撑简单方案

E2的ON高于OO/NN/ZE，但三个同时区间都跨零；ON相对ZZ的差值是描述性的4.79pp。
S/F均选OO，D_F精确为0。现有数据没有证明可部署选择器增益。

混搭好也不能直接证明交互。例如：

`OO=.50, ON=.60, NO=.40, NN=.50`，

ON最好，但 `I=.50-.40-.60+.50=0`。
这只是经历更新有益、规则更新有害的可加情形。
更不能因为打上“部分提交”的名字，就把这个固定选择提升为新算法。

E2的dev/test反转可以来自题目组成、解码随机性等，
尚不支持对稳定性破坏、分布漂移或通用错误接受机制的归因。

## 2. 一手文献约束

### Faulty Memories v2

本会话已读§5、§7与附录L.3，固定版本：
<https://arxiv.org/html/2605.12978v2>。

§5明确“fast episodic store / slow schema-forming store”，
比较Auto、Force、Episodic Management Only；
§7提出selective、delayed、grounded in recoverable trajectories的抽象。
因此保留经历、延迟规则、分组件存储本身不能作为新贡献。

### PACE v1

已读§4、§6：
<https://arxiv.org/html/2606.08106v1>。

候选与incumbent的配对anytime-valid验收已有；论文明确per-candidate、
非全运行保证，且dev覆盖限制仍在。把同一个门控接到ExpeL不自动产生创新。
“低功效时少接受”的代价也已有讨论，不能把谨慎拒绝本身当收益。

### SkillSmith v2：本轮最重要的补充核对

<https://arxiv.org/html/2606.01314v2>，2026-09-26版本。
必须用arXiv编号区分同名的其他SkillSmith论文。
本轮读取§1–3.2及定向抽取§3.2、3.3、3.5、3.6、§5、附录A.3/A.6。

已包含：

- 组件效用取决于共同出现的其他组件；
- 随机mask、二阶效用与Bayesian working posterior；
- 以版本为作用域的nogoods、作用域变化时失效；
- delta debugging、反事实检查、候选验收；
- 上下文与迭代双预算，所有诊断/最小化测试计费。

其§5明确限制：稀疏交互暴露、适应性演化下后验校准、改变任务分布的迁移。
附录A.3的识别依赖固定窗口内stationary/homogeneous二阶效应与正暴露；
A.6的veto soundness依赖version-scoped failure persistence。

不能把论文理论仅在这些条件下成立误述成“实验证明方法必然失败”；
也不能把它缩减成只会整库更新。本文没有复现其整个系统或所有基准。

### 低秩bandit

<https://arxiv.org/html/2402.15739v1>，
Low-Rank Bandits via Tight Two-to-Infinity Singular Subspace Recovery。
本轮读摘要、§1–3，包括two-phase spectral estimation、
misspecified linear bandits、best policy identification与incoherence要求。

<https://arxiv.org/html/2210.00340v3/>，
Speed Up the Cold-Start Learning in Two-Sided Bandits with Many Arms。
读取检索返回的摘要和引言；没有宣称完成全文或复现。

这两条研究线已覆盖“把两个组成因素放成矩阵，低秩估计后缩小搜索范围”。
模型矩阵名称、换成LLM记忆或增加贝叶斯探索不足以主张新的算法原理。

## 3. 对P2的最强反驳

P2包含版本表、结构估计、主动搜索、随机探索、独立验收：
这些逐一已有常规来源。若最后相当于
`generic low-rank bandit + sample split + PACE`，
方法论增量仍不成立，即使比最弱的NN基线好。

特别危险的实验设计：

1. P2有25个候选，基线只有OO/NN，把动作集合扩大当成算法优势；
2. 只对P2开放缓存/更多dev/既有错误信息；
3. 用大规模全表预计算，再把读取表格算作“无需模型调用”；
4. 把最差新版、最好旧版事后选为实验端点；
5. 从当前已看过的E2题集拆出一个“新test”；
6. 数据无结构时换更大模型/更多模块，直到出现收益。

这些均应直接否决。

## 4. 仍可能值得研究的内容

P2可以形成一个有价值的研究问题，但需补证：

- **实证结构问题**：版本间效果能否在未测组合、独立题和独立历史间迁移？
  是否有使低秩/加性推断系统性出错的检索/packing变化？
- **实用算法问题**：在相同C_h和总成本下，记忆特有的结构校验/评估分配
  是否优于通用低秩模型及不共享结构的直接搜索？
- **失败边界问题**：结构指导何时节省成本，何时因失配或最终验收变得不划算？

如果只能回答第一/第三项，可以考虑严谨的测量研究；
不能把它冒称为已经有新方法，也不能保证测量本身足够投稿。

## 5. 修改要求与传递给R2/R3的问题

P2保留多版本矩阵及结构失配作为问题对象，但必须：

1. 明确模型预测只是提议，不是验收证据；
2. 保留ZZ、纯经历、固定混搭及相同候选的强搜索基线；
3. 分离固定题集解码不确定性、新题泛化和新构建历史；
4. 说明如何发现漏掉的好/坏组合，承认无法无假设保证全面发现；
5. 给出包含构建、多个选择器、校准、test的完整成本；
6. 没有明确算法增量时继续HOLD，不用复杂性换取PASS。

**R1结论：P0/P1否决，P2值得进一步进行有边界的离线审查；
目前尚不足以支持新方法实现和新一轮模型实验。**
