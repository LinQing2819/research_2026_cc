### 六对比与覆盖率

按 `(OO, ON, NO, NN, ZE, RZ, ZZ)`，新的主族为：

```text
C1   = (-1, 1,  0,  0,  0, 0, 0)
C2   = ( 0, 1,  0, -1,  0, 0, 0)
C3   = ( 0, 1,  0,  0, -1, 0, 0)
I    = ( 1,-1, -1,  1,  0, 0, 0)
D_F  = e_S - e_F
D_ON = e_S - e_ON
```

此修订将原 G1 的三个必要对照直接登记，不改变 G1 要回答的问题。
依据 V4 L3、L146-L147 的“尚无任何新实验回答”声明，它是结果产生前的协议修订，
不是看过效果后挑窄区间；原 R2 的旧六对比建议不必与新族合并成十二项。
这一时间顺序是本次评审接受的前提，本轮未读取运行产物独立审计该声明。
新族此后冻结，不能再据 smoke/dev/test 效果换族。

给定条件信息，对任一非零系数向量，令 `s=sum_a c_a^2`。
估计量中每个独立请求的区间长度为 `|c_a|/(2*n)`，
长度平方和为 `s/(2*n)`，因此：

```text
P(|theta_hat-theta| >= h | C) <= 2*exp(-4*n*h^2/s)
h^2 = s*log(240)/(4*n)
单对比失败概率 <= 1/120 = 0.05/6
六对比任一失覆盖概率 <= 0.05
```

公式正确，不要求六对比彼此独立；共享 ON 或共享所选臂不会破坏 union bound。
按系数真实值域截断仍保留覆盖率。S=F 或 S=ON 时相应系数为零，
必须直接输出 `[0,0]`，不能另生成策略回答或称其“精度不足”。

`a=NO-OO=-C2-I`、`b=ON-OO=C1` 的恒等式正确。
若报告 a 的推断区间，应从同一覆盖事件得到：

```text
CI(a) = [-U_C2-U_I, -L_C2-L_I] intersect [-1,1]
CI(b) = CI(C1)
```

不能给 a 另算一个未经增补错误率预算的直接 Hoeffding 区间，
再将它冒充现有六对比同时保证的一部分。

### 判据没有降低

当前主 GO 仍是 `L_C1>0.03 AND L_C2>0.03 AND L_C3>0.03`。
任一 `U_Ck<0.03` 只否决当前固定 ON 在该目标上的三项联合要求；
不是所有混合策略无效，也不必然意味着负效应。等于边界时不满足该严格判据；
若没有其他必要项触发 NO-GO，则归 INCONCLUSIVE。

原 G2 的强选择器主张已经撤回，而不是用两个较弱辅助对比判其通过。
D_F/D_ON 现在各自只支持本次实现出来的指定差值，不构成通用选择器 GO。
固定 ON 对 ZE 的比较固定了 E 新，只排除这一匹配纯经历控制对该增益的解释；
不能挪给 NO，也不自动分解规则语义、长度或自然在线更新机制。

### 方差、功效与预算

两次独立同分布 Bernoulli 解码有
`E[(Y_1-Y_2)^2]=2*p*(1-p)`，
故 V4 的 `sum c_a^2*(Y_ia1-Y_ia2)^2/(4*n^2)` 确为条件解码方差的无偏估计。
逐题差值样本方差包含题间异质性，不能当作同一固定 T 的纯解码方差。
低观察方差或两次回答相同均不允许收窄预登记主区间。

普通非零差值 `s=2`，I 的 `s=4`；n=96、r=2 下半宽约 0.169 / 0.239 正确。
排除题后须按实际 n 重算，不能沿用这两个展示值。
约 7300 题是给定真效应 0.06、门槛 0.03 时，普通差值边际 80% 功效的保守充分规模，
既不是三项主 GO 的联合 80% 功效，也不是信息论必要样本量。
该限制已充分公开，不构成否决大效应 discovery 的理由。

预算算术闭合：`7*160*2=2240`，smoke 不另加 56；
`2240+2+44=2286`。单请求可重试两次不意味着每个请求都获赠两次预算，
仍同时受全局储备、总提交上限与持久化账本约束。
共享 dev 行在两种 selector 的各自成本计算中均按其读取成本计入，
不能把另一策略已生成的数据算成免费标签；物理生成总账与策略选择账分别报告。
