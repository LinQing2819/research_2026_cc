# 第二轮：可识别性、证据复用、推断与功效

日期：2026-10-26。评审者：本会话主代理。
对象：P2“结构失配下的主动组件版本选择”，承接R1的新颖性HOLD。
本轮没有模型调用；数值均为公式计算，不是新实验。

## 判定

**FAIL_FOR_CURRENT_REAL_EXPERIMENT**：尚无可冻结的真实实验设计、功效与采集规则。
修订后的“结构仅提议、独立数据直接验收”逻辑在下述条件下成立；
可做零生成分析，不等于目前的算法/采样/保证已完整。
R2的数学可修正不解除R1的新颖性问题。

## 1. 不可识别的“省钱保证”

设算法只观测矩阵的子集Ω，未观测格c。
构造两个环境，它们在Ω上的完整观测分布完全相同，
但环境A中c效用高于当前候选，环境B中c低于当前候选。
算法只看到Ω时无法区分两者。

这证明：没有额外结构/暴露条件，不可能同时保证不漏最佳组合及跳过未测格。
这只是标准不可区分性反例，不是新信息论成果。

“低秩”本身也不足够。一块只有单格非零的交互矩阵仍为rank-1，
但违反常见的不相干/广泛暴露要求。它可以恰好出现在未测格。
若16个未测格里只有1个异常，均匀无放回检查4格，漏掉概率为12/16＝75%，
甚至假设测到就能无误识别；有解码噪声时并不会更容易。

因此“随机抽查没发现问题→整个矩阵结构已验证”必须删除。
随机探索只能增加发现概率，有限样本不能自动给未观测格发合格证。

## 2. 从E2不能推出低秩或真实交互

2×2的四个均值可被截距、规则主效应、经历主效应、一个交互完全表示。
一个拟合良好的2×2模型没有压缩/泛化意义。
E2的七臂也不是完整3×3（空、旧、新）表，缺少旧规则-only和旧经历-only。

现有I=-9.04pp、同时区间[-33.19,+15.10]pp，符号仍不确定。
不应将其设为新仿真唯一的“真实交互”或当新理论成立的实证依据。
数值仿真必须至少覆盖：

- 加性且固定混搭最好；
- 平滑rank-1交互；
- rank-1单格尖峰；
- 稠密、非低秩交互；
- 题组效应相反、dev/test题组比例变化；
- 无效应及全部含记忆配置差于ZZ；
- 高解码噪声、版本相同、成本悬殊。

只展示满足自己模型假设的仿真不算过审。

## 3. 修订后的推断合同

### 分开三种对象

1. 旧E2：条件于该固定题集与历史的新解码均值，原区间保持原样。
2. 新题性能：给定某条历史h，目标为独立目标题分布D_h上的平均正确率。
3. 跨历史效果：还要对记忆构建过程随机性或明确有限历史集合取平均。

多次解码、同一批题置换、同一日志取多个快照都不能冒充独立构建历史。
多个历史共用测试题会形成交叉相关，不能简单把H×n行当iid。

### 分开数据与用途

- B：构建流，只供记忆学习；
- S：搜索/拟合/模型选择数据；
- V：候选与对照冻结后的直接验收数据；
- T：最终评估，评估通过验收后的完整策略，包括未通过时的回退。

用T挑排名、阈值、候选、是否发布或是否给某个历史追加预算均不允许。
不同history、不同方法之间可共享预先记录的相同结果用于公平对比，
但统计需保留共享结构，不能算成新的独立回答。

S可以自适应使用，但S上的排名分数不具有自动的泛化覆盖保证。
V上决定继续改候选时，旧V不再是新候选的独立验收集。
第一阶段固定一个候选、一个验收终点，禁止失败后循环寻找下一候选复用同一V；
如要候选流，则另设计fresh blocks或有效的适应性数据使用机制和风险分配。

## 4. 一条成立但不新、也未必负担得起的验收界

给定S和已冻结的候选c、对照b，V中的m道题独立来自D_h。
每题运行完整配置，定义
`D_i = mean_r Y_i,c,r - mean_r Y_i,b,r ∈ [-1,1]`。
各题之间独立；题内配对/重复可以相关，按整题作为单位。

固定m，J个预定参考比较，单侧总错误率α，
Hoeffding＋union bound给出：

`LCB_b = mean_i D_i - sqrt(2 log(J/α) / m)`。

候选只有在全部预定LCB_b超过δ时才宣称该次平均收益通过。
取J=2（当前配置与ZZ）、α=.05时：

| 独立题m | 单侧扣除量 |
|---:|---:|
| 64 | 33.95pp |
| 128 | 24.01pp |
| 256 | 16.98pp |
| 512 | 12.00pp |
| 1024 | 8.49pp |

若**观测**差值8pp、门槛3pp，该保守界至少要2952题才能让下界超过门槛；
若观测差值6pp则至少8198题。这里只是代入观测差值的界宽计算，
不是80%功效保证，更不是所有统计方法的必需样本量。

更精细的方差自适应/配对方法可能明显省样本，但必须在新研究开始前选定、
给出假设和功效评估，不可因为这张表难看就临时换最有利检验。
PACE的discordant-pair单候选控制也不能直接推出绝对3pp增益、
多候选全运行保证或任意数据重用有效性。

该界证明直接验收可以不依赖工作模型正确性；
不证明候选全局最佳、不证明“每道题不受损”、不证明未来分布安全。
ZZ也只是基线配置，不是已知安全真值。

## 5. 新颖性与统计的交叉问题

若为保证安全，最后总要独立大样本直接测量，
搜索阶段省下的几百个请求可能被验收成本淹没。
必须把搜索与验收的总成本一起比较，不能把“模型拟合只用少量点”称为系统省钱。

候选选择与效果确认分开是标准样本分割，不是本项目的新理论。
工作模型/贝叶斯后验的不确定性不能当上述频率学下界；
模型失配时这种替换尤其容易造成错误接受。

## 6. 主评价目标需要提前唯一确定

候选目标A：相同总选择成本下，最终独立test的策略准确率优于强基线；
候选目标B：在预定非劣界内，达到同样准确率所需总成本更低。
两者不能在结果出来后择优。

对齐内容应包括：

- 相同候选集合及公共输入；
- 相同搜索＋验收预算，成本以预留tokens为硬上限；
- 固定策略零搜索成本；
- 相同最终test与评分，保留方法间配对结构；
- 多基线/多个预算点的主次划分与多重性控制；
- 平均效果、每历史效果、拒绝率、错过收益同时报告。

保留全部方法挑出的候选到T并报告分数可比较实际策略；
把T上噪声最大的配置当真oracle会引入winner's curse，不能据此声称无偏simple regret。

## 7. 数据隔离与停止条件

E2及已看过的E0结果全部属于开发材料。改变题目顺序或重新取相同题的答案
不能恢复确认独立性。新阶段需要语义题组隔离的真实新构建/评估划分。
不能保证整个预训练过程未见这些题，只能声明本研究流程隔离。

停止条件：

- 现有数据不足以识别所需结构，且新增数据成本不可承担；
- 结构模型在留出的组合/独立题上不比无结构基线好；
- 模型获得排名优势，但直接验收后策略收益/总成本优势消失；
- 只能通过选后分组、删题、增加重复或改检验取得正结果。

**R2结论：P2已经有可审查的统计边界，但真实执行合同未完成；
当前批准零生成的反例、功效和已有数据分析，不批准新模型实验或方法有效性声明。**
