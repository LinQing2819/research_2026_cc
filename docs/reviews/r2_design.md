## 核心结论

**R2 = FAIL，待必要修订后重审；不放行编码。**

不是因为尚无显著结果，也不要求 pilot 先证明方法有效。V3 已正确冻结单条历史、七臂、分组件 packing、dev/test 和解码次数，并放弃旧/新能力主张；但其推断目标、区间、六对比错误率和判据仍未闭合。

必须修改：

1. **固定推断对象。** 主分析只能对“该历史、该 packing、该次 dev 选择、实际合格的固定 test 题集”的新解码期望作推断。不能用逐题 bootstrap 宣称它是有限固定题集的解码区间，也不能外推 query 总体或构建历史总体。
2. **登记一个六对比的同时区间方案。** 下文给出固定样本、有限样本有效的方案及证明，`alpha=0.05`，不复用旧 H3 weighted CS。相同所选臂必须代数消去，不能重新采样制造“选择收益”。
3. **拆开机制与策略结论。** 胜过 dev 完整 selector 不等于胜过两个完整端点；选中 ON 时相对固定 ON 恒为零；选中 NO 时 ZE 不是匹配的旧经历-only 控制。因此一次总体选择不能证明一般的自适应选择价值或排除所有纯经历解释。
4. **冻结 GO / NO-GO / INCONCLUSIVE。** 保留 `delta=0.03`，不能用点估计超过 delta、未显著逊于对照、或“pilot”身份替代相应同时区间门槛。机制达标不替代 selector 主张达标。
5. **如实登记功效。** 96 题、两次独立解码，在正确率约 0.5 的情景下，普通差值/交互的标准误约 5.1/7.2 个百分点；六对比 Bonferroni 正态近似半宽约 13.5/19.0 个百分点。该预算不支持可靠判定三个百分点增益；可检验大效应，但很可能不确定。
6. **补齐预算和隔离。** 独立 smoke 另需 56 次求解，不能包含在 `7*160*2=2240` 中；test smoke 也须隔离。两个 selector 应锁定合格 dev 的最大可负担前缀、剩余预算与可读标签，不能只说“同预算”。

以下是保持七臂、单历史、dev64/test96、每臂两解码和三个百分点门槛的具体修订方案。其充分明确后可以重审；**本文件不是对尚未修订的 V3 自动转 PASS**。未来 PASS 也只表示值得跑且可证伪，不表示效应、创新或发表资格成立。

## 1. 推断对象与可辨识范围

### 1.1 主目标：条件于实际固定 test

记条件信息为 `C`：历史构建轨迹及已有 E0 分析、两个快照、模型与评分器、最终输入、合格题目清单、dev 结果与已冻结的两个选择。它不包含正式 test 的新回答随机性。

令：

```text
T = 实际合格的固定 test qid 集合
n = |T| <= 96
r = 2
A = (OO, ON, NO, NN, ZE, RZ, ZZ)
Y_iar in {0,1} = 题 i、臂 a、第 r 次新生成的正确性
p_ia = E[Y_iar | C]
mu_a,T = (1/n) sum_i p_ia
S = 组件 selector 在 dev 选出的一个臂
F = 完整 selector 在 dev 选出的一个臂
```

主目标是这些 `mu_a,T` 的对比，概率来自重复整个新解码实验，不来自“把 96 道已固定题重新抽一遍”。需要以下假设：

- 给定最终输入和模型配置，各正式请求的生成随机性相互独立，包含同题跨臂和跨重复；题间正确率无需相同。
- 后端没有跨请求学习、共享回答缓存或未记录的模型切换；随机打散请求顺序不能替代独立性和稳定性假设。
- 评分规则固定且确定。正常完成但格式错误的回答按预定规则计错；后端失败、缺失、重复或指纹不一致不能按普通答错处理，也不能删题凑完整样本。
- 排除题目的规则只依赖生成前的长度等固定信息，所有七臂共同排除；推断分母是排除后的 `n`。它不代表原始 96 题或所有 Engineering 题。
- 正式 test 使用未用于 smoke 的随机流。登记独立随机主种子及运行阶段命名空间；推断不再额外条件于所有未来随机数的具体实现值。哈希派生 seed 本身不是后端独立性的证明。

若这些条件不成立，下文保证失效，不能事后改用题目 bootstrap 补救。完整性失败属于数据不合格；不能只保留成功请求继续检验。

`n=0` 时无可定义的 test 均值，判数据不合格；`n=1` 时主区间仍可计算，但题间样本方差记为不适用，不能除以 `n-1`。

历史上看过题目使本轮不能成为独立确认，但不妨碍在协议冻结后、以全新独立解码对上述条件目标给出有效区间。该区间不校正此前选题、选方向的研究者自由度，也不支持总体泛化。

### 1.2 六个预定目标

按上述臂顺序，记 `e_a` 为臂 a 的单位向量。所有目标都是 `theta_j = c_j' mu_T`：

| 目标 | 系数 `c_j` | 含义 |
| --- | --- | --- |
| a | `(-1,0,1,0,0,0,0)` | 旧经历下的规则更新简单效应 |
| b | `(-1,1,0,0,0,0,0)` | 旧规则下的经历更新简单效应 |
| I | `(1,-1,-1,1,0,0,0)` | 正确率加性尺度交互 |
| D_F | `e_S-e_F` | 本次所选组件策略相对本次完整策略 |
| D_Z | `e_S-e_ZE` | 本次所选组件策略相对新经历-only |
| D_ON | `e_S-e_ON` | 本次所选组件策略相对固定 ON |

严格说，a、b 不是对另一因子两水平取平均的 factorial 主效应；后者分别为 `a+I/2`、`b+I/2`。主报告使用“简单效应”，避免混称。

这是受控的冻结 prompt 干预，允许归因于所定义的组件版本切换整体，不能进一步分解为规则语义、检索内容、输入长度或自然在线更新的独立因果机制。E 新是累计池，不是新增经历；I 不是语义兼容性的量表。

### 1.3 本次策略与选择算法不是同一目标

给定 dev，S/F 已固定，因此独立 test 可以评价本次实现出来的两个策略，不需要再因“四选一”对 test 额外罚四倍。

但以下目标不同：

```text
theta_realized = mu_S(dev),T - mu_F(dev),T
theta_algorithm = E_dev[mu_S(dev),T - mu_F(dev),T]
```

本轮区间覆盖前者，不是后者。对前者的条件覆盖率再取 dev 的期望，仍然覆盖随机的 `theta_realized`，不会自动变成对固定 `theta_algorithm` 的覆盖率。不能用一次 dev 的结果声称算法平均选择能力、跨历史收益或稳健的版本自适应。

同样，若 S=NO，本次策略与固定 NO 完全相同；胜过固定 ON 只排除这一条指定基线，不能证明优于所有固定混合策略。

## 2. 可直接实现的主统计方案

### 2.1 估计量与数据复用

```text
Ybar_ia = (Y_ia1 + Y_ia2)/2
D_ij = sum_a c_ja * Ybar_ia
thetahat_j = (1/n) sum_i D_ij
```

先按 qid 配齐七臂和两次重复，再计算差值。所有策略分数引用相应固定臂的同一批 test 行，不额外生成“selector 的回答”。S=F 时 `D_F=0`；S=ON 时 `D_ON=0`，均有精确区间 `[0,0]`。

a、b、I 共享数据；策略对照也可能与它们完全相同。这不是六组独立实验。计算系数向量时先合并同一臂，不能把相同数据当成两次独立测量。

### 2.2 六对比 95% 同时区间

主方案选用固定样本 Hoeffding 区间，保守但完全明确，不依赖正态、iid 题目、bootstrap 或方差估计成功：

```text
alpha = 0.05
K = 6
q = log(2*K/alpha) = log(240)
s_j = sum_a c_ja^2
h_j = sqrt(s_j*q / (2*n*r))

CI_j = [thetahat_j-h_j, thetahat_j+h_j]
       intersect [sum_{c_ja<0} c_ja, sum_{c_ja>0} c_ja]
```

`c_j=0` 时直接输出 `[0,0]`。不因为重复对比或某个零对比事后回收 alpha；非零普通差值 `s_j=2`，交互 `s_j=4`。

**证明。** 条件于 C，估计误差是独立变量 `c_ja Y_iar/(nr)` 的中心化和。各变量区间长度为 `|c_ja|/(nr)`，区间长度平方之和为 `s_j/(nr)`。Hoeffding 给出：

```text
P(|thetahat_j-theta_j| >= h | C)
  <= 2 exp(-2*n*r*h^2/s_j).
```

代入 `h_j` 得单对比失败概率至多 `alpha/6`，再用 union bound 得：

```text
P(六个区间同时覆盖各自目标 | C) >= 0.95.
```

不需要六个对比相互独立。对所有合法 dev 实现条件覆盖成立，故 dev 选择不会破坏这个“本次所选策略”保证。

这是一套完整方案，不再另外挑 Holm、普通 95% CI 或未校正 p 值中较有利者决定 GO。a、b、I 可双向解释，策略收益读取下界，排除 delta 收益读取上界；同一同时区间允许这些判断而无需另分 alpha。

七臂均值可全部报告点估计。RZ/ZZ 不在六对比族中；未经预登记的独立显著性、test 最优臂、子组检验不能借本方案获得保证。任何补充区间都必须明确非主分析，不能改变判定。

### 2.3 从同一覆盖事件得到端点与机制区间

要声称“优于完整快照”，不能只比较 F。利用以下恒等式：

```text
ON - OO = b
ON - NN = -a-I
NO - OO = a
NO - NN = -b-I
ON - ZE = D_Z-D_ON
```

若基础区间为 `[L_x,U_x]`，则：

```text
CI(-a-I) = [-U_a-U_I, -L_a-L_I] intersect [-1,1]
CI(-b-I) = [-U_b-U_I, -L_b-L_I] intersect [-1,1]
CI(D_Z-D_ON) = [L_Z-U_ON, U_Z-L_ON] intersect [-1,1]
```

先做代数消去；例如 S=ON 时最后一项就是 `CI(D_Z)`。某个端点对比等于 D_F 时，将上述区间与 `CI(D_F)` 取交集。所有这些是同一个同时覆盖事件的确定性推论，不是新添几项未校正的独立检验。

代价是组合区间可能明显更宽；例如一般的 `-a-I` 半宽为两项半宽之和。不得为提高 GO 率在看到结果后把这些对比升级成另一套较窄主检验。未来若改为直接检验更多端点对比，应在独立确认前重新登记完整检验族和功效。

## 3. 固定题集与 Query 总体必须分开

### 3.1 固定题集的解码方差

在第 1 节独立性下：

```text
V_dec,j = Var(thetahat_j | C)
        = (1/n^2) sum_i sum_a c_ja^2 * p_ia*(1-p_ia)/r
```

两次重复足以得到一个无偏的解码方差估计：

```text
Vhat_dec,j = (1/(4*n^2))
             sum_i sum_a c_ja^2 * (Y_ia1-Y_ia2)^2.
```

因为 `E[(Y_1-Y_2)^2]=2p(1-p)`。报告它及 `sqrt(Vhat_dec,j)` 用于诊断和下一次研究的敏感性规划；**不把它代入 Wald 区间替代主区间**。两次相同回答不证明该题概率为 0 或 1，零估计方差也不是零不确定性证书。

### 3.2 逐题 bootstrap 实际混入什么

令 `theta_ij=E[D_ij|C]`，`sigma_ij^2=Var(D_ij|C)`。题间样本方差为 `s_D,j^2`，则：

```text
E[s_D,j^2/n | C]
  = V_dec,j
    + sum_i (theta_ij-theta_j)^2 / [n*(n-1)].
```

第二项是固定题集内的效果异质性，不属于本次有限题集均值的解码不确定性。

反例：一半题上的臂差恒为 +1，另一半恒为 -1，所有回答均确定。固定题集平均效应精确为 0，解码方差为 0；逐题重采样仍产生正负波动。因此逐题 bootstrap 不能仅改一个标题就成为正确目标的 CI。这个方差关系也不构成 bootstrap 有限样本覆盖率的保证。

### 3.3 若另要 query superpopulation

需另外定义题目分布 P，并有可辩护的独立代表性抽样以及与 dev/构建的隔离。目标变为：

```text
theta_P,j = E_{Q~P}[sum_a c_ja*p_a(Q)]

Var(D_j(Q))
  = Var_Q(sum_a c_ja*p_a(Q))
    + E_Q[sum_a c_ja^2*p_a(Q)*(1-p_a(Q))/r].
```

此时抽样单位是题目，不是 192 个解码；每题两次重复必须保留在同一个 cluster。可预登记题级 t/cluster bootstrap 作为大样本近似，但不能把它宣称为有限样本精确保证。

若坚持有限样本保证，iid 题目下可直接使用题级 Hoeffding：

```text
h_pop,j = ||c_j||_1 * sqrt(log(240)/(2*n)).
```

它同样控制六对比，且更保守。对随机题目边缘化后，同一题的各臂不是独立 Bernoulli，不能套用第 2 节的请求级宽度。

当前公共后缀的固定置换不凭空产生目标总体 P。随机分割至多可能支持另一个明确登记的有限池抽样目标；它与“条件于实际 T”仍不同，不能混用有限总体修正或任意换分母。本轮不作 query 总体推断。

只有一条历史也不能估计构建流间方差。两个世界可以在当前历史上完全相同，却在所有其他历史上具有相反效应；当前数据无法区分它们。

## 4. 选择器、预算与执行隔离

### 4.1 预算定义应补成算法条款

在任何新回答产生前，先渲染全部候选 prompt、共同排除超长题，得到固定有序合格 dev 清单 `D=(q_1,...,q_m)`，`m<=64`。不从 manifest 后方补题。

```text
A_F = {OO,NN}
A_S = {OO,ON,NO,NN}
t_ia = 实际完整输入 token 数
cost_K(q_i) = 2 * sum_{a in A_K}(t_ia+2048)
B = sum_{i=1}^m cost_F(q_i)
k_K = max{k in {0,...,m}: sum_{i=1}^k cost_K(q_i) <= B}
```

F 使用全部 m 题；S 使用前 `k_S` 题。**首次遇到放不下的题块即停止，不跳过它找后面更便宜的题。** `m=0` 或 `k_S=0` 时选择程序不合格，不能用 test 或默认臂顶替一个声称经过选择的策略。

每个 selector 的每个候选分母严格相同，均为其 `2*k_K`；按正确次数最大化，平局优先 NN、OO、ON、NO。记录两份 qid 清单、逐题成本、累计成本、余额和各候选正确次数。

两者匹配的是同一个可预知的 reserved-token **上限**，不是实际花费严格相等。dev 题数与构成不同是所比较资源受限程序的一部分；结果不能单独归因于“扩大候选集”的纯效应。输入和输出实际 token、时间及固定策略的零选择成本另报。

全部七臂机制数据即使已经物理存在，selector 也只接收其授权投影，尤其不能让 S 读取预算之外 OO/NN 的标签。共享的合法 dev 请求可复用，但两种策略的资源账本各按其独立执行成本收费。

### 4.2 固定 2240 上限的 smoke 修订建议

V3 的独立 smoke 为 `4*7*2=56` 次；若保留它，实际总量为 `2296` 次求解，再加最多 2 次后端探测，而非 `2240+2`。

建议在不增预算的前提下明确改成：

- 取消独立生成式 smoke，尤其取消 test 上的提前 smoke。
- 正式 dev 清单中前 4 个合格 qid 先执行，不足 4 个则取全部，作为工程冒烟批次；它们就是正式 dev 行，只生成一次，不另建第二份回答样本。
- 这批数据在选择时仍遵守各自 qid 预算清单；不能提前据其效果修改快照、packing、评分、任务或选择规则。
- 参数、manifest 和统计协议先冻结；只有工程验收通过才继续剩余 dev。写入并封存选择记录后，才开始正式 test 生成与评分。
- 若批次暴露设计/实现错误，当前运行判无效，提交修订重审，不把它的结果择优拼进新版本。

七臂正式求解上限仍为 2240，生成式探测最多 2 次；排除题使数量减少，不将空余额改分配给更多题或重复。

还须写清重试成本：每个已提交生成请求均记入对应硬上限，含超时但可能已执行的请求。重试只为同一逻辑请求、同一 seed 的传输恢复，不能取多个完成回答中较好者。若固定上限内无法取得完整数据，判数据不合格，不静默增加预算或改变 n。若确需独立重试储备，必须先改预算并重审，不能声称仍是 2240。

## 5. 预定判定树：不得把不同主张合并

以下是建议写入协议的明确合同。所有下界/上界来自第 2 节同一覆盖事件；`delta=0.03` 不下调，等于边界时归入不确定。

### 5.1 先验收干预与数据

导入、时序隔离、因子不变性、模板/评分/指纹、预算授权、完整性任一失败，先输出“干预无效/数据不合格”，不作效应判定。

另报告最终 prompt 中规则版本变化题数、经历版本变化题数、两者同时变化题数。某因子所有题都无实际变化时，对应版本机制不可检验；两因子从未在同一题同时变化时，I 在本干预定义下结构性为零。不能重挑快照、题目或删去无变化题以放大效果。

合法的长度排除本身不等于数据错误，但必须同时报告 dev/test 的原始分母、实际分母、覆盖率和目标缩窄。不能继续使用名义 n=96 的区间。

### 5.2 GO：两种不同的“有希望”

**G1，旧规则与新经历的机制证据。** 同时满足：

```text
L(ON-OO) > delta
L(ON-NN) > delta
L(ON-ZE) > delta
```

用第 2.3 节的 `b`、`-a-I`、`D_Z-D_ON` 判定。这检验预先指定的固定 ON 是否超出两个完整端点和同 E 新的规则缺失控制，无需先要求 S=ON。

允许结论：“当前固定题集上，旧规则+新经历的组合有超过预定门槛的条件机制证据，值得设计独立确认。”**不允许结论：“selector 增益成立”。** 即使 G1 成立，固定 ON 已解释结果时，也不能将其包装成选择算法贡献；若研究只接受方法主张而不接受机制发现，G1 不能算该主张 GO。

**G2，本次所选策略的指定对照证据。** 同时满足：

```text
S in {ON,NO}
L(D_F)  > delta
L(D_Z)  > delta
L(D_ON) > delta
L(S-OO) > delta
L(S-NN) > delta
```

所有要求均为交集，不以“其中一项显著”代替。端点要求防止 F 恰好选错被误称为完整快照能力上限。

S=ON 时 G2 不可能成立，这是对固定 ON 排他要求的正确后果。S=NO 时可以成立，但它只表示本次 NO 胜过指定的完整策略、两个端点、新经历-only 和 ON；**仍未排除旧经历-only，也未证明超出固定 NO 的选择价值**。

因此 G2 不足以宣称“排除所有纯经历解释、证明通用 selector 优势”。保持七臂时必须收窄为上述指定对照结论；若坚持更强主张，本轮设计不支持，不能靠统计显著补齐缺少的控制。独立确认须补匹配的旧经历-only 对照及跨实例选择评价，不能回头给本轮加臂追结果。

G1/G2 的达标只是不同范围的 discovery GO；必须逐项标注，不允许以 G1 替代 G2 的失败，也不允许任一 GO 被写成发表或效应泛化 PASS。若主代理不接受这种目标拆分，应先修改研究目标，而不是保留模糊的单个“有希望”标签。

### 5.3 NO-GO：只能停止被区间排除的主张

- 对“相对 B 有至少 delta 的增益”，只有 `U(S-B)<delta` 才能排除；`U<0` 才进一步支持负效应。未显著为正不能代替上述任一结论。
- G1 或 G2 任一必要效应的上界小于 delta，就否决该组条件在当前目标上的 delta 级达标；写明是哪一项，不能推广成所有混合策略无效。
- S=ON 时 `D_ON=[0,0]`，因此相对固定 ON 的额外增益直接 NO-GO；它不是估计精度不足。
- S 为 OO 或 NN 时，G2 的混合版本条件直接不成立，且相对自身端点的差精确为零；本次混合选择主张 NO-GO，但仍单独评价固定 ON 的 G1。
- “固定 ON 足以解释收益”至少要区分完全同一策略和 `U(D_ON)<delta` 的近似无额外重要收益，不能用 `p>0.05` 宣称等效。
- 对无方向的交互，区间排除 0 才是符号证据；若将 0.03 同时登记为交互重要性门槛，只有 CI 完全落在 `(-0.03,0.03)` 内才排除这一量级的交互。无显著 I 不等于无交互。

### 5.4 INCONCLUSIVE 与后续研究

质量合格但既未达到相应 GO、也未排除相应 delta 级目标，则输出“不确定”。例如点估计大于 delta 但下界不超过 delta，仍不能 GO；区间跨 0/delta 时不能用“方向一致”补票。

必须交付六个估计与同时 CI、实际分母、两种方差口径、选择清单与预算、干预变化率、各判据状态及一次独立确认的成本设计。不得继续增加本轮题目、重复或变更任务/时点；固定样本区间不支持效果驱动的可选停止。

不确定只授权设计一次独立确认，不自动授权执行，更不是靠“pilot”身份降低标准后的 PASS。若能负担的确认规模仍不足以回答 delta 级问题，应明确不可行并停止该精度主张。

## 6. Pilot 功效与确认规模

### 6.1 在当前预算下有多宽

以下是 n=96、r=2、各臂正确率约 0.5、独立解码的噪声情景。普通差值指非零的 a、b、D_F、D_Z、D_ON；S 与基线相同时不适用。

```text
Var(thetahat_j | C) <= s_j/(4*n*r)
z_(1-alpha/(2*6)) = z_0.995833... ≈ 2.638
z_0.8 ≈ 0.842
```

| 项目 | 普通差值 | I |
| --- | ---: | ---: |
| 解码标准误上界情景 | 0.0510 | 0.0722 |
| Bonferroni 正态近似半宽，仅作功效参考 | 0.1346 | 0.1904 |
| 本评审主 Hoeffding 区间半宽 | 0.1690 | 0.2389 |
| 正态检验近似 80% 功效，拒绝零所需真效应 | 0.1776 | 0.2511 |
| 主区间判正、以正态噪声近似 80% 功效所需真效应 | 0.2119 | 0.2997 |

后两行不是实际功效保证，也未计算复合 GO 的联合功效。多个必要对照同时达标通常更难；G1 的组合端点区间还会更宽。排除题使以上数值按 `sqrt(96/n)` 放大。

GO 检验的是超过 delta，而非仅超过 0。因此近似功效中的效应应换成“真实效应减 delta”的余量。不能要求在真实效应恰等于 delta 时，以 80% 概率证明它严格超过 delta。

test 信息量是 96 题，不是 dev+test 的 160 题；192 次单臂解码也不是 192 条构建历史。dev 数据不能回填到 test 提升显著性。

选择本身亦很噪：如果 F 用 64 题，S 约用 32 题，在近 0.5 的简单情景下两个候选的 dev 差值标准误约为 0.0625 和 0.0884；3 个百分点的候选差远小于这些误差。S 实际题数须由 token 成本确定，不能将 32 写死。此现象影响选对概率，不破坏给定所选臂的独立 test 区间。

### 6.2 不用“observed power”；登记设计情景

对效应阈值 `delta_0` 和预定备择 `Delta_1>delta_0`，正态近似规划为：

```text
n ≈ v_j * (z_(1-alpha/12)+z_(1-beta))^2
     / (Delta_1-delta_0)^2
```

固定题集解码情景、r=2 时，普通差值的 `v_j<=0.25`，I 的 `v_j<=0.5`。拒绝零、真效应 0.03、边际功效 80% 时，约需 3400 / 6700 题。这仅是噪声情景下的正态规划，不是当前主区间保证；要证明超过 0.03 且真效应为 0.06，余量同样是 0.03。

主 Hoeffding 区间有直接可算的保守充分条件。记 `g=Delta_1-delta_0>0`，则只要：

```text
g >= sqrt(s_j/(2*n*r)) *
     [sqrt(log(12/alpha)) + sqrt(log(1/beta))]
```

就由单尾 Hoeffding 得到至少 `1-beta` 的边际检出概率。等价地：

```text
n >= s_j/(2*r*g^2) *
     [sqrt(log(12/alpha)) + sqrt(log(1/beta))]^2.
```

证明：`L>delta_0` 需要 `thetahat>delta_0+h`；当真效应为 `Delta_1`，未达标概率至多 `exp(-2nr(g-h)^2/s_j)`，再令该上界不超过 beta。

在 `g=0.03`、r=2、beta=0.2 时，充分规模约为 7300 / 14500 题。它是保守充分条件，不是信息论必要样本量，不能据此宣称更高效合法区间都需要同样多样本。若要求 k 个必要事件联合功效至少 80%，可把每项 beta 设为 `0.2/k` 作充分规划；不得将六项各 80% 误称联合 80%。

仅要求当前主区间半宽不超过 0.03，也需普通差值约 3045 题、I 约 6090 题（r=2）。所以当前预算下区间接近零但仍无法排除三个百分点增益，是正常的不确定，不是方法被否决，也不是放宽阈值的理由。

### 6.3 怎样使用 pilot 方差设计一次确认

- 条件于同一固定 T 增加重复：使用解码方差口径，方差约随 `1/r` 缩减；这不能增加 query 或历史泛化。
- 面向新题：采用题级总方差 `s_D^2` 作情景中心，并提供从观察值到保守上界的敏感性范围；不能只用解码方差删掉题间异质性。
- 面向新构建流：必须另加构建流方差情景。本 pilot 只有一条流，不能把未知的流间方差设成零。
- 对独立构建流、每流独立新题的简化嵌套设计，可规划 `Var(mean) ≈ tau_H^2/K + tau_Q^2/(K*n) + nu/(K*n*r)`。若跨流复用题目，需显式处理交叉相关，不能照抄该式。
- 评价 selector 算法时，每流须独立重做 dev 选择；上述流级方差还须包含这种选择随机性，不能把本轮已固定 S 的解码方差当作算法的全部方差。
- 预先列出真效应 0.03/0.06/0.10 等情景及对应“拒绝零”或“超过 delta”目标，不把观察到的最大效应当必然真实值。报告点方差、保守情景、所需题数/流数/调用及 token 预算。
- r=2 的七臂 test 每增加一题需要 14 次求解；新历史构建、dev 选择和后端核验成本另计。若公共未见题数不足，不能通过重复旧题伪装增加总体样本量。

## 7. 防止过度解释的反例

### 7.1 混合优势不要求 I 非零

```text
OO=0.70, ON=0.80, NO=0.60, NN=0.70
a=-0.10, b=0.10, I=0
```

ON 超过两个完整端点，但只是规则更新负效应与经历更新正效应的可加组合。因此不能把显著 I 设为一切混合机制的必要条件，也不能从混合胜出反推非加性交互。

### 7.2 胜过完整 selector 不等于胜过完整端点

```text
OO=0.40, ON=0.70, NO=0.20, NN=0.90, ZE=0.30
```

有限 dev 有非零概率使 F=OO、S=ON。此时真实 `D_F=0.30`，且 ON 胜 ZE，却仍比 NN 差 0.20。所以仅凭 selector-vs-full 不能声称整库快照这个策略类过粗，必须补端点比较或收窄结论。

### 7.3 NO 胜 ZE 不能排除纯经历解释

```text
OO=0.30, ON=0.40, NO=0.80, NN=0.45, ZE_new=0.50
未观测的 ZE_old=0.90
```

NO 胜两个端点、ON 和 ZE_new，但旧经历-only 更好；新规则在旧经历下反而降低 0.10。七臂数据与这个世界相容。保持七臂时只能排除登记的 ZE_new，不能把缺失的 ZE_old 控制写成已经排除。

对 ON，`ON-ZE_new` 固定了 E 新，因此确实是加入旧规则块的受控效应；这个配对解释不能挪给 NO。

### 7.4 选择收益的恒等式失败出口

S=ON 时，本次 selector 就是固定 ON；其均值、逐题分数和 CI 对固定 ON 的差都严格为零。重新为“selector”生成一份答案后得到的非零差只是解码噪声，不是选择价值。

S=NO 时对固定 NO 同理。该实验没有跨题路由或多次独立决策，不能用一个全局臂标签构造一般“自适应”收益。
