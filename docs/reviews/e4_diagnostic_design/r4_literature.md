## 1. 先给裁决

**不再把“尚待发明的关系学习器”保留为唯一算法主线。推荐实质转向：无需新算法的、封顶的测量与低成本预测诊断。** E4-D0 的自然更新对象和有符号差值目标可以保留；“关系表示应胜出”不应继续成为默认叙事。

> 在事先选定的自然更新、未参与构建与拟合的新解题模板上，可重复的题间增量结构有多大；一个不调用 LLM 的双端点探针，是否已经足以降低包含预测开销后的估计方差？

建议单任务 Engineering、五维 CPU 表示和岭回归，不命名新方法。API 退出当前候选，放弃双任务主张；工程稿已纠正反馈缺陷属于 HumanEval，不能继续把它当 API 退出理由。默认零目标更新校准、零全池 LLM 预测；与工程稿保留语义强对照/16题校准的付费方案存在分歧，交 R5 决定，不冒充已统一。

## 3. 四篇真正可借的核心

### 3.1 GBV-PD：借方向性分解，不能把文本差当梯度

**Evolution-Aware Regression Test Prioritization of ML-Enabled Systems using Gradient-Based Behavior Vectors**。作者：Eunho Cho、Donghwan Shin、In-Young Ko。实际版本：`2606.28037v2`，页面标注 2026-08-12。[正文 §3](https://arxiv.org/html/2606.28037v2#S3)。

核心为 \(g_i=\nabla_{\theta[K]}\ell_i,\ v_i=B^\top(g_i-\mu),\ z=B^\top\Delta\theta,\ p_i=v_i^\top z\)，其中 \(B\) 是训练样本梯度的 PCA 基。一阶展开 \(\Delta\ell_i\approx g_i^\top\Delta\theta\)，丢掉跨题共同项 \(\mu^\top\Delta\theta\) 后，\(p_i\) 只是**相对方向排序**，其正负不必等于实际损失变化正负。算法1再结合旧损失排名，不输出准确率差。

**可借：** 难度/方向分离、先查信号再排序、预计算与逐更新成本分账。**不可声称：** 首次逐题增量预测或不全跑新版。其误差界依赖局部可微更新、参数对齐及监督梯度；E4 权重固定而输入变化，文本向量差不是梯度，不能直接移植算法与保证。

本项目代数检查：\(\beta^\top(\phi_n-\phi_o)=f_\beta(q,P_n)-f_\beta(q,P_o)\)，其中 \(f_\beta=a+\beta^\top\phi\)。“编码两端、相减、线性头”与共享线性端点头相减属于同一函数类；不同训练目标可能得到不同系数，但不是新增关系信息。

### 3.2 FAQ：借预测与校正分离，修正保证与迁移口径

**Efficient Evaluation of LLM Performance with Statistical Guarantees**。作者：Skyler Wu、Yash Nair、Emmanuel J. Candès。实际版本：`2601.20251v3`，页面标注 2026-05-08。方法简称 Factorized Active Querying。[正文 §3](https://arxiv.org/html/2601.20251v3#S3)。

原文拟合历史正确性矩阵 \(P(H_{ij}=1)=\sigma(u_i^\top v_j)\)，固定题因子 \(v_j\)，对新模型因子作在线 Laplace 更新。PAI 用预测加逆概率残差：

\[
\hat\theta=\frac1T\sum_{t=1}^T
\left[\frac1N\sum_j\hat p_{t-1,j}
+\frac{z_{I_t}-\hat p_{t-1,I_t}}{Nq_t(I_t)}\right].
\]

策略混合 \(\sqrt{\hat p(1-\hat p)}\) 与针对总体均值的后验方差减少量，保留均匀探索；预测和抽样概率只依赖过去。**可借预测/校正分离，不必借整套主动采集器。**

- 定理3.1的区间是满足 A.1–A.3 时的**渐近**保证，不是小样本精确覆盖或 anytime-valid。
- 原设计**有放回**；附录 B 警告删掉已抽题仍套原估计量会失效，不能直接套给 D0 无放回审计。
- 固定题因子依赖同一题库历史标签；新模型适配不等于新题族迁移。补文本编码器不是忠实原版。
- 固定二值结果不等于随机解码差值；不能把 \(D\in[-1,1]\) 当 Bernoulli 概率代入 \(p(1-p)\)。

### 3.3 CheckList：借测试设计，不虚构官方差值学习器

**Beyond Accuracy: Behavioral Testing of NLP Models with CheckList**。作者：Marco Tulio Ribeiro、Tongshuang Wu、Carlos Guestrin、Sameer Singh。实际读取：`2005.04118v1`；另有旧稿提供的 [ACL 2020 入口](https://aclanthology.org/2020.acl-main.442/)，本轮未重取出版页。[方法 §2](https://arxiv.org/html/2005.04118v1#S2)。

原设计是“能力 × 测试类型”：MFT 用有标签的简单实例隔离能力；INV 对合法保标签输入变换要求预测不变；DIR 检查单调关系或指定标签。模板填充值作笛卡尔积，辅以掩码模型建议与人工筛选。

**可借：** 模板族、合法评分关系、覆盖检查，不必启动出题器。**不可声称：** 原文有 memory-diff 收益学习器或省测保证。“直接 diff+CheckList”是本项目提示适配，非官方算法；自然更新没有默认改善方向，单位转换也未必保持答案字符串。运行适配基线前仍须冻结提示、校准和全池成本。

### 3.4 PACE：借同题比较，不能继承任意复用保证

**PACE: Anytime-Valid Acceptance Tests for Self-Evolving Agents**。作者：ZayxShawn（论文公开署名）。实际版本：`2606.08106v1`；本轮未单独重取提交历史。[方法 §4](https://arxiv.org/html/2606.08106v1#S4)。

非平局中候选独对记 \(w_i=1\)，当前版本独对记0；更新 \(E_i=E_{i-1}[1+\lambda(2w_i-1)]\)，固定 \(\lambda\in[0,1)\)，从1出发，达到 \(1/\alpha\) 接受。Ville 界依赖每步 \(P(w_i=1\mid\mathcal F_{i-1})\le1/2\)，是**单候选条件保证**。

- 全池均值不正不推出定向选题的条件胜率不超过1/2；反复用反馈造候选也可能破坏前提。
- §3 声称 alpha-spending 必须知道总轮数，过强：\(\alpha_t=\alpha/2^t\) 等可求和分配无需固定终点。
- §5 的随机代理用温度0.7、审计用温度0，估计对象不同，不能作为 E4 同分布差值保证的验证。
- 跳过平局只用于该检验，不适用于均值估计；未接受也不是证明无效。

**可借**同题比较、审计隔离和未决处理；D0 不做提交门，不引入 e-process，也不宣称配对消除独立解码噪声。

## 4. 实际值得冻结的廉价探针

输入为题干/完整选项 \(q\) 和每题实际渲染的外部记忆 \(B_o,B_n\)，保留经历选择、顺序、截断；缺真实文本则资格 HOLD，不能替成存储规则列表。字符3–5 gram稳定散列至4096桶，非负计数、L2归一化为 \(E(x)\)，保留大小写/数字/符号，不读答案或身份元数据。令 \(s(q,x)=E(q)^\top E(x)\)，按字符把记忆等分三段，空段相似度为0：

\[
\phi(q,B)=
[s(q,B),s(q,B_{\rm front}),s(q,B_{\rm middle}),
s(q,B_{\rm back}),\log(1+|B|)].
\]

这是表面匹配/位置/长度探针，不是语义、梯度或免测判据。散列规则预定；特征按开发均值/标准差标准化，零方差列置零。拟议固定岭回归：历史等权、历史内题等权的平均平方损失加 \(\lambda\|\beta\|^2\)，\(\lambda=1\)，截距不惩罚；不按旧 test 调参。尚未拟合。

| 探针 | 训练/预测方式 | 解释上限 |
|---|---|---|
| 零值、开发任务常数 | 不读取目标更新标签 | 直接配对均值和共同偏置基线 |
| 仅新版 | 用 \(\phi(q,B_n)\) 回归合法开发配对差值 | 在缺旧参照时能预测多少 |
| 共享端点头 | 用两端的平均正确性共同拟合 \(f=a+\beta^\top\phi\)，输出 \(f_n-f_o\) | 旧端点是否补齐基线 |
| 直接差值头 | 用同一配对标签拟合 \(\beta_D^\top(\phi_n-\phi_o)\)，不另加关系模块 | 同一线性差分函数类的目标适配 |

共享合法标签、预定权重；输出有限实数，不冒充概率或事后裁剪。默认零目标校准；若保留16题，所有方法共同计费，只修截距不能改善中心化残差。

直接配对均值和端点相减必须保留。rawpair LLM、diff+CheckList 是强语义适配对照，未合规纳入就**不能声称胜过强关系表示**，不以弱 CPU 版本偷换。是否购买该比较交 R5；便宜探针失败不证明关系信息不存在，成功也不是新方法。

## 5. 不靠新算法的诊断与成本判据

固定池 \(N\)，均匀无放回抽 \(n\) 题，每版本每题 \(r\) 次独立解码。记 \(\tau_q=p_{n,q}-p_{o,q}\)，\(v_q=p_{n,q}(1-p_{n,q})+p_{o,q}(1-p_{o,q})\)。稳定分布、调用独立且预测审计前锁定时，主代理推导的标准残差校正满足：

\[
\hat\mu_m=\bar m_Q+\overline{(\bar D-m)}_A,\qquad
\operatorname{Var}(\hat\mu_m)=
\frac{1-n/N}{n}S^2_{\tau-m}+\frac{\bar v_Q}{nr}.
\]

有限总体方差分母 \(N-1\)。修正只乘抽题项；即使 \(m=\tau\)，保留残差校正仍有独立解码噪声。真正已知全部 \(\tau\) 的 oracle 可直接算均值，但那不是可部署预测器。固定回答数 \(2nr\) 时噪声项固定，增重复不免费获益。

预测/校准成本使审计由 \(n_0\) 降到 \(n_1\) 时，必须以上式分别代入 \((m,n_1)\) 与 \((0,n_0)\) 比较，不能只看同一批题残差。CPU、构建、校准、全池评分、失败均计成本，不预设短预测与长回答的兑换率。

两组独立解码只作聚合诊断。令 \(R_{q,g}=\bar D_{q,g}-m_q\)：

\[
\widehat V_{\rm cross}(m)=\frac1{n-1}
\sum_{q\in A}(R_{q,1}-\bar R_1)(R_{q,2}-\bar R_2).
\]

两组零均值噪声独立、预测独立于审计时，其期望对应潜在残差方差。报告相对常数/新版/端点的有符号方差差，负估计不截零，不拼省题倍数，不给单题稳定标签。少量留出历史不作普遍迁移显著结论。

旧 test94 的规则对照 `NO-OO` 跨重复协方差约零、`NN-ON` 为负；经历对照为正。这是主代理提供的旧表描述，本轮未复算，且 dev/test 不一致。它提醒我们别默认规则差更可学，**不授权只挑经历更新、ON 或旧赢家**，也不证明规则真实效应方差为零。

顺序：真实更新/渲染与评分资格、同输入控制、重复信号/噪声、CPU探针、完整成本判断。旧表只作开发反证。

## 6. 题族隔离不能抹掉研究对象

| 口径 | 需要隔离的对象 | 可以共享什么 |
|---|---|---|
| 新解题模板迁移 | 同一生成模板、同构解题步骤的换数/改名题、近重复题及同一母题派生题，作为一族放在同侧 | 可共享物理定律、数学概念、API 功能等知识；这正可能是记忆发挥作用的范围 |
| 新知识概念迁移 | 在模板隔离之外，还隔离预先定义的概念/适用条件类别 | 只能共享声明允许的更上层背景；这是更强且未必可行的另一个问题 |

主口径建议为**新历史、新模板，允许知识概念重合**。同模板换数必须合并，但共享概念不自动算泄漏。族划分先于效果标签，按题面/生成来源/解题结构确定；模糊处记录敏感性，预测器不获取审计答案。概念隔离若抹掉记忆适用范围，应判更强目标不可行，不能据域外题证明记忆无用；也不把 FAQ 同题库适配叫新模板迁移。
