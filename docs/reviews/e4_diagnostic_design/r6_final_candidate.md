# R6统一裁决稿：自然更新的可测性与廉价预测诊断

E4-D1，2026-10-28。本文定稿研究设计；实际数据清单、模型身份和执行实现尚待验收。
所有效果未知。R6三角色审查同一版本，不以讨论轮数代替实验。

## 1．唯一目标

在两条预定新构建路径中，各取首个满足文本资格的自然记忆更新；
针对一个固定64题池，区分随机解码波动与题间准确率增量结构，
检查**一个用旧数据拟合的固定CPU词面探针**是否值得继续做独立等成本确认。

这是旧开发数据到新路径的迁移筛查。64题各代表一个解题模板族，
不代表整个Engineering总体、所有同族题或任意自然更新。
两条路径不足以确认普遍迁移；本阶段没有新算法、主动选题、接受门、来源机制或失败发现主张。
不购买全池LLM预测，因此不声称超过强语义端点、rawpair或diff+CheckList适配。
CPU探针失败不能否定全部语义信息；其成功也不构成关系算法贡献。

E2的INCONCLUSIVE和E3的NO_INCREMENTAL_SIGNAL_ON_THIS_TABLE保持不变。
统计推断条件于旧数据及据此作出的设计选择、已实现的合格更新、固定题池和锁定预测；
不包含重新抽取开发数据或未来历史总体的变异。

## 2．数据与自然步骤

开发：复用旧E2的158题NN−OO，各端两rep，共632份旧回答及绑定的实际记忆输入。
完整NN−OO比较按状态定义选定，不按组件赢家选择。旧test在本研究中明确改作开发，
不再承担独立评价；旧E2预注册及其当时结论不改写。
开发仅一条历史的193/581两个端点，跨度较大；未来单步更新与之不保证同分布。

新采集只考虑Engineering，两根均从空状态开始，每根事前最多64道构建题。
每题solver一次，batch_update_size=8、max_num_rules=20、top_k=3；
每8次成功至多一次curator，因此每根最多64＋8次构建调用。构建不重试。
第一批初始化；成功batch第2至第8次中，选择首个父状态规则非空、
规范渲染规则文本发生变化且事件完整提交的步骤。文本重排保留并注明。
资格渲染器保留规则顺序，资格不读取审计成绩、不依任意评价题的packing选点。

事件边界固定为：触发题评分后、进入update_memory之前是父状态；
经验加入、curator处理和整个更新返回且完整提交后是子状态。
保存完整规则/权重、成功池、pending batch、轨迹、原始curator请求/响应和事件身份。
处理对象为完整规则、经验池、检索和packing状态的自然前后变化；
不把固定经验池的人工规则对照当自然步骤，也不归因于单条规则。
选中即停止该根构建；64题仍无候选、请求超长或状态损坏，均为资格失败。
正常答错或完整但无有效编辑的curator事件可继续预定窗口；不补根、不扩大窗口。
禁用旧resume续建：已知其会重置规则权重、丢pending状态。

两根构建题族互斥。共享一个64题评价池，每族一题；评价族与两根构建、
旧158题以及已进入开发的源材料隔离。允许知识概念/物理定律重合，
隔离的是同一母题、同构解题模板换数/改名及近重复。无法判定同源时合并并记录。
构建可复用公开旧材料，但不能根据旧后缀结果选取，重合范围必须披露。
原E0可能曾生成某些候选评价题的回答；旧后缀输出隔离不用，
只称“未用于本研究构建和拟合”，不称模型从未见过。
名义剩228题不是已验收的64个模板族；题料不足在生成前停止。

CPU先计算并锁定各根全64题预测，再各自独立SRS无放回抽32题。
允许两个审计子集重叠，不人为去重后仍称独立抽样。
每题每端4rep，预拆两组各2rep；不购买留出根的16题校准。
预测器只见允许的题面/选项与实际记忆文本；gold、审计回答、旧后缀输出、qid等身份捷径不进入特征。
评分侧可持有gold，身份字段仅用于隔离、调度与核验。

## 3．确定特征与拟合；只选一个主方法

q为完整题干及选项；R/E为实际渲染、按实际顺序和packing进入solver的规则/经历。
特征归一化固定为Unicode NFKC、casefold、连续空白变一个空格、首尾去空白。
对归一化串x，长度≥3时G(x)为所有连续字符三元组的集合；
长度1或2时取单元素集合{x}，空串取空集合。不加边界符。
\(s(q,x)=|G(q)\cap G(x)|/\sqrt{|G(q)||G(x)|}\)，空分母置0。
保留原始输入用于身份核验；特征归一化不能当作真实输入等价判据。

令 \(z_t=s(q,R_t)+s(q,E_t)-1\)，\(t=o,n\)。

| 预定方法 | 原始标量/定义 | 角色 |
|---|---|---|
| 零、开发常数 | 0、开发均值 | 直接配对基准；主量等价 |
| **E** | \(x=(z_n-z_o)/2\) | 唯一主方法，开发直线拟合 |
| E原始 | x | 无训练对照 |
| N | \(z_n\) | 仅新版词面探针 |
| D | \([s(q,R_+)-s(q,R_-)+s(q,E_+)-s(q,E_-)]/2\) | 显式编辑词面对照 |
| L | \(\ell(R_n\Vert E_n)-\ell(R_o\Vert E_o)\)，\(\ell(x)=|x|/(|x|+1024)\) | 长度对照 |
| H | 下述端点联合头 | 区分端点目标与差值目标 |

L以归一化字符长度计算，R/E之间插入一个换行再归一化。
D先在R/E各块内逐行执行上述归一化并去空行，再作保序LCS；
多解取匹配索引对序列的字典序最小者。未匹配新/旧行分别为加/删，
按各端原顺序用换行拼接。重排可能被表示成删加，不称语义删除。

E/N/D/L分别以158个题级均值差 \(d_i\) 拟合：
\[
\min_{a,\ |\gamma|\le1}\sum_i(d_i-a-\gamma x_i)^2+\gamma^2.
\]
这里x替换为各方法的预定标量；惩罚1、不搜索，题权相同，不把rep当新题。
斜率为中心化交叉积除以中心化平方和加1后裁到[-1,1]，截距为
\(\bar d-\gamma\bar x\)。完整预测不再裁剪，审计后不调权、不换主方法。

为对齐E/H的中心化预测范围及差值正则，记
\(u_i=(\bar Y_{n,i}+\bar Y_{o,i})/2\)、\(v_i=(z_{n,i}+z_{o,i})/4\)。
H使用共同差值斜率坐标：
\[
\min_{a,c,\ |\gamma|\le1}
\sum_i[(d_i-a-\gamma x_i)^2+4(u_i-c-\gamma v_i)^2]+\gamma^2.
\]
预测仍为 \(m_H=a+\gamma x\)。它等价于两端共享斜率、各有截距：
\(f_n=c+a/2+\gamma z_n/2\)，\(f_o=c-a/2+\gamma z_o/2\)，
训练损失为两端平方误差和的2倍加\(\gamma^2\)。
E/H差值项的每题系数、斜率范围及惩罚均相同，H额外拟合绝对得分水平。
两者拥有相同差值函数类；表现差异只能归于拟合目标等既定配方，不称新增关系信息。
辅助signed损失另受截距影响，不能将其优势写成主量优势。
所有对照共享合法标签权限；这些低容量词面模型不替代强语义基线。

## 4．主统计、方差和区间

对每根分别令 \(N=64,n=32,r=4,f=n/N\)，
\(\tau_q=E[Y_{n,q}-Y_{o,q}]\)，\(S_Q^2\)用分母N−1。
主量与估计为
\[
\Gamma=S_Q^2(\tau)-S_Q^2(\tau-m_E),\quad
w_q=\frac{2N}{N-1}(m_{E,q}-\bar m_{E,Q}),\quad
\widehat\Gamma=-S_Q^2(m_E)+n^{-1}\sum_{q\in A}w_q\bar D_q.
\]
在锁定预测、完整SRS和无偏解码下，对上述条件目标无偏；无需题目难度iid或模型正确。
它不是准确率提升的pp。常数平移不改变主量，因此留出截距校准无益于本目标。

旧新解码及不同题/rep须条件独立、稳定，评分为0/1。
令 \(v_q=p_n(1-p_n)+p_o(1-p_o)\)，则
\[
V_\Gamma=(1-f)S_Q^2(w\tau)/n+\overline{w^2v}_Q/(nr).
\]
每端4个得分的无偏样本方差为 \(s_{n,q}^2,s_{o,q}^2\)，
\(\hat u_q=(s_{n,q}^2+s_{o,q}^2)/r\)：
\[
\widehat V_\Gamma=(1-f)s_A^2(w\bar D)/n+
f\,\overline{w^2\hat u}_A/n.
\]
该估计非负且在上述条件下无偏；不能把全部解码噪声乘有限总体修正。
记录后端、时序与完整输入IDs；不同seed不证明独立，相关或漂移时上式不能直接使用。

逐根报点值、标准误、明确标为近似的t31区间和最大|w|/逐题贡献，不删高影响题。
同时给保守核对：每根\(\alpha=.025\)，\(\alpha_s=\alpha_d=\alpha/2\)，\(W=\max_Q|w|\)，
\[
t_s=W\sqrt{2\log(2/\alpha_s)/n},\quad
t_d=\sqrt{2\log(2/\alpha_d)\sum_{A}w_q^2/(n^2r)}.
\]
\(\widehat\Gamma\pm(t_s+t_d)\)使用无放回有界抽样、独立有界差值解码及联合界。
两根主比较同时覆盖至少95%仍依赖声明的条件，不要求两根独立；
它可能很宽，不用近似t区间替代其保证。其他对照仅描述，不追加未经校正的正式显著宣称。

两个解码组分别重算Gamma；合并主值是两组均值。它们共用审计题，
不是额外历史或独立抽题验证。辅助报
\(\operatorname{Cov}_A(D^{(1)}-m,D^{(2)}-m)\)、signed损失和N/D/L/H；
负的潜在方差估计保留，不构造稳定单题标签。

## 5．测量控制与明确终态

共64个额外控制回答：每根4个事先指定且冻结的完整input，各在主审计前、后调用4次。
每根控制选择固定为排序后首两个评价qid各取old/new，共4个prompt；排序依据事前种子与qid的稳定摘要，
不读成绩。seed列表事前独立抽取并冻结；主审计按题交错旧新，先后顺序事前随机化。

每根以4个input的“晚均值−早均值”的等权平均为统计量，作双侧层内4/4精确置换，
分层为input；两根报警错误率总计.01、各.005。
精确性依赖零假设下联合分布对所用分层置换不变，边际同分布或seed不同均不充分。
随机人工臂标签不承担漂移检验；早晚是时段属性。
显著只触发日志、身份及协议核查，不单凭p值认定漂移原因或否决实验。
未显著永不认证稳定，也不排除中途或未覆盖输入的变化。
若核查发现或不能排除具体协议破坏，相应推断降为不完整诊断；不得为了过门删控制题。

投入筛查比例：
\[
\hat B=(1-f)s_A^2(\bar D)+f\,\overline{\hat u}_A,\qquad
\hat\eta=(1-f)\widehat\Gamma/\hat B.
\]
分母为0或非有限时不定义、不通过。比例不裁为0到1，报告分子分母及不确定性。
两根Gamma点估计均正、各根代入改善≥10%、每解码组的等历史Gamma均值均正，
且全部资格完整，才建议另行设计独立等成本确认。
10%只是投入阈值，没有自动功效或错误率保证；区间跨零时也只能说“值得继续研究”。

| 终态 | 允许解释 |
|---|---|
| 无合格更新/题料/输入或记录不完整 | 对象或工程资格失败，不判断结构有无 |
| 潜在结构未分辨、区间宽、负方差估计 | 本预算未决；不追加seed或换题 |
| 结构存在而E不达门槛 | 限制当前特征、拟合与开发迁移的联合流程；不单独归因为词面特征 |
| E满足投入门 | 值得新一次确认；未证明真实改善≥10%、可复现或省成本 |
| 只有次级对照更好 | 记录线索，不替换E，不自动升级语义模型 |

## 6．完整成本合同

| 用途 | 已提交attempt上限 |
|---|---:|
| 两根构建，各64 solver＋8 curator | 144 |
| 两根32题×2端×4rep审计 | 512 |
| 早晚同输入控制 | 64 |
| 接口探测与非构建额外尝试 | 112 |
| **总计** | **832** |

前720个逻辑槽包含各自第一次派发，失败/空操作同样计费；
后112含至多8个事前登记接口探测、至多104个非构建重试，不互相挪用。
非构建每逻辑请求最多一次额外尝试；按固定协议接纳，不能按正确与否挑回答。
构建无重试；客户端、SDK等层不得隐藏重试。未知是否派发计入其本次槽，
不重复扣为两个attempt；额外重试另扣。明确未派发的超长输入记拒绝事件，生成计0。
所有提交前预扣、冻结逻辑与物理请求身份；失败根不补抽，余量不用于补题、扩样或追显著。
审计重试后仍缺回答则整根不完整，不能用complete-case通过。任一根资格失败，
主要双根诊断结束，已完成部分只能描述，未用额度不再花出。

solver/curator均保持最大输出2048，输入≤5888且输入＋2048≤实际上下文上限。
总预留至多 \(832\times7936=6,602,752\) tokens；保持输出帽仅减少一项迁移失配，
不保证后端/模型分布相同。完整curator八轨迹可能超长；派发前计数，超长停根，
不临时剪轨迹、摘要、减batch、换短题或扩窗口。
拟议24 GPU小时、8人工小时、2 CPU小时硬帽，任何先到就停止；不是已授权资源或完成预测。
CPU特征新增模型请求0，仍记解析、检索、拟合耗时。
旧开发实际采用632份回答，原E2全表2212份及更早构建支出另账，历史未知项明确标缺失。
摊销只用真实复用次数；不能把已有数据说成冷启动训练免费。

若以后主张省成本，仍须比较同精度下的完整成本：
\[
\operatorname{Var}(\hat\mu_m)=
\frac{1-n/N}{n}S_Q^2(\tau-m)+\frac{\bar v_Q}{nr},\quad
\hat\mu_m=\bar m_Q+\overline{(\bar D-m)}_A.
\]
完美预测也只能消抽题项；开销挤掉真实回答会放大噪声项。
当前Gamma或投入门通过均不等于这项经济性比较已经完成。

## 7．准入范围与待验清单

本稿可裁决的是设计：唯一目标、具体特征/模型、主统计、有限预算、失败解释。
当前只读资产整理在既有授权内，无需反复确认。
旧prefix有封存哈希但未取回；恢复它有助于路径诊断，不是从零新根的必要前置。
APIBench本轮退出；字符串反馈缺陷属于HumanEval，旧稿的API归属在此纠正。

进入任何新采集前，必须有实际而非模板占位的：

- 题库/评分器身份，64评价模板族及两根构建清单、旧材料暴露边界与交集报告；
- 旧158题得分到实际R/E、输入IDs及packing身份的绑定，固定开发拟合产物；
- 模型权重、tokenizer/chat模板、解码/上下文配置、检索器与packing版本；
- 根/状态/事件/请求身份、完整状态提交、预算闸门、拒绝与接纳规则；
- 抽样/顺序/控制种子，预测锁定产物，时间与tokens账本，以及执行验收记录。

这些资产与实现尚未齐备。R6最多通过限定设计和只读资格工作；
不能给新生成、真实效果、普遍迁移、节约率或可投稿贡献PASS。
若限定探针不值得进一步投入，结论可为停止此方向，不靠继续增加模块保留算法叙事。
