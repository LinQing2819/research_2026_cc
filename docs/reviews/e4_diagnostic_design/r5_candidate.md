# R5统一审查稿：自然更新的可测性与廉价预测诊断

稿号E4-D1候选，2026-10-28。R4后的实质修订，尚未实施。

## 1．唯一保留的问题与放弃的主张

固定求解器，外部记忆自然更新后，未见解题模板上的准确率变化是否具有可重复的题间结构；
一个预先固定的廉价词面探针，能否利用其中一部分，值得继续做独立的等成本确认？

停止等待“新的关系学习器”。本阶段不训练编码器、不做主动选题、提交决策、源绑定或失败发现。
不为全池LLM语义预测付款，不主张胜过语义rawpair或CheckList适配，也不以CPU失败证明语义信息不存在。
E2/E3既有结论保持不变。这是测量与低成本可用性诊断，尚无新算法贡献。

R4文献已核实：线性两端向量相减与共享线性端点头相减可属同一函数类；
FAQ依赖历史模型在固定题池上的成绩；PPI的残差校正已有；CheckList不是现成的有符号预测器；
PACE的条件胜率前提不能由总体非正收益推出。
详见[文献](r4_literature.md)、[统计](r4_statistics.md)、[数据](r4_feasibility.md)。

## 2．数据收敛：复用开发资产，只新建两个留出根

不再新增一条开发历史。已有E2的一条历史作为**后续研究的开发资产**：
使用全部158题NN−OO的两次得分以及完整实际记忆输入，拟合下述固定探针。
选NN−OO是完整旧新状态的预定比较，不按组件赢家挑选。158题不再充当本研究独立评价；
这不改写E2当时的预注册或结论。既有开发标签、构建与模型调用历史成本另报，不能称为免费训练资源。

拟议新采集：

1. Engineering单任务，两个从空状态开始的新根，根角色与输入顺序事先固定；每根最多64道构建题。
2. 求解器每题至多一次、每8次成功至多一次curator，故每根最多64＋8＝72次。
   第一批形成初始记忆；从第2至第8个成功batch选择首个旧规则非空且渲染规则发生文本变化的自然步骤。
   只按记录/文本资格选点，不看验证效果；重排保留并单独描述。没有合格步骤即停，不补第3根。
3. 处理对象为该在线步骤的完整前后状态：规则、经验池、检索和packing一起冻结。
   不用固定经验池的人造规则对照替代；不把当前一步的变化归因于单条规则。
4. 两个根允许共用同一64题评价池；每题代表一个预先定义的解题模板族。
   该池与两根构建、旧158题及旧开发材料按模板族隔离；概念/物理定律允许重合，另做描述。
   目标是这个固定64题池的等权均值，不是原始工程全集或新知识概念的迁移。
5. 构建题可从原公共材料中选取，但不得根据旧后缀答案/得分选择。两根构建题族相互隔离；
   所有题料划分在新生成前固定。名义剩228题不是已经合格的64个模板族。
6. CPU预测全64题并锁定后，各根独立均匀无放回抽32题审计，每版本4次，事先拆两组各2次。
   不读取留出更新的校准标签，不开展16题截距校准。审计gold与回答仅由评分与分析侧持有。

旧prefix原件仍未取回；它有助于恢复原路径但不能制造新的独立根。
当前只读获取已在研究授权内，受连接条件限制。新根必须真正从零保存完整状态，
不能走会重置权重/丢pending batch的旧resume路径。
APIBench退出本轮；上一版所提字符串反馈缺陷实际属于HumanEval，此处明确纠正。

## 3．唯一主方法：四个预定标量中的端点差

采用[R4统计§3.1](r4_statistics.md)的完全确定CPU规则：
Unicode NFKC、casefold、空白归一，带起止标记的字符三元组集合；
\(s(q,x)=|G(q)\cap G(x)|/\sqrt{|G(q)||G(x)|}\)，空块置0。
q含完整题干与选项，R/E为实际渲染的规则/经历，包含最终顺序及合法packing内容。

令 \(z_t=s(q,R_t)+s(q,E_t)-1\)。

| 对照/方法 | 固定原始标量或预测 | 作用 |
|---|---|---|
| 零、开发常数 | 0、开发均值 | 直接配对均值；两者主量相同 |
| N | \(z_n\) | 仅新版的词面探针 |
| **E，唯一主方法** | \((z_n-z_o)/2\) | 便宜的双端点词面差 |
| D，次级 | \([s(q,R_+)-s(q,R_-)+s(q,E_+)-s(q,E_-)]/2\) | 保序行diff的词面差，规则与经历分块LCS；多解按索引字典序固定 |
| L，次级 | \(\ell(R_n\Vert E_n)-\ell(R_o\Vert E_o)\)，\(\ell(x)=|x|/(|x|+1024)\) | 排查长度变化 |
| E原始，无训练 | \(z_E\) | 区分固定探针与开发拟合 |
| 共享端点预测头 | 用两端得分共同拟合 \(f(z)=a+bz\)，输出 \(f(z_n)-f(z_o)\) | 检查拟合目标的影响；不冒充强语义端点模型 |

N/E/D/L各只拟合一条同规则的开发岭直线：
\[
b=\operatorname{clip}_{[-1,1]}
\frac{\sum(z_i-\bar z)(d_i-\bar d)}{\sum(z_i-\bar z)^2+1},
\quad a=\bar d-b\bar z,\quad m=a+bz.
\]
每开发题一个两rep均值差标签，不把rep扩充成独立题；不搜索超参数，不按开发胜负换主方法。
共享端点头用316个端点均值标签、同一有界斜率及惩罚1，题权相同；
这是共享参数的端点拟合对照。其差分与E的函数类可重合，差异可能仅是拟合目标/正则缩放。
这些都是表面匹配探针，不能推出semantic diff、特殊关系表示或来源的贡献。
全部预测保持有限实数，不作审计后裁剪或调权。

## 4．统计对象、主量和决策

\(\tau_q=E[Y_{n,q}-Y_{o,q}]\)。主量为
\(\Gamma_{0,E}=S_Q^2(\tau)-S_Q^2(\tau-m_E)\)，并分别报告每个根。
使用[R4统计§4](r4_statistics.md)的全池已知预测矩估计：
\[
w_q=\frac{2N}{N-1}(m_q-\bar m_Q),\qquad
\widehat\Gamma=-S_Q^2(m)+\frac1n\sum_{q\in A}w_q\bar D_q.
\]
主值之外报告设计标准误、明确标为近似的区间、两个解码组和有界保守核对。
题池SRS不要求题目难度iid；调用仍要求独立、稳定。不同seed不是独立性的证明。
同输入控制、输入IDs、解码与后端身份共同用于测量排查，未报警不等于等效认证。

主统计不是准确率提升的pp。辅助报告cross-rep协方差、signed损失、N/D/L/共享端点对比；
负方差估计保留，不按两rep一致造单题标签，不挑次级赢家替代E。
两根共享题池只支持这两条路径、这个题池的条件描述，不以题或rep扩大历史样本数。

按同采样配置，潜在总方差改善比例
\[
\eta=\frac{(1-n/N)\Gamma}
{(1-n/N)S_Q^2(\tau)+\bar v/r}.
\]
R4规定的代入估计不裁成0到1；分母为0则未定义。
固定样本后，仅当两根主点估计均正、各根代入改善≥10%、两解码组的等历史均值均正，
且资格与测量记录完整，才值得设计下一次独立确认。10%是资源筛查阈值，不是显著性/功效保证。
区间宽而不达筛查时，本预算结束、统计结论未决，不续抽追通过。
E失败只否定这个探针；D成功不能自动顶替主方法或启动更大语义模型。

## 5．完整预算候选

| 用途 | 已提交attempt硬上限 |
|---|---:|
| 两根构建，每根64 solver＋8 curator | 144 |
| 两根32题×2版本×4rep审计 | 512 |
| 同输入控制：每根4个prompt，每prompt两人工标签各4rep | 64 |
| 接口探测、非构建重试、未知派发余量 | 112 |
| **总计** | **832** |

CPU特征/拟合新增生成请求为0，另记CPU用时；旧开发账独立披露。
构建不重试；其他同一逻辑请求至多一次额外尝试，计入112。
任何题在额度内不能完成预定回答，整根只报告不完整诊断，不删题后取得通过。
根缺失不补抽；文本无变化、curator无有效操作也消费已经派发的调用。

新协议建议统一输入上限5888 tokens、solver/curator输出512 tokens，总预留不超过
\(832\times6400=5,324,800\) tokens；同时受实际后端上下文限制。
这是明确的新诊断设置，不是沿用E2的2048输出并偷偷截断。512可能改变成功率及目标分布；
旧开发数据的输出上限不同是迁移失配，须评审是否应保持2048。
每个完整请求派发前计数，8条curator轨迹不保证装得下；超长停根，不截材料或扩窗口。
拟议另设24 GPU小时、8人工小时、2 CPU小时上限，先到即停；不是资源授权或完成预测。

即使E表现好，仍需完整成本比：
\[
C_{\rm pred}+C_{\rm fit}+C_{\rm audit}(n_1,r)
\quad\text{对}\quad C_{\rm paired}(n_0,r),
\]
且两者同精度。历史训练成本的摊销次数必须真实。
预测只能减少抽题误差，不能消掉独立解码噪声；不直接宣布“省多少题”。

## 6．R5需要集中裁决的未决点

1. 复用旧158题开发、只新建两个根是否足以完成这个限定诊断；不要求它支持普遍性。
2. 一维词面模型的函数类、校准、主量与继续阈值是否清楚；保守区间公式是否成立。
3. 512输出与旧开发2048不一致是否应改回2048；curator超长即停是否使此预算在实践中几乎不可完成。
4. 同输入控制的随机标签只能排查哪类测量问题；是否不应把显著性报警当整体有效性必要门。

三方审同稿后只作必要修订，R6审同一最终版本。没有借审查轮数取得新生成或方法贡献PASS。
