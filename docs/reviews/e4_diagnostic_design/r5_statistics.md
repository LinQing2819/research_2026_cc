# R5统计评议

结论：**有条件接受为固定题池、两条已实现更新路径的低成本诊断；统计表述仍须修改，不构成改善确认。**
范围：仅据共同稿 `r5_candidate.md` 审查，不联网、不实施、不调用模型。R4 §4原文本轮未完成逐式对读；以下从共同稿定义独立验算，不宣称已核实其原文。

## 1. 主Gamma正确；方差与保守界须明确成立条件

共同稿L80–86的主估计正确。条件固定旧开发数据、已选两根更新、评价池与全池预测，令
\[
S_Q^2(x)=\frac1{N-1}\sum_Q(x_q-\bar x_Q)^2,\quad f=n/N,\quad
D_{qj}=Y_{n,qj}-Y_{o,qj},\quad v_q=\operatorname{Var}(D_{qj}).
\]
这里每题配成 \(r=4\) 个版本差，不是8个独立差；每个解码组计算时 \(r=2\)。
\[
\Gamma=2S_Q(\tau,m)-S_Q^2(m)
=-S_Q^2(m)+N^{-1}\sum_Qw_q\tau_q.
\]
因此SRS下 \(\widehat\Gamma\) 对条件目标无偏；无须题目难度iid，也无须词面模型正确。常数预测的Gamma确为0；截距不影响该主量。

**必须修改M1（L82–89）：** 最终协议须明确方差公式及独立稳定解码假设，不能只写“设计标准误”。在不同题及rep的差值独立、同题rep同分布时，准确分解是
\[
\operatorname{Var}(\widehat\Gamma)
=\frac{1-f}{n}S_Q^2(w\tau)+\frac1{nr}\overline{w^2v}_Q.
\]
令 \(\hat v_q=s_j^2(D_{qj})\)，一个等价的无偏方差估计为
\[
\widehat V_\Gamma
=\frac{1-f}{n}s_A^2(w\bar D)+\frac{f}{nr}\overline{w^2\hat v}_A.
\]
第一项的样本方差已经含解码噪声，所以补项系数是 \(f\)，不是1；也不能只留第一项，把解码噪声一起乘有限总体修正。不同seed不能证明独立；存在共享调用噪声时须计协方差，上式不再直接成立。

**必须修改M2（L87）：** “有界保守核对”须给出实际界、覆盖率与条件。以下是可核对的充分形式，不是新增预测方法：
假设单次评分 \(Y\in[0,1]\)，令 \(W=\max_Q|w_q|\)，取预定的 \(\alpha_s+\alpha_d=\alpha\)，则
\[
t_s=W\sqrt{\frac{2\log(2/\alpha_s)}n},\qquad
t_d(A)=\sqrt{\frac{2\sum_{q\in A}w_q^2}{n^2r}\log(2/\alpha_d)}.
\]
在上述独立稳定调用条件下，\(\widehat\Gamma\pm[t_s+t_d(A)]\) 至少有 \(1-\alpha\) 的逐根覆盖率。
理由：\(w_q\tau_q\in[-W,W]\)，SRS无放回可用不加有限总体改进的Hoeffding界；给定A，解码项按每个 \(w_qD_{qj}/(nr)\) 的范围单独界定，再作联合界。
若沿用R4更紧的界，须逐项核对取值范围、无放回修正及尾概率分配；不能用潜在均值的有限总体修正缩小全部解码噪声。两根同时覆盖须另分配错误率，逐根区间则明确不是同时区间。保守界可能很宽，不要求它成为筛查门槛。

## 2. 旧158题开发与两个新根：条件推断成立

可接受复用全部旧158题拟合。条件于这些数据以及据此作出的全部方法选择后，锁定预测再独立抽审计题，旧标签噪声、开发历史只有一条、开发集曾被分析，都不破坏上述条件无偏性；它们主要限制预测性能与外推。

**必须修改M3（L21–40、93）：** 明确条件化对象包含旧数据驱动的设计选择、合格步骤选择、实际保留的两根状态及固定64题池。推断不包含开发样本重抽或新历史总体的不确定性。
保留模板族隔离、先锁全池预测再抽样、仅按文本资格选步骤、失败不补根、不完整不通过等约束即可；不要求增加开发根或第三根。
两根共用题池并各自SRS，不影响逐根结论；两解码组共用同一审计题集，仍共享抽题误差，不能称为两次独立确认，更不能扩成四个独立历史。
结果仅针对满足既定资格的这两条路径，不代表任意自然更新或未筛选更新的平均收益。旧158题不能再充当独立评价，历史成本应继续单列。
512输出可作为预先固定的新诊断目标；与旧开发2048的失配不导致主量偏差，但限制迁移解释。统计上不强制改回2048；不能见审计效果后再选输出上限。

## 3. 同输入随机标签检验不能认证无漂移

**必须修改M4（L89、112、141）：** 明确标签何时随机化、分配单位、置换空间、统计量及报警用途。
若标签不改变实际输入或执行流程，只在既定调用槽内随机分成两组，随机化检验检验的是标签关联，不是时间稳定性。
即使所有调用存在共同时间漂移，只要标签确实随机且无作用，条件于全部观测结果的随机化检验仍按零假设工作。因此它对这种漂移没有系统检出能力；显著也不能单独归因为漂移。
若标签代表不同执行或评分分支，同输入控制可以排查这些分支造成的标签效应，但结论限于所查输入与时段。若标签其实是前后时间块，不能未经证明便把任意置换当有效检验。
接受R6将两种检验明确分开、控制回答总数保持64：每根4个预指定input，每个早4次、晚4次，每根32次。人工随机标签若保留，只作标签/请求混淆检查；早晚标签是时段属性，不能援引人工标签的随机化保证。
早晚检验依赖零假设下的可交换性：整个数据的联合分布须在所用的“根×input”层内4/4置换下保持不变。只有早晚边际同分布不充分，跨调用或跨层的共同依赖也可能破坏这种置换有效性。
预先独立抽取并冻结seed列表、冻结输入及解码设置，主审计旧新调用按题交错且事前随机化先后，可以减少混淆；这些措施不证明实际调用独立或可交换。
预定评分指标、检验统计量、双侧方向及逐根/汇总报警规则。早晚检验只对所选输入、指标与时段的差异提供证据，不能排除中途波动、未覆盖输入的漂移或其他共同变化。
不显著永不认证稳定；显著仅触发预定核查，不应自动成为整体有效性否决门。若核查发现无法排除的协议破坏，则相应推断条件不满足，应降为不完整诊断。

建议R6最简准确写法：
> 同输入控制共64个回答：每根4个预指定且冻结的输入，各在主审计早期和晚期调用4次。seed列表事前独立抽取并冻结，解码设置固定；主审计旧新调用按题交错，先后顺序事前随机化。
> 人工随机标签检验仅检查标签/请求混淆，不用于检测共同时间漂移。早晚差异另按预定评分统计量，在“根×input”层内进行4/4精确置换检验；其精确性依赖零假设下联合分布对所用分层置换不变，不能仅由边际同分布或seed不同推出。
> 显著结果是测量核查信号，不单独认定漂移原因；不显著永不认证稳定。该控制不替代主分析的独立稳定调用假设，也不单凭p值决定整体有效性。

## 4. 10%点估计门槛可以保留，但仅作资源筛查

共同稿L95–99的比例正确：它比较相同 \(n,r\) 下直接配对均值与全池预测加残差校正均值的方差。
\[
V_0=\frac{1-f}{n}S_Q^2(\tau)+\frac{\bar v_Q}{nr},\quad
V_E=\frac{1-f}{n}S_Q^2(\tau-m)+\frac{\bar v_Q}{nr},\quad
\eta=(V_0-V_E)/V_0.
\]
**必须修改M5（L100–103）：** 写清代入分母与不可用规则。例如采用同一审计样本的噪声校正时，
\[
\widehat S_\tau^2=s_A^2(\bar D)-\overline{\hat v}_A/r,\qquad
\widehat B=(1-f)\widehat S_\tau^2+\overline{\hat v}_A/r
=(1-f)s_A^2(\bar D)+f\overline{\hat v}_A/r.
\]
该分母非负；0或非有限时比例不可用且不通过。若R4选用可能为负的其他代入分母，须将非正值也排除，不能靠符号翻转取得通过；潜在方差的负估计本身仍原样报告。
比例不裁剪是正确的，但小分母可放大点估计，不能把超出理论范围的估计当作真实改善程度。报告分子、分母和不确定性即可，不必新增筛查阈值。
保留“两根主点估计正、各根代入改善至少10%、两组等历史均值正”的预定规则；明确组内统计为各根使用该组两rep所得Gamma的等权平均。
这是决定是否设计下一次独立等成本确认的资源规则，不是显著性检验，没有自动的功效或错误率保证。区间跨零仍可筛查通过，但不得表述为已证实可重复改善、真实改善至少10%或已经节省成本。
