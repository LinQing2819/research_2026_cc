# R5 范围与贡献边界交叉评议

2026-10-28。仅依据 `r5_candidate.md` 与 `r4_literature.md`；未联网、编写代码、拟合或调用模型，不改其他稿。实验效果未知。

## 裁决

**有条件接受为封顶的测量与 CPU 词面预测诊断设计；不接受为新关系算法、普遍迁移或已证实省测的方案。** 下列三项应在最终冻结稿中修订，不要求增加模块、语义基线、题池或更新根。本评议不核准未读的统计与工程细则，也不构成实施授权。

从关系学习器退到固定标量、零目标标签校准、两条新根和硬预算，是实质收敛：方法可预定，失败后不换主方法，研究不再依赖尚未发明的表示。但“自然更新有无可测结构”和“这个旧开发拟合的词面探针能否利用结构”仍是两个问题，不能以后一项失败代答前一项。

收缩的代价也要承认：R4 的多维位置/长度探针变成 R5 的字符三元组集合重合度，并非同一假设的等强测试。保存完整渲染文本不等于特征保留其信息；集合重合度大量压缩顺序、频次与作用条件，R/E 相似度相加也不能识别来源贡献。它是有意选择的弱探针，不是自然更新的充分表示。

## 必须修订一：把函数类与拟合差异写到可核对

当前“函数类可重合、差异可能仅是目标/正则缩放”仍不够准确。令 `x=(z_n-z_o)/2`：

- E 为 `a_E+b_E*x`，`|b_E|<=1`；共享端点差为 `2*b_H*x`，`|b_H|<=1`，无自由截距。
- 因而原始预测的受限函数类并不相同；即使主量中心化去掉截距，共享头在 x 坐标上的斜率范围仍是 E 的两倍。
- 同写惩罚 1 不表示同等正则：换成 x 坐标后，端点斜率惩罚的系数随之改变；316 个端点与158个差值的损失求和、每题权重及归一化还须明确。
- 端点目标同时拟合绝对正确率水平与变化，差值目标只拟合变化；即使公平对齐后 E 更好，也可能只是目标适配，不是增加了关系信息。

**修订要求：** 用共同的差值斜率坐标写清两种损失、每题总权重、约束和有效惩罚，统一允许的中心化预测范围与可对齐的正则尺度，只将训练目标保留为被比较因素。这是改现有对照定义，不是新增方法；不能对齐的部分须明示为拟合配方差异。

`Gamma` 对常数平移不变，因此 E 的截距、开发常数均不产生该主量上的贡献。signed 损失却会受截距影响，须单独注明其比较口径，不能把偏置拟合优势转述为关系表示优势。E 原始对照可描述开发拟合的作用，但仍不能分离所有迁移与特征因素。

## 必须修订二：冻结一个有意义但足够窄的目标

单个64题池并非单一模板：若每题确实来自不同、预先隔离的模板族，它可以回答“两条预定路径上，面对这些未参与构建及拟合的题面，旧开发训练的廉价探针是否有筛查价值”。这对是否支付下一次独立确认成本有意义，不因单任务而自动失去价值。

边界是每族仅一个代表、只有一个固定池和两个更新；没有族内稳定性证据，也没有从 Engineering 总体抽样的保证。共享池允许条件比较，不提供独立题池复现。两条从零根也只代表两条路径，不能据64题或重复调用数构造更新总体的样本量。

**修订要求：** 在唯一问题、摘要与结果模板中统一写成“首个满足预定文本资格的自然步骤、两条路径、固定64题池等权目标、旧开发到新路径的迁移筛查”，而非笼统的自然更新规律。文本变动包括重排，未必代表行为改变；无合格步骤是对象资格失败，不是无增量结构。

旧 E2 全158题改作开发资产是合理的后续复用，但不能恢复成独立检验；一次历史的158题也不是158次更新。完整 NN-OO 比较与新根单步更新的变化幅度和机制可能不同，应作为开发迁移条件明示，而不是声称“同分布训练”。

输出设置需在此处一并定稿：优先使求解器上限与旧开发2048一致，并同步重算预算。若预算只能支持512，则将问题明确命名为跨输出设置迁移诊断，承认失败兼容于设置失配；不能既保留失配又把阴性结果归因于词面表示。本轮不要求追加新设置对照或重采开发标签。

允许共享概念、隔离解题模板是合理边界；强行隔离概念可能移除记忆本来适用的范围。不过“一族一题”只支持这些代表题的描述，不足以宣称整个新模板族都迁移成功。

## 必须修订三：预先写清结果如何结束或继续

**修订要求：** 将已有资格、结构、预测和成本指标组织成以下解释表，不增加实验分支。主量满足 `Gamma=2*Cov(tau,m)-Var(m)`；因此不达标既可能是相关信息不足，也可能是缩放失配，不能仅凭负值诊断“特征没有信息”。

| 观察结果 | 可接受解释与动作 |
|---|---|
| 状态、模板隔离或测量资格不完整 | 只能报告不完整诊断；不进入算法优劣或结构有无判断。 |
| 潜在结构未分辨、方差出现负估计或区间很宽 | 本预算下未决；不是结构为零，也不是自然更新无用，不续抽追通过。 |
| 结构可分辨，但 E 不达筛查 | 至多限制这套词面特征、拟合及旧开发迁移流程在这两条路径上的可用性；不能单独定位为特征容量不足。 |
| 两根 E 及各解码组满足原定筛查条件 | 值得预注册下一次独立、同精度完整成本确认；正点估计和10%阈值不等于显著性、可复现性或已节省预算。 |
| E 与共享头或原始 E 相当 | 简单探针可能够用；没有特殊关系信息或开发拟合必要性的证据。 |
| 仅 N/D/L 或其他次级对照更好 | 记录解释线索；不得替换主方法取得通过，也不自动启动语义模型。 |

若区间足够精确，能排除预定的实用改善幅度，才可形成有信息量的局部阴性结论；仅“未过门槛”仍可能是精度不足。结构存在而 E 失败，不否定更丰富特征或语义关系；结构未检出，也不能倒推问题没有结构。

准确率均值变化和估计方差收益必须分开：总体准确率下降时仍可能有可预测的题间结构，`Gamma>0` 不表示更新改善了求解能力。两解码组只提供噪声诊断，不是额外独立历史。

本轮 CPU 新增生成请求为零不等于整个流程免费。旧开发与构建成本、拟合和审计均需分账；相同 n/r 下的潜在方差收益只支持继续筛查，不能替代同精度且包含预测开销的总成本比较。

## 去掉语义 rawpair 是否合理

合理，前提是当前问题明确限定为“固定 CPU 探针是否已值得继续确认”，而不是“关系方法能否战胜现有方案”。在这个限域问题中，不购买全池语义预测符合预算约束，无须为了算法叙事重新加回。

代价是不能声称击败强端点/关系表示、语义 rawpair 或 CheckList 适配，也不能声称这是最优成本前沿。未比较并非对方不适用或无效；弱 CPU 共享头不能替代强语义基线。当前 N/E 比较即使有差异，也只涉及特定标量与拟合流程，不是旧状态普遍具有独立预测价值的证明。

## 文献与贡献措辞

以下边界只依据 R4 已载核验，本轮不追加独立文献核验：

- **GBV-PD：** 借方向性分解及成本分账；不能把文本差称为梯度，不能声称首次逐题增量预测；本设计没有其局部可微更新保证。
- **FAQ / PPI：** 借预测与残差校正分离；校正不是新发明。FAQ 的同题库历史成绩不同于本设计的新模板代表题，不能据此虚构算法优势，亦不继承其区间保证。
- **CheckList：** 借模板族与合法行为关系定义；它不是现成的有符号更新收益预测器。未运行提示适配，不写胜过 CheckList。
- **PACE：** 借同题比较、审计隔离及未决处理；这里不做提交接受检验，不借用 anytime-valid 或任意反馈复用的保证。

建议贡献表述：“在固定求解器的自然外部记忆状态更新中，预先限定两条新路径与一个未参与构建、拟合的模板代表题池，区分随机解码噪声和题间增量结构，并筛查预定 CPU 词面探针是否具有进一步成本确认的价值。”

这是拟检验的测量问题与协议安排，不是已取得的发现。只有得到精度足够、可解释的正向或局部阴性证据，才谈条件性的实证贡献；没有效果时，不能用‘新评测框架’补足不存在的算法或经验贡献。

**最终意见：范围收敛真实、限定问题有意义；完成上述三项文字与对照定义修订后，可接受为小规模诊断设计。效果、普遍性和经济收益均仍未知，不授予方法创新或实验效果 PASS。**
