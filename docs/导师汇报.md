# 自进化 Agent 外部记忆：阶段汇报与下一步研究

目前完成了固定记忆组件比较和有限预算配置选择的实验，尚未确认可靠增益。基于实际结果，下一阶段收敛为：**自然记忆更新带来的性能变化能否测清、能否被廉价预测，从而为减少更新评估成本提供依据。**

## 一、最初想解决什么问题

Agent可以把历史成功案例和归纳规则作为外部记忆，在后续任务中读取。可以把模型看作能力固定的学生，规则是方法总结本，案例是例题本。本研究不训练模型权重，考察“笔记更新以后，做题表现怎样变化”。

记忆更多并不保证更好：新增案例可能有用，新规则也可能过度概括。我们最初希望识别有害记忆并恢复较好的历史版本；进一步发现，整库回退可能连有用的新案例一起丢掉，因此转向规则与经历的组件比较。

## 二、已经做了哪些工作，结果是什么

| 阶段 | 研究问题与方法 | 实际进展 |
|---|---|---|
| E0：伤害筛查 | 比较有／无记忆，加入无记忆重复以估计随机翻转 | 获得探索线索；复核发现日志、反馈、状态恢复及特征时序问题，早期数值不能直接作为确认结论 |
| E1：快照恢复 | 比较较早与最新的完整记忆 | 完成设计与工具；尚无可确认收益的完整结果 |
| E2：组件交叉 | 将旧／新规则与旧／新经历交叉，加入缺失组件控制 | 完成七臂生成与复核；主统计结论为未决 |
| E3：有限预算选择 | 比较实际提示表示、存储表示和简单分配方法 | 完成真实离线回放；未达到预设增量条件 |
| E4：自然更新诊断 | 先检验更新差异的可测性与廉价预测价值 | 限定设计已通过内部评审，进入数据与输入验收准备 |

**E2的实验材料：** Qwen3-8B、MMLU-Pro Engineering、一条ExpeL历史。较早与较晚快照分别在完成193题和581题后形成；实际评价为64道开发题、94道测试题。每题七种配置各回答两次，共2212份正式回答。

| 测试配置 | 正确回答／188 | 准确率 |
|---|---:|---:|
| 旧规则＋新经历，ON | 108 | 57.45% |
| 旧整库，OO | 94 | 50.00% |
| 新整库，NN | 93 | 49.47% |
| 仅新经历，ZE | 95 | 50.53% |
| 无记忆，ZZ | 99 | 52.66% |

ON的点估计较高，但相对OO、NN、ZE的三个预定同时95%区间都跨零，也跨过3个百分点的最小重要收益门槛，故结果为 **INCONCLUSIVE**。开发集上的整库选择器和组件选择器都选了OO，组件选择没有取得增益。测试上某个固定组合最高，不等于算法能够提前把它选出来。

**E3复用这2212份回答，没有新增模型调用。** 六种方法使用同样的候选与虚拟评估预算，分别运行16种预定读取顺序。主方法“实际进入提示的表示”平均测试准确率为50.83%，原始存储表示为51.00%，不共享信息为50.76%，均匀分配为50.30%。主方法未达到相对三个必要对照至少提升2个百分点的筛查条件。16种读取顺序共享旧回答，不构成16次独立实验。

E2正式已接纳回答使用约739万tokens；E3只重新读取已存结果，其虚拟成本用于方法间公平比较，不能抹去原始数据的生成成本。

## 三、结果为什么促使我们转向E4

逐题复核显示，同一道题在不同配置下往往一起容易或一起困难。测试94题×7配置的两次得分相关性约0.596；分别扣除题内七配置均值后降到约0.112。这是描述性诊断，提示可预测的绝对得分结构未必是可利用的记忆增量结构。

同时，完整输入相同也出现过两次全对与两次全错的差异。因此，观测到的更新前后对错变化混有随机解码波动。继续增加配置选择模型的复杂度，未必能解决这一测量问题。

当前研究顺序调整为：**先确认自然更新带来的变化是否可测、是否含有低成本可利用的信号，再研究怎样靠预测减少评估。**

## 四、E4具体研究什么，准备怎么做

长期目标是每次记忆更新后，先根据题目和新旧记忆预测影响，再抽少量题实际运行、纠正预测误差，以估计整体收益。预测辅助估计和残差校正已有相关方法；本阶段先检验它们在自然记忆更新中的前提。

例如，某题旧版本答对概率为80%、新版本为60%，目标变化就是−20个百分点。我们要预测这个变化，而不是仅预测新版本的绝对得分。这里的概率是解释性例子，不能由单题一两次回答可靠确定。

E4-D1采用一个收敛后的有限设计：

1. **开发数据：** 使用旧158题的完整新旧快照比较NN−OO，两端各两次，共632份旧回答。原test在E4中明确作开发，不再承担独立确认。
2. **新研究对象：** 从空状态构建两条预定路径，每条至多64道构建题，各取首个符合文本与完整性要求的自然更新。不按评价表现挑更新，规则和经历的完整变化共同保留。
3. **评价设计：** 固定64个解题模板族代表题，与开发及构建材料隔离。各路径锁定全池预测后，独立随机抽32题，每端回答4次，共512份审计回答。
4. **唯一主预测器：** 用题面与实际规则／经历的字符三元组相似度变化，拟合固定的一维岭直线。另设零值、常数、新版、文本增删、长度及端点拟合等对照。新增预测模型调用为0。
5. **测量目标：** 检查预测是否降低题间残差方差，并区分抽题误差和解码噪声；增加64份早晚同输入回答检查测量条件。

拟议新增预算封顶832次提交尝试，包含144次构建、512次审计、64次同输入控制、8次探测及104次非构建重试。输入至多5888、输出预留2048 tokens，总预留包络约660万tokens。旧数据和历史构建成本另账。

## 五、E4能说明什么，不能说明什么

主量为正意味着预测可能帮助区分题目受更新影响的程度，不等于更新提高了总体准确率。两条路径都达到预定的正向点估计和10%代入方差改善条件，只表示值得继续做独立等成本确认；不能宣布真实节约10%或统计显著。

若没有合格更新、输入超长或题族不足，属于资格失败；若区间太宽，则保持未决。若当前探针无效，结论限于这组词面特征、拟合方式与开发迁移流程，不能否定全部语义预测。两条路径也不能支撑普遍跨历史结论。

文献上借鉴GBV-PD对更新方向与题目难度的区分、FAQ和PPI的预测加残差校正思路，以及CheckList的模板测试组织方式。这些已有思想不作为本项目的新算法贡献。当前要争取的是自然更新的可测性、预测可用性和失效边界证据；可投稿贡献尚未建立。
