# 果蝇记忆门控与连接组具身控制：两篇阅读报告

- **阅读日期：** 2026-11-25
- **主题：** 分裂式吸引子、记忆写入门控、连接组计算、无人机具身闭环
- **与本仓库的关系：** 为 `E+ / E- / R` 异质记忆、候选集合选择和反馈闭环提供机制类比与工程边界，不构成当前方法的效果证据，也不改变已冻结的 P5/P6/P7 协议。

## 总览

两篇材料分别回答了两个层次的问题：

1. **《A split attractor design for rapidly writing a navigational goal》**研究一个神经回路如何在“持续保存目标”和“快速更新目标”之间切换。核心机制是：PFG 神经元持续跟随当前方向输入，hΔK–PFG 递归回路负责稳定目标表示，FB5V 等抑制性输入则通过抑制或去抑制控制递归回路何时真正进入记忆状态。[cite:1](#cite-1)
2. **FlyDrones**研究如何把果蝇连接组计算模型接入无人机闭环。核心并不是“连接组直接看像素并控制电机”，而是由工程化感知编码器、脉冲网络、下行神经元读出、传统飞控和独立安全控制器共同构成闭环。[cite:3](#cite-3)[cite:4](#cite-4)[cite:5](#cite-5)

两者共同揭示了一条值得关注的系统原则：

> 一个可持续工作的智能系统不仅需要内部状态，还需要明确的写入门控、输入输出接口和独立执行边界。

对本仓库而言，最直接的启发不是新增一种算法，而是更严格地区分四件事：**什么内容可被召回、什么内容应被选中、什么反馈允许更新选择策略、什么硬约束始终不能被学习组件覆盖。**

## 阅读报告一：分裂式吸引子与导航目标的快速写入

### 1. 文献信息

- **论文：** *A split attractor design for rapidly writing a navigational goal*
- **作者：** Aaron J. Lanz、Nicholas D. Kathman 等，通讯作者 Katherine I. Nagel
- **期刊：** *Nature*
- **在线发表：** 2026-10-07
- **DOI：** `10.1038/s41586-026-11144-9`
- **辅助阅读：** 微信公众号“知跃空间智能”文章《行业解读｜分裂式吸引子设计——果蝇导航目标的“写入开关”》

论文原文是本报告关于生物机制的主要依据；公众号文章用于帮助梳理结构，不作为独立实验证据。[cite:1](#cite-1)[cite:2](#cite-2)

### 2. 研究问题

递归吸引子网络适合维持持续活动，因此常被用于解释工作记忆。但持续性越强，旧状态通常越难关闭，形成稳定性与灵活性之间的矛盾：网络既要在短暂线索消失后继续保持目标，又要在动物转向或环境变化时迅速解除旧目标。[cite:1](#cite-1)

论文聚焦三个具体问题：

1. 果蝇如何在气味消失后继续保持此前选定的导航方向？
2. 表示当前方向的活动如何转变成稳定的短时目标记忆？
3. 已经形成的目标如何在转向或休息时快速关闭，避免持续活动反过来妨碍行为更新？

### 3. 回路结构

论文研究果蝇中央复合体扇形体中的 hΔK、PFG、FB5V 和 FB6M 等神经元。关键分工可以概括为：

| 组件 | 主要输入或连接 | 论文支持的功能解释 |
|---|---|---|
| PFG | 接收来自内部罗盘系统的结构化方向输入；与 hΔK 强递归连接 | 低活动时连续跟随当前朝向；与 hΔK 共同高活动时参与稳定目标表示 |
| hΔK | 与 PFG 构成环状递归网络；接收广泛兴奋和抑制输入 | 活动峰出现时较稳定，关联目标方向的短时保持 |
| FB5V | 对 hΔK 提供前馈抑制 | 抑制增强时使 hΔK 与 PFG 功能解耦；抑制降低时允许递归回路写入目标 |
| FB6M | 同时影响 hΔK 和 PFG，并接收部分反馈 | 更像对整个递归回路的许可性调节，而不是单独承担内容写入 |

这里的“分裂”不是指网络被永久切断，而是递归吸引子由两个接收不同输入的神经群组成：

- PFG 更接近**当前内容输入端**；
- hΔK 更接近**被门控的保持端**；
- 抑制性输入控制两个部分何时形成有效递归。

这种结构把“写入什么”和“什么时候写入”分给不同的回路入口。[cite:1](#cite-1)

### 4. 核心机制

#### 4.1 跟随模式

当 hΔK 受到较强抑制时，hΔK–PFG 递归作用被功能性削弱。PFG 仍能接收罗盘输入，因此其活动峰可以跟随果蝇朝向连续移动；hΔK 则很少形成稳定活动峰。

该模式适合实时反映当前方向，但不会轻易把瞬时方向固化成目标。

#### 4.2 写入与保持模式

气味出现并触发目标导向行为时，FB5V 活动受到抑制，hΔK 被去抑制。此时 hΔK 与 PFG 的递归回路重新耦合，当前罗盘输入对应的位置被快速锁定为稳定活动峰。即使之后方向输入变化或气味消失，活动仍可持续一段时间。

用通俗语言描述：

1. PFG 不断提供“此刻朝向”；
2. 去抑制相当于打开写入开关；
3. 开关打开瞬间的方向被递归回路稳定下来；
4. 稳定活动继续支撑短时目标导向行为。

#### 4.3 退出与改写模式

果蝇发生明显转向或偏离目标时，FB5V 活动增强，hΔK 再次受到抑制，稳定目标峰消失。PFG 恢复为跟随当前朝向的状态。之后再次去抑制时，可以把新的方向写入回路。

因此，该回路不是单纯的“持续记忆器”，而是一个可以在下列两种状态间切换的锁存结构：

```text
输入跟随：当前方向持续变化，不固化
    ↓ 去抑制
信息保持：当前方向被锁定为目标
    ↓ 抑制恢复
输入跟随：释放旧目标，等待下一次写入
```

### 5. 证据链

论文没有只依赖单一观察，而是组合了多种证据：

- **闭环行为与钙成像：** hΔK 和 PFG 在气味诱导的直线目标运动中都形成持续活动峰；PFG 在转向时继续跟随方向变化，hΔK 活动则多在转向时消失。
- **全细胞电生理：** hΔK 本身的内在膜性质不足以产生所观察到的持续兴奋；阻断递归信号会削弱持续活动，支持网络交互而非单细胞自持解释。
- **连接组分析：** hΔK 与 PFG 具有强递归连接，PFG 接收罗盘输入，FB5V 和 FB6M 提供抑制性输入。
- **计算建模：** 慢速递归兴奋配合快速抑制，可以在较宽参数范围内形成可调节的持续活动；对 hΔK 的抑制或去抑制可以复现“方向跟随”和“目标保持”的切换。
- **抑制性神经元成像：** FB5V 在气味和持续目标运动期间活动降低，在转向和偏离目标时活动增强，方向与模型预测一致。[cite:1](#cite-1)

### 6. 论文最重要的贡献

#### 6.1 把内容与写入时机解耦

传统的统一吸引子模型往往把输入、保持和状态切换压在同一群神经元上。该研究显示，递归网络可以拆成两个部分：一个接收要保存的内容，另一个接受门控。这样，写入内容和写入时机可以由不同信号控制。

#### 6.2 用功能解耦解决稳定性与灵活性冲突

网络的解剖连接不需要临时改变。快速抑制可以在功能上切断递归，去抑制又能迅速恢复递归。系统因此既保留稳定的物理连接，又能快速切换计算模式。

#### 6.3 时间常数本身是计算资源

模型表明，慢速兴奋不是单纯的生物延迟，而是扩大可稳定持续活动的参数范围，使持续时间可以通过较小的兴奋或抑制变化进行调节。快速抑制则负责及时关断。稳定与快速不必来自同一种动力学。

### 7. 局限与未完成证据

这篇论文给出了较完整的相关性、回路生理和模型证据，但作者明确指出，门控模型还需要进一步因果验证：

- 还没有通过直接激活或抑制 FB5V，完整证明它可以按预测在“跟随”和“保持”两种模式间切换；
- 部分持续性可能来自该回路上游，而不完全由 hΔK–PFG 内部递归产生；
- 果蝇导航目标是低维方向变量，不能直接外推到语言模型中的高维文本记忆；
- 生物回路中的去抑制不等同于软件系统里的二值开关，真实作用还受到神经调质、时间尺度和行为状态影响。[cite:1](#cite-1)

因此，最稳妥的结论是：

> `[SINGLE-SOURCE]` 该研究支持“分离内容输入与写入门控可以兼顾状态保持和快速更新”这一生物回路机制；它不能单独证明同样结构在语言模型外部记忆中必然有效。

### 8. 对本仓库研究的启发

#### 8.1 “被召回”不等于“被写入”或“被使用”

当前 P5 负责从 `E+ / E- / R` 三个通道形成有限候选池，不调用 solver，也不决定最终使用内容；后续反馈和选择器负责估计实际效用。这个边界与论文中的“PFG 跟随输入，但只有去抑制后才进入稳定保持”具有结构类比。

对应关系只能用于帮助思考，不能视为生物等价：

| 分裂式吸引子 | 当前外部记忆流程 |
|---|---|
| PFG 跟随当前方向输入 | P5 形成与当前问题相关的候选内容 |
| hΔK–PFG 递归锁定目标 | 选择器确定本题实际使用的记忆子集 |
| FB5V 抑制/去抑制 | admission / selection gate 决定是否启用候选 |
| 转向时解除旧目标 | 反馈表明记忆有害或失效时停止使用 |

当前仓库已经明确“召回相似度不是记忆效用”，并把 P5 候选形成与 P6/P7 效用学习分开。[P5 汇报](../../../P5汇报更新_2026-11-10.md)中的这一边界应继续保持。

#### 8.2 选择器需要保留空集动作

如果门控只能在候选中强制选择，就相当于吸引子永久处于开启状态。当前设计允许选择空集，并限制最多使用三项，这与“默认跟随、条件满足后才保持”的思想一致。

因此，空集不应被当作无信息的退化类别，而应被视为一个明确的控制动作：

- 当前候选不值得进入 prompt；
- 当前题对已有记忆不敏感；
- 候选存在冲突或风险；
- 使用记忆的预期收益不足以覆盖成本。

#### 8.3 写入门控与内容价值应分开评估

论文中，PFG 提供内容，FB5V 控制写入时机。对应到外部记忆系统，内容质量评分与是否启用记忆不应压缩成同一个无条件相似度分数。

当前 `Set vs NoCross` 的关键价值也在这里：它检验跨角色交互是否提供增量，而不是只看某条内容自身得分。已有评审明确要求 Set 与 NoCross 共享候选、标签、可行集合和预算，唯一差异限制在跨角色项。[创新性评审](../../reviews/four_role_memory/novelty.md)

#### 8.4 不应立刻引入新的“生物门控算法”

当前 P6 执行前必须冻结题目、A/B/C 三项组、完整 prompt、模型、随机种子、评分器、解析器和独立预算。分裂式吸引子更适合作为后续机制解释或新一轮研究假设，不应成为看到当前结果后修改 P6 条件的理由。

合理的后续问题是：

> 在当前 Set/NoCross 主比较完成后，是否需要单独研究“选择候选内容”和“决定是否开启记忆”两个不同控制头？

这个问题需要新的预注册实验，不能复用本轮反馈做事后证明。

### 9. 阅读结论

这篇论文最有价值的地方，不是给出了一个可以直接照搬的软件模块，而是展示了一种明确的计算分工：

- 当前输入可以持续被读取；
- 记忆写入需要额外门控；
- 持续状态由递归结构维护；
- 状态解除由更快的抑制机制负责；
- 内容通道与控制通道彼此分离。

对当前研究而言，这支持继续坚持“召回、选择、反馈、准入分层”，但不支持新增未经对照的生物启发算法主张。

## 阅读报告二：FlyDrones 与果蝇连接组无人机闭环

### 1. 项目信息

- **项目：** FlyDrones — *A fruit fly connectome as a drone pilot*
- **仓库：** `SpikeCalls/FlyDrones`
- **定位：** 连接组计算模型、脉冲神经网络、感知编码、动作读出和无人机接口组成的开源研究原型
- **核心数据：** MaleCNS v1.0 雄性果蝇中枢神经系统连接组
- **神经动力学基础：** Shiu 等人在 *Nature* 2024 发表的果蝇计算脑模型

FlyDrones 的 README 和 SCIENCE 文档主动区分了生物学依据与工程选择，这是评价该项目时最重要的材料。[cite:3](#cite-3)[cite:4](#cite-4)
公众号文章用于梳理项目结构和中文术语，项目完成度与技术边界以仓库原始文档为准。[cite:11](#cite-11)

### 2. 项目到底实现了什么

FlyDrones 把无人机感知、果蝇连接组计算和飞行控制串成一个闭环：

```text
相机 / IMU
  -> 软件提取亮度、光流、逼近膨胀和偏航速度
  -> 映射到果蝇视觉与平衡相关神经元
  -> 脉冲神经网络传播活动
  -> 读取 DNg02、DNp03、DNp01 等下行神经元
  -> 映射为油门、偏航、制动或逃逸指令
  -> 独立安全控制器过滤
  -> 无人机飞控执行
  -> 新的相机和 IMU 状态再次进入网络
```

项目架构文档给出的单次控制循环顺序为：

```text
frame
-> retina.encode
-> encoder.encode
-> brain.tick
-> decoder.update
-> safety.filter
-> drone.send
```

安全控制器位于神经网络之后，并且拥有最终决定权。[cite:5](#cite-5)[cite:7](#cite-7)

### 3. 哪些部分来自生物数据

#### 3.1 连接结构

MaleCNS v1.0 是完整雄性果蝇中枢神经系统连接组，覆盖脑、视叶和腹神经索。官方项目提供细胞类型、连接、突触、骨架和注释等数据，并以 CC-BY 许可发布。[cite:8](#cite-8)[cite:9](#cite-9)

FlyDrones 使用连接组中的神经元类型、侧别、突触数和预测神经递质构建有符号连接网络。具体神经元和连接数量会随过滤条件变化，项目文档通常概括为约 16.6 万个神经元。[cite:3](#cite-3)[cite:4](#cite-4)

#### 3.2 神经元动力学

项目采用漏积分-发放模型。这个方向有独立论文基础：Shiu 等人利用果蝇连接组和预测神经递质构建全脑脉冲模型，并通过味觉、进食和梳理回路展示了连接结构与神经递质信息能够生成可实验检验的感觉运动预测。[cite:10](#cite-10)

FlyDrones 沿用该工作的主要参数，但为了运行速度调整积分步长，并加入可选噪声和持续偏置等工程项。[cite:4](#cite-4)

#### 3.3 感觉与动作通路名称

项目选择了已有神经科学研究中的细胞类型：

- R1–R6：亮度输入；
- T4/T5：方向选择性运动输入；
- LPLC2、LC4：逼近物体相关输入；
- 平衡棒传入神经：由无人机 IMU 偏航速度近似；
- DNg02：升力与左右转向读出；
- DNp03：逼近诱发的快速转向；
- DNp01 / giant fiber：快速逃逸通路。

这些细胞类型和部分功能解释来自既有研究，但 FlyDrones 对输入和输出的具体映射仍由工程实现定义。[cite:4](#cite-4)

### 4. 哪些部分是工程桥接

FlyDrones 不是“连接组直接看像素、直接控制电机”。至少有五层人工设计：

1. **早期视觉由软件计算。** 光流和逼近膨胀先由传统视觉算法提取，再注入 T4/T5、LPLC2 和 LC4 等神经群；真实果蝇层板和髓质中的大量早期视觉计算被绕过。
2. **存在持续飞行偏置。** DNg02 接收人工设定的 tonic flight drive，使安静画面下仍有合理的基础飞行输出。
3. **动作读出是工程映射。** 下行神经元发放率通过线性权重转换为高层摇杆指令，权重可使用默认值或校准得到。
4. **部分行为语义由外部设定。** 前向巡航速度不是连接组自主规划的；逃逸时的上升、下降或制动也是适配无人机的替代动作。
5. **传统飞控与安全层独立存在。** 无人机自身飞控负责姿态稳定，Safety Governor 负责速度、地板、天花板、地理围栏、看门狗、电量和最长飞行时间等约束。[cite:3](#cite-3)[cite:4](#cite-4)[cite:7](#cite-7)

因此，准确表述应是：

> FlyDrones 是一个以果蝇连接结构和飞行相关神经通路为核心先验、由工程感知与动作接口包围、由传统飞控和安全控制器兜底的闭环实验系统。

### 5. MiniFly 与 MaleCNS 必须区分

| 维度 | MiniFly | MaleCNS 模式 |
|---|---|---|
| 规模 | 约 850 个神经元、4,928 条连接 | 约 16.6 万个神经元；连接数取决于过滤 |
| 连接来源 | 仓库内手工构造的简化网络 | 电子显微镜重建的真实连接组 |
| 主要用途 | 浏览器演示、测试、快速复现 | 完整连接组计算与通路分析 |
| 证据边界 | 只能证明软件闭环可运行 | 结构真实，但动力学和输入输出仍有工程近似 |

浏览器演示和 GIF 使用的是 MiniFly，而不是完整 MaleCNS。README 明确说明这一点。[cite:3](#cite-3)

### 6. 当前完成度

项目已经提供：

- 事件驱动 LIF 模拟器；
- MaleCNS 数据构建与加载；
- MiniFly 演示网络；
- 相机光流、逼近信号和 IMU 输入；
- 多类下行神经元动作读出；
- 模拟器、Tello、Crazyflie、MAVLink 和 ESP32 接口；
- 安全控制器、可视化面板、校准和测试；
- 浏览器三维演示。[cite:3](#cite-3)[cite:5](#cite-5)

但项目路线图把“首次完整 MaleCNS 的真实 Tello/Crazyflie 飞行，并发布日志与未剪辑视频”列在后续版本中；README 也明确写明硬件适配器尚未由作者完成真实飞行测试。[cite:3](#cite-3)[cite:6](#cite-6)

因此，当前证据主要支持：

- 软件接口和仿真闭环已经实现；
- MiniFly 浏览器演示可以运行；
- 完整连接组可被加载并用于计算；
- 项目具备真实无人机适配层和安全协议。

当前证据尚不支持：

- 完整 MaleCNS 已经可靠完成真实无人机自主飞行；
- 连接组在没有人工感知、读出和安全层时可以独立导航；
- 该方法优于现代无人机控制器或 VLA；
- 浏览器演示可以代表完整连接组的实时性能。

### 7. 项目价值

#### 7.1 把连接组从静态结构变成闭环可干预系统

连接组研究常停留在“谁连接谁”。FlyDrones 把连接结构放入环境反馈中，使研究者可以观察感知变化如何经过神经活动转化为动作，再由动作改变下一帧输入。

#### 7.2 将结构先验用于低层快速控制

项目没有训练一个端到端策略去学习所有反射，而是利用已知视觉和下行神经通路构造低层控制先验。这个方向可能适合数据稀缺、需要快速反应和可解释路径的局部控制问题。

#### 7.3 故障可以沿接口逐层定位

系统可以分别检查：

- 视觉特征是否正确；
- 输入神经群是否被激活；
- 脉冲传播是否符合预期；
- 下行神经元是否产生信号；
- 读出映射是否合理；
- 安全控制器是否覆盖异常命令。

这比只观察端到端动作更容易区分“结构失败、动力学失败、接口失败和执行失败”。

### 8. 局限

项目文档主动列出了主要限制：[cite:4](#cite-4)

- LIF 是点神经元模型，不包含树突、缝隙连接、复杂神经调质和可塑性；
- 早期视觉由软件计算，不能证明完整连接组自己完成了视觉运动估计；
- 普通无人机相机与果蝇复眼在视场、分辨率和成像机制上差异很大；
- 控制循环处于几十赫兹量级，与真实果蝇飞行的毫秒级反射存在时间尺度差异；
- 仿真器采用简化速度响应，不包含复杂空气动力学；
- 完整 MaleCNS 在文档所述 CPU 基准上尚未稳定达到实时速度；
- 真机接口存在不等于真实飞行已经验证。

这些限制决定了 FlyDrones 更适合作为**连接组具身化试验平台**，而不是“数字果蝇已经学会驾驶无人机”的完成性证据。

### 9. 对本仓库研究的启发

#### 9.1 系统贡献必须按层归因

FlyDrones 的表现同时来自连接结构、软件视觉、神经动力学、动作读出、飞控和安全层。把最终行为全部归因于“果蝇连接组”会造成错误归因。

当前外部记忆研究也需要保持相同纪律：

| FlyDrones 层 | 当前记忆研究层 |
|---|---|
| 感知特征与神经群映射 | P5 类别路由与三通道候选召回 |
| 连接组动力学 | 候选间关系与 Set/NoCross 交互建模 |
| 下行神经元读出 | P7 选择器对子集的评分与选择 |
| 环境反馈 | P6 solver 回答和评分反馈 |
| Safety Governor | 冻结协议、预算账本、人工准入和执行门槛 |

这个表是工程类比，不表示两个系统在数学上等价。

#### 9.2 硬约束不能交给学习器自行决定

FlyDrones 的安全控制器位于神经网络之后，限制始终优先于脑模型输出。对应到当前研究，下列条件也应继续作为不可学习覆盖的硬门槛：

- `human_attestation=false` 时不能宣称正式人工准入；
- P5 不能调用 solver 或报告效用；
- P6 条件必须事前冻结；
- 各阶段预算不能转借；
- Set 与 NoCross 除跨角色项外必须共享其他条件；
- 重复回答必须先在题内聚合，再按题等权统计。

这些约束不是选择器特征，而是实验可识别性的安全层。

#### 9.3 闭环不等于在线自修改

FlyDrones 已经形成感知—动作—新感知闭环，但当前版本并不因此自动学习或修改连接组。类似地，P5—P6—P7 构成反馈链路，也不能自动推出“自进化记忆已经成立”。

需要区分：

- **闭环执行：** 输出会影响下一步输入或反馈；
- **参数学习：** 反馈用于拟合选择器；
- **记忆写入：** 新内容被准入库；
- **自进化：** 系统能在受控规则下持续修改内容与策略，并经独立评估证明收益。

当前仓库只应按真实完成阶段报告状态。[项目 README](../../../README.md)和[最终同稿决定](../../reviews/four_role_memory/decision.md)已经明确限制训练、P6反馈和效果主张。

#### 9.4 对照实验必须覆盖接口贡献

如果未来声称跨角色关系提高选择效果，需要排除以下替代解释：

- 候选文本更多或更长；
- 路由让某些方法获得了更好的候选；
- 选择器预算不同；
- 某一角色包含了其他角色独有信息；
- 工程过滤而非跨角色交互带来收益。

这与 FlyDrones 必须区分“生物连接结构”和“工程桥接”的理由相同。当前 Set/NoCross 共享候选、标签、枚举、可行集合和预算的设计应继续保持。

### 10. 阅读结论

FlyDrones 的价值不在于证明一个完整生物大脑模型已经可以替代无人机控制栈，而在于展示了一种分层闭环：

- 生物连接结构提供先验；
- 工程接口把现实传感器转换为网络输入；
- 可解释读出把网络状态转换为动作；
- 传统控制器负责稳定；
- 独立安全层限制风险；
- 环境反馈持续回到系统。

对当前记忆研究而言，最重要的借鉴是**分层归因和硬门槛优先**，而不是把“连接组”“脉冲网络”或“具身闭环”包装成新的算法标签。

## 两篇材料的联合启发

### 1. 共同结构

| 问题 | 分裂式吸引子 | FlyDrones | 外部记忆研究 |
|---|---|---|---|
| 信息从哪里来 | PFG 的方向输入 | 相机、IMU 和感知编码 | 当前题与 P5 候选 |
| 何时进入内部状态 | 去抑制打开写入 | 编码器驱动指定神经群 | admission / selector 决定是否使用 |
| 状态如何产生作用 | hΔK–PFG 递归保持 | 下行神经元读出 | 记忆子集进入 solver prompt |
| 如何获得反馈 | 行为状态与新方向 | 动作改变下一帧感知 | P6 答案与评分 |
| 什么不能被内部状态覆盖 | 抑制重新关闭保持 | 独立 Safety Governor | 冻结协议、预算和人工准入 |

### 2. 对当前路线的建议

1. **不修改当前冻结实验。** 两篇材料只进入阅读与机制讨论，不用于事后调整 P6 的 A/B/C、子集、预算或统计规则。
2. **继续保持召回与效用分离。** P5 只产生候选；P6 才产生反馈；P7 才训练选择器。
3. **把空集作为正式控制动作。** 选择器应能拒绝全部候选，而不是被迫使用记忆。
4. **把实验硬门槛放在学习器之外。** 人工准入、预算、题族隔离和比较公平性不能由训练结果覆盖。
5. **后续可研究双层控制。** 在当前主比较完成后，可另行预注册“选哪些记忆”和“本题是否开启记忆”两个控制问题，但不能把分裂式吸引子的生物证据直接当成该设计的效果证据。
6. **报告系统贡献时做接口消融。** 任何收益都要区分内容、检索、跨角色交互、选择器和 prompt 长度的贡献。

### 3. 最终判断

- **分裂式吸引子论文：** 对“记忆内容与写入时机分离”提供了强机制启发，对当前选择器和空集动作的解释有帮助。
- **FlyDrones：** 对“结构先验如何嵌入完整工程闭环”提供了清晰案例，最值得借鉴的是接口分层、安全边界和贡献归因。
- **创新边界：** 两篇材料都不能证明 `E- × R` 跨角色交互有效，也不能证明当前系统已经具备自进化能力。真正的研究结论仍必须来自预注册的 Set/NoCross 和后续反馈实验。
