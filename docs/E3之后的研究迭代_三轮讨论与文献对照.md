# E3之后的研究迭代：问题诊断、文献对照与下一阶段

2026-10-27。基于真实E2/E3结果的事后分析；新增模型实验调用为0。

## 1．研究建议

**停止继续优化当前E3全局配置选择器，保留“自然记忆更新的增量信息诊断”作为下一阶段研究问题。**

需要先回答：一次记忆更新对哪些题有帮助、对哪些题有损害，这种差异是否稳定到足以被学习？如果有，旧新版本的关系是否比直接比较两份记忆、分别预测两端效果等简单方法更有用？

当前不建议直接换更强embedding、增加GP复杂度、引入RL，或把两个时点扩成许多版本。它们会增加成本，却尚未解决“是否存在可迁移的增量信号”这一前提。已有论文也覆盖了这些常见扩展。

下一阶段暂记为**E4-D0**：诊断提案，不是已通过的新方法，不是开始运行的新实验。优先检查版本与数据资格，随后才决定是否值得采集新的独立回答。

## 2．E3结果究竟否定了什么

| 方法 | 16种顺序的平均测试准确率 |
|---|---:|
| 实际提示表示 rendered | 50.83% |
| 检索后、打包前表示 unpacked | 50.83% |
| 原始存储表示 stored | 51.00% |
| 去交互表示 additive | 50.66% |
| 不共享信息 independent | 50.76% |
| 均匀分配 uniform | 50.30% |

rendered相对stored、independent、uniform为−0.166、+0.066、+0.532个百分点，均未达预先要求的+2个百分点。非空记忆选择次数为11/16，满足次数条件。因此失败来自准确率增量条件，不是数据错误或程序未完成。

**被实测的是一套联合流程：字符表示、核、全局臂效用模型、预算分配、两候选入围及少量复核。** 联合失败不能定位哪个部分贡献最大，也不能统计上证明“实际表示永远无效”。

rendered与unpacked有三种顺序的搜索动作不同，但最终选择16/16相同；与stored的最终选择15/16相同。当前表示差异没有转成有用的决策差异。

所有方法的平均分都低于固定无记忆ZZ的52.66%。这是一项描述性提醒：复杂选择器至少要证明值得付出它的选择成本；不能只与较弱记忆方法比较。

## 3．深入分析得到的五个修正

### 3.1 不是简单的“开发题只看了31道”

完整64道dev中，ON为57/128＝44.53%，OO为74/128＝57.81%。即使把旧选择器可看的题数翻倍，当前回答上的均值规则仍会选OO。

| ON减对照 | dev第1次回答 | dev第2次回答 | test第1次回答 | test第2次回答 |
|---|---:|---:|---:|---:|
| OO | −14.06pp | −12.50pp | +2.13pp | +12.77pp |
| ZZ | −14.06pp | −7.81pp | −1.06pp | +10.64pp |

开发／测试的ON−OO方向差异在两个重复中都出现，而ON−ZZ的测试优势在重复间连方向也不一致。预算不足可能影响候选覆盖，但不足以独自解释现象；也不能直接命名为分布漂移，因为dev/test来自同一后缀的预定随机划分。

**优化含义：** 不再以“怎样让算法选到ON”为训练目标。ON不是已知最优标签；继续调到选中它很容易变成追逐已看过的测试结果。

### 3.2 “题容易不容易”比“哪份记忆帮得更多”更稳定

两次回答的正确性相关，在test为0.596；每题先减去七臂共同均值后，相关降到0.112。dev对应为0.522和0.136。

直观地说，模型容易在同一道简单题上对、在同一道难题上错，这能使七种配置看起来具有很强共同结构。但选择记忆需要知道的是：扣除这种共同难度后，哪种配置更好？

同样，原`题×配置`均值矩阵的第一奇异成分占能量88.17%；按题中心化后仅30.12%。原矩阵中的非零均值与共同难度，不能被当作“记忆增量低秩”的证据。

这些相关与谱都是描述性指标，中心化还引入共享约束，每题只有两次测量。**低相关不证明不可学习，高原始相关也不证明值得做低秩选择。**

**优化含义：** 学习目标从总体正确率转到同题新旧差值，并以预测差值的残差、独立重复和未见更新泛化来评价。

### 3.3 两次都对与两次都错，仍可能没有记忆处理差异

题11985比较两个铝块接触后的不可逆性。ON与OO的完整输入token IDs相同，均为3568 tokens，规则与三条经历也相同；结果却是ON两次正确、OO两次错误。四次使用不同seed，均正常结束。

在无状态且稳定的solver条件下，这道题没有记忆输入干预，观测差异不能归因于新旧经历。它贡献了ON−OO净多14条正确回答中的2条，但这一比例不是总体噪声率。

**优化含义：** 不按每臂两次一致给题贴“被修复／被伤害”的真值标签。保留同版本及精确同输入负控制、独立解码与未决结果；不删除这道题，不修改E2预注册结论。

### 3.4 新版没有删掉旧规则，主要是追加和重排

逐条核对快照后：

- 旧14条中13条去编号后逐字出现在新20条中；
- 另一条只增加句首冠词并改变首字母大小写；
- 新版增加6条规则，旧条目排序也变化；
- 旧99条成功经历完整保留，新池追加到302条。

因此，“新版把旧知识抽象坏了、丢了前提”不能作为本次数据已证明的机制。新增知识、规则位置、输入长度、案例竞争都可能改变行为，目前没有分离这些干预。

规则内容也不是旧版天然正确：旧新两版都包含海水传播距离与频率成反比的说法；在介质参数固定的良导体近似下，固定衰减比例的距离应与频率平方根成反比。新版短偶极天线孔径规则又省略了方向与增益条件；无损匹配峰值方向需包含1.5增益因子。

上述核验支持“规则需要条件与内容检查”，不证明这些条目造成了E2分数变化。类似地，一条被判成功的历史经历存在复数开方相角错误，却进入了一道ON、ZZ都答对的题。**内容有错、被检索、导致当前错误，是三个不同判断。**

**优化含义：** 首先恢复自然更新事件，区分追加、编辑、重排；不通过人工造一个“丢前提”的版本来冒充自然退化。

### 3.5 当前数据没有稀疏的“受影响题集”

所有题都看到全部旧14或新20条规则。新经历池中的新增案例进入59/64道dev、93/94道test。ON与OO完整输入相同的机会只有dev2题、test1题。

因此，“只重测命中更新的题”在本次设置下几乎仍要全测；输入变化不等于有效果，效果大小与方向还需测量。

**优化含义：** 不能把代码回归测试中的依赖图直接换成记忆命中图，便宣称能省大量调用。需要证明哪种预生成信息对实际效果差有预测价值。

## 4．算法层面的可疑点及其边界

当前E3为七种配置各估一个全局均值，不直接学习“题目×版本”的作用。它给不同臂读取同一顺序的不同长度前缀，这些均值又混入题目组成差；按同题成对比较可以减少这项干扰。

噪声模型`0.25/n_answers`对固定题、固定样本量、条件独立解码是方差上界；对新题泛化，则还需要题目异质性，两个回答不等于两道新题。自适应停止和同题共享也不由这一对角项完整描述。因此，GP标准差只是工作模型的不确定性。

这些是合理的改进线索，**不是已识别的失败主因**。完整dev本来就不支持ON，换一个更准确的统计模型也不会凭空生成缺失的验证信号。应先在相同观测权限下比较信息价值，再把有价值的信息放入主动采集过程。

## 6．下一阶段的具体问题与做法

### 6.1 从绝对分数转到版本差值

原E3问“七个配置中哪一个最好”。E4-D0先问：

> 给定同一题和一次自然更新，能否预测新版本相对旧版本的平均得分差，而且这种预测对未见更新仍有用？

例如，新版新增一条天线规则。旧新全文已经告诉预测器新增了什么；任务题干告诉它是否涉及天线。然而“相关”并不等于“该更新会改善答案”。候选模型需要预测同题旧新差值，并在新的独立回答中验证。它不能看到两版已经做出的当前答案后才宣称预先预测了收益。

这里研究的是整次更新在当前固定solver上的作用。若要进一步定位某条规则、错误公式或重排的因果贡献，需要单独设计干预。

### 6.2 必须跨过三道简单对照

1. **直接paired均值或常数。** 少量校准题已经能告诉我们某次更新总体可能偏好或偏坏；模型必须提供更多题间信息。
2. **分别预测两端再相减。** 旧版本能帮忙，也许只是让算法知道原来表现如何，而非学到了特殊版本关系。
3. **同预算的原始旧新全文，以及直接diff提示。** 差分是两端文本的确定函数，不能声称它增加了原文之外的信息；若显式结构有用，也须排除额外计算和更多有效上下文。

只看新版本的强边界方法、廉价变化量和预先匹配的错配关系也作为对照。主方法只胜过明显不相关的旧版本，不算支持贡献。

第一阶段保持相同观测掩码与简单学习器，不同时更换检索、记忆内容、统计模型和选题策略。先识别信息是否有价值，再问它怎样分配预算。

### 6.3 为什么先看“残差结构”

设预测器给每道题预测新旧差值，再抽一批随机审计题核对。可使用已有的模型辅助思路：

```text
估计全题池更新收益
  = 全题池的平均预测
  + 随机审计题中“实际配对差值−预测”的平均
```

如果模型只对每题报同一个数，该数会在加减中抵消，最后仍是普通抽样均值。要减少误差，需要模型抓住哪些题的版本差偏高、哪些偏低，使剩余残差更稳定。

该估计思想已有，不是本项目理论贡献。当前诊断只看支撑它的可迁移信息；没有可靠全池真值和合适测量精度时，不宣布整个估计器已经更准。

### 6.4 机器学习与强化学习的安排

第一阶段可以用固定文本表示和正则化的简单预测头，比较输入信息条件；具体学习器仍需单独冻结，不能假定现成embedding解决问题。训练标签是经过独立解码测量的有符号版本差值，不是“哪个配置赢了”。

暂不引入RL。我们缺的不是更大的动作空间，而是足够可信、可迁移的反馈。若先把随机差异当奖励，RL只会更积极地利用这种误差。待增量信息得到支持后，才有理由比较主动采集与均匀配对评估的成本收益。

## 7．现有资产能支持哪一步

E3导出包有两个端点及逐题投影，没有逐步规则更新链和当前回答完整正文。但原manifest列出了已封存的`prefix_raw.json`、`old_prefix_raw.json`，导出时已校验其存在与摘要，只是没有把原文包含在当前包中。

取回这些封存原件，有望恢复：

- 每次规则变化前后的文本；
- 当时传给curator的最近8条成功经历；
- 哪些事件只是权重/排序变化，哪些有实际文本变化。

这能恢复**真实输入批次**，不等于能确定每条新规则唯一来源。旧规则本身还携带更早信息。端点之间约25个batch边界仍属于同一条历史，也不等于25个独立实质更新。

本轮尝试读取封存原件时连接超时，尚未取得新增日志；以上“可恢复批次”是依据已核验manifest与构建代码的判断，未冒充已完成原件分析。

工程后缀中，未进入本次E2且扣除两道已知重复题后，名义上剩228题；尚未通过新题族隔离，且早期E0可能已产生其结果，不能称为从未见过的新题。另有物理、数学公共文本，但没有因此获得合格独立构建历史。

**立即可完成的是资产与资格审计，不是重新生成整张实验表。** 如果独立历史、题族或评分条件不足，报告缺口，再设计新采集。不能用改题号、换顺序或多次解码填充历史数。

## 8．规模与成本：先有边界，不承诺小效应

讨论过一个条件性信息诊断形状：两个任务各三条自然构建历史，其中一条开发、两条留出；每历史16题校准、32题审计；校准每版本2次，审计每版本4次。共1920条成功回答，合法共享于所有信息条件。

拟议总上限3072次attempt，剩余额度覆盖构建、特征与强对照、测量控制、失败和重试；在单次输入5888、输出2048上限内，对应至多约2438万预留tokens。该额度尚未逐项闭合，也不是已确认资源配额，更不能证明它足够新建六条历史。

这只有四条留出历史，最多提供有限诊断，不能确认3个百分点收益、普遍迁移或部署安全。已有统计情景显示：即使固定一条历史、只检验单个两臂对比，按题级差值方差0.14规划，检测3个百分点对零差约需1221道独立题，且尚未加入多历史、多对照等不确定性。

因此新生成阶段保持HOLD。下一步若要执行，必须给出真实历史清单、题族隔离、评分器资格、具体学习器、全部对照成本和停止规则；不能靠省略强对照获得开跑资格。

## 9．三轮讨论怎样改变了方案

本次确实使用多agent分工：每轮三个角色，第二轮复用了一个第一轮agent，其余按独立任务上下文工作。三轮形成九份角色评议，由主代理综合。它们属于AI内部交叉讨论，不是九位人类专家或外部同行评审，也不提供统计独立证据。

| 轮次 | 主要问题 | 修订结果 |
|---|---|---|
| 第一轮：统计、记忆文献、问题定位 | 是否只是预算小？规则是否真的丢知识？近邻覆盖了什么？ | 加入完整dev、重复稳定性、共同难度、同输入反例；淘汰“更复杂选择器自然更好”的假设 |
| 第二轮：查重、设计、可行性攻击 | 变更测试与源绑定是否新？应该发现失败还是估总体收益？ | 变更测试宽泛新算法被否决；源绑定退出；增加端点相减与rawpair强对照，承认数据资格缺口 |
| 第三轮：同稿核查 | 收缩后的问题、统计对象、成本与准入是否一致？ | 三个角色均限域接受经验问题与只读资格工作；要求文字修订，算法、生成与贡献均维持HOLD或不通过 |

第二轮存在真实分歧：可行性角色倾向“发现更新相关失败”，统计角色倾向“有限题池总体差值估计”。最终选择后者的信息前提，因为它与预算受限更新评估主线一致，也避免用定向挑战集的高失败率冒充整体风险。失败发现保留为另一个问题，本阶段不同时追求。

## 10．研究停止条件

- 如果旧新关系只改善绝对正确率，不改善有符号版本差值的残差结构，停止该关系学习主张。
- 如果端点相减或直接diff提示已同样好，承认简单方法足够，不包装新算法。
- 如果效果只在已看题、同一历史或人工制造错误中成立，不支持自然更新迁移。
- 如果复核噪声和总成本使问题在当前资源下不可分辨，记录未决并停止扩张；不追加到显著。
- 如果资产审计没有独立历史或有效评分条件，先解决测量对象，不能直接训练RL。
